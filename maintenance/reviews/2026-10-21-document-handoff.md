- “先问接收方”缺少问题内容和分流：改为副本、签名公证、附加证明书、翻译、内容更正的联系人与所需答复。
- “允许代理就索取模板”缺少签署与交接：补具体动作、草稿预查、签署条件、亲友带件清单及不允许代理的退路。
- 文件来源不明确：用NJ签发婚姻记录作为限定实例，连接州卫生部门、财政部门和官方申请入口，明确副本申请与附加证明书是两步，网上付款后仍须送件。
- 原完成标准把取得下一步要求也列在一起：明确物流、登记、补件与正式结果分开；待补件不能标成办结。

保留全部标题、历史内容及任务ID。新增四个任务搜索用例，不增加重复清单。各个示例都不使用真实私人资料。

## 虚构情境走查

| 情境 | 可找到的起手动作与结果边界 |
|---|---|
| 海外本人请亲友代领国内档案 | 先问具体业务能否代理与专用格式；不能代理时问本人路线，不靠多做认证突破限制 |
| 窗口只说要公证 | 追问文件、签字、认证形式、翻译与原件；美国办理机构与国内受理方分别确认 |
| NJ婚姻记录已在手机拍照 | 从卫生部门申请适用认证副本，说明附加证明书用途；不把照片公证当正确记录版本 |
| 人住NJ但记录来自其他州 | 回文件来源州办理，不将居住州当作记录签发州 |
| 在线附加证明书费用已支付 | 仍按订单方式送材料与确认页、保存退回安排，不把支付成功当办妥 |
| 原件已签收却没有案件更新 | 用运单、签收日、案件编号和清单向收件部门查登记，避免盲寄第二套原件 |
| 有附加证明书仍因姓名／翻译／权限被退 | 找对应签发机关、译者或授权审阅方处理具体缺项，不继续加认证掩盖内容问题 |
| 补件来不及 | 询问可否延期／先交部分材料，保存明确答复；申请不当作批准 |

这是编辑者模拟走查，不是真实办理、法律专业审定或用户验收。当地接收部门的受理要求、跨境签署形式、材料与期限仍需真实个案确认。
