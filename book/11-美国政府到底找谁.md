# 11 — 美国政府到底找谁

美国生活事务分散在联邦、州、县和市镇，也有非营利组织参与服务。遇到问题，先判断紧急程度和主管机构，再确认办理方式与期限。本章提供找入口的方法，不把某个城市的做法当作全国规则。

## 1. 不知道联邦机构名称，从官方目录开始

**优先级：** P1

**查入口：** [USA.gov：联邦机构 A–Z 目录](https://www.usa.gov/agency-index) · [USA.gov：州与地方政府目录](https://www.usa.gov/state-local-governments) · [USA.gov：按生活事件查政府服务](https://www.usa.gov/)。

搜索广告、代办网站和看起来正式的标志都不能证明政府身份。先从官方目录进入，再收藏实际办事页；下载应用也应沿官方网站给出的链接。

## 2. 紧急情况先打 911

**优先级：** P0

在美国，生命受到即时威胁、火灾、正在发生的严重犯罪或严重伤害，应联系 911。清楚说明地址、发生了什么及是否有人受伤，并按接线员指示行动。具体准备见[第 03 章](03-紧急情况与急救.md)。

普通停车咨询、长期邻里争议和一般服务请求，使用当地非紧急电话；如果原本普通的纠纷出现即时暴力危险，应重新按紧急情况处理。

**直接入口：** [911.gov：Calling 911](https://www.911.gov/calling-911/)。

## 3. 211 帮助寻找社区资源

211 服务网络连接住房、食物、公共事业费用援助及其他健康和社会服务资源。它由地方服务机构组成，不应当作全国统一的政府审批窗口，也不保证转介后一定符合福利资格。

**直接使用：** [211.org：按 ZIP code / 地区寻找本地资源](https://www.211.org/)。

咨询时给出所在地区、需要的服务、语言需求及时间紧迫程度，问清具体机构、申请条件和联系方式。211 不替代紧急救援。

## 4. 311 要查所在城市是否提供

311 是一些城市的非紧急服务入口。例如纽约市 311 提供噪音、住房维护、垃圾和街道等问题的入口及工单查询。其他城市的号码、职责和网站可能不同。

**纽约市入口：** [NYC 311：搜索服务、提交请求和查状态](https://portal.311.nyc.gov/)；其他城市先从对应市政府官网进入。

搬家后保存当地市政服务页、警察非紧急电话和停水停电报修方式；不要假设拨 311 就一定能联系到目标城市，尤其是在异地或海外。

## 5. 州政府常负责哪些事

驾照与车辆登记、州税、保险监管和许多职业执照，通常先找州级机构。车辆部门可能称为机动车管理局（DMV）或机动车委员会（MVC），名称并不全国统一。

通过官方目录确认办理州，再核对预约、所需原件、地址变更和付款方式。执照查询与投诉也可能是不同页面，查询到执照不代表监管机构为服务质量担保。

**查州入口：** [USA.gov：State motor vehicle services](https://www.usa.gov/state-motor-vehicle-services) · [USA.gov：州消费者保护办公室](https://www.usa.gov/state-consumer) · [IRS：各州政府网站汇总](https://www.irs.gov/businesses/small-businesses-self-employed/state-government-websites)。

## 6. 县级机构不能忽略

不动产登记、部分婚姻和出生死亡记录、地方卫生服务、法院相关事务等，可能涉及县级机构，也可能由州、市或其他司法机构负责。

遇到县书记官（County Clerk）、登记官（Recorder）或遗嘱认证法院（Probate Court）等名称，先查所在辖区的职责。不要仅凭名称判断某个办公室一定受理某类文件，也不要把政府记录查询网站与收费代查公司混淆。

**找县级入口：** [USA.gov：State and Local Governments](https://www.usa.gov/state-local-governments)。从州 / 地方政府官网继续进入实际 county clerk、recorder、court 或 health department。

## 7. 市镇事务从住址所属辖区查起

停车、垃圾清运、建筑许可、分区使用、噪音及房屋规范问题，经常需要市镇或当地主管机构处理。邮寄地址上的城市名不一定足以确认主管辖区。

准备具体地址、问题照片、发生时间及已联系过的单位；涉及公寓时，同时区分物业合同责任与政府执法权限。

**找市镇入口：** [USA.gov：State and Local Governments](https://www.usa.gov/state-local-governments)；停车、building、zoning、noise 与 sanitation 均以实际 municipality / local authority 页面为准。

## 8. 提前建立联邦税务个人账户

**优先级：** P1

美国国税局个人在线账户（IRS Individual Online Account）可查看税务记录、余额、缴款、部分电子通知和授权事项，并提供身份保护码入口。页面显示范围有限，不能把“网上没看到”当成纸质通知无效的依据。

**直接办理：** [IRS Online Account](https://www.irs.gov/payments/online-account-for-individuals) · [IRS：Get Transcript](https://www.irs.gov/individuals/get-transcript) · [IRS：Payments](https://www.irs.gov/payments)。

注册、身份验证和账户恢复应在没有迫切期限时完成。不要把账户密码交给报税人；需要代理时使用适当授权程序。

## 9. 理解税务身份保护码

身份保护码（IP PIN）是帮助防止他人冒用社会安全号码（SSN）或个人纳税人识别号码（ITIN）报税的六位码。符合条件并能验证身份的人可以申请，不限于已经遭遇身份盗窃者。

有效码按日历年变化：在某年提交以前年度税表，也应使用提交当年的有效码。当前规则包含一次性加入选项，该选项在日历年结束时退出；其他加入方式和身份盗窃受害者安排须看本人情况，不能统一理解成“永久加入”或“随时退出”。

**直接办理：** [IRS：Get an Identity Protection PIN](https://www.irs.gov/identity-theft-fraud-scams/get-an-identity-protection-pin) · [IRS：Identity Theft Central](https://www.irs.gov/identity-theft-central)。只在准备申报时通过安全方式提供给可信报税人，不回应索要验证码的陌生来电。

## 10. 核对社会安全收入记录

社会安全个人账户（my Social Security）可查看收入记录和福利估计。发现漏记或异常时，保存工资税表及相关证明，按社会安全局（SSA）的纠错指引处理。

**直接办理：** [SSA：my Social Security](https://www.ssa.gov/myaccount/) · [SSA：Review Your Earnings Record](https://www.ssa.gov/prepare/review-record-earnings) · [SSA：How Do I Correct My Earnings Record?](https://www.ssa.gov/faqs/en/questions/KA-02603.html) · [SSA：Office Locator](https://secure.ssa.gov/ICON/main.jsp)。优先使用当前网页与在线账户；需要纸质说明时再从 SSA Publications 获取最新版本。

账户中的估计不是保证支付的金额，建立账户也不等于已符合某项福利资格。使用官方入口完成身份验证，并保存独立于手机的恢复方式。

## 11. 护照与海外协助要按身份区分

美国护照事务可从[USA.gov 护照入口](https://www.usa.gov/passport)进入国务院办理渠道。美国公民的海外领事协助，与外国公民的美国签证、移民申请不是同一类业务。

截至 2026-09-21，国务院当前公布的 U.S. passport processing times 为：

- **Routine：4–6 weeks**
- **Expedited：2–3 weeks**，另收 **$60** expedite fee
- **Urgent travel：** 需要在 **14 calendar days** 内国际出行时，可按资格预约 passport agency / center；若还需要 foreign visa，相关 agency appointment 标准可覆盖 **28 calendar days** 内的签证需要。

这些 processing times **不包括邮寄时间**。国务院提示申请寄到 passport agency / center 可能另需最多约 2 周，印好后寄回也可能另需最多约 2 周；因此“4–6 weeks”不能直接当作从寄出申请到拿到护照的总时长。Passport agency appointment 也不是保证有位，第三方收费“代抢 appointment”不是国务院官方服务。

**办理 / 查询：** [国务院：U.S. Passports — current processing times](https://travel.state.gov/content/travel/en/passports.html) · [国务院：Get Your Processing Time](https://travel.state.gov/en/passports/apply/help/processing-time.html) · [国务院：Where to Apply / urgent travel](https://travel.state.gov/en/passports/apply/help/where-to-apply.html) · [国务院：Passport Application Status](https://passportstatus.state.gov/) · [国务院：International Travel](https://travel.state.gov/)。

旅行前根据自己的国籍、旅行证件和目的地，保存相应使领馆联系方式。不要因为持有美国居留身份，就默认所有美国公民服务都适用；护照处理时间会随需求变化，真正申请时重新看 current page。

## 12. REAL ID 已经进入执行阶段

从 **2025-05-07** 起，TSA 已开始执行 REAL ID 要求。**18 岁及以上**旅客搭乘美国境内商业航班时，如果使用州政府签发的驾照或身份证作为机场安检证件，该证件通常需要是 REAL ID-compliant；TSA PreCheck 旅客也不例外。

这不等于“没有 REAL ID 就绝对不能飞”。TSA 仍接受多种其他身份证件，例如：

- U.S. passport 或 passport card；
- foreign government-issued passport；
- DHS Trusted Traveler card（例如 Global Entry）；
- U.S. military ID 等 TSA current acceptable-ID list 中的证件。

如果只带了 non-REAL-ID state license 且没有其他 acceptable ID，可能需要额外 identity verification / screening，也可能最终无法进入 checkpoint。不要把机场工作人员“以前放过一次”当作以后也能使用的规则。

**直接核对：** [TSA：REAL ID](https://www.tsa.gov/real-id) · [TSA：Acceptable Identification at the Checkpoint](https://www.tsa.gov/travel/security-screening/identification) · [USA.gov：REAL ID](https://www.usa.gov/real-id)。申请 REAL ID 的材料、预约和费用仍按本人州 DMV / MVC 的当前规则办理。

## 13. 消费纠纷先分行业

[USA.gov 消费投诉目录](https://www.usa.gov/consumer-complaints)按商品、金融、住房、交通等分类。先向商家或服务机构明确提出事实和诉求，同时查看信用卡争议、保险申诉或监管投诉是否有独立期限。

**常用投诉入口：** [CFPB：金融产品与服务投诉](https://www.consumerfinance.gov/complaint/) · [FTC：ReportFraud](https://reportfraud.ftc.gov/) · [USA.gov：州消费者保护办公室](https://www.usa.gov/state-consumer)。

商业评价或民间调解平台不能替代监管与法院程序。监管投诉也不保证返款，不要为了等待处理而错过其他救济期限。银行与信用卡纠纷见[第 16 章](16-银行信用卡消费者纠纷与诈骗.md)。

## 14. 升级处理时，区分三种路径

| 目的 | 要查的程序 |
|---|---|
| 查询进度、补材料、处理服务问题 | 原机构客服、主管、申诉专员或适用的协助渠道 |
| 反对正式决定 | 通知中列明的复议、听证、上诉或司法救济程序及期限 |
| 举报欺诈、浪费、滥权等不当行为 | 相关监察长办公室（OIG）的受理范围 |

[USA.gov](https://www.usa.gov/government-agency-complaints)建议先联系原机构，必要时寻求民选代表办公室协助；[监察长体系](https://www.ignet.gov/content/report-government-fraud)则提供不当行为举报入口。不要把监察长办公室当成所有办事迟延的通用上诉机关。

**找人：** [House.gov：按 ZIP code 查联邦众议员](https://www.house.gov/representatives/find-your-representative) · [Senate.gov：查本州联邦参议员](https://www.senate.gov/senators/senators-contact.htm)。

议员办公室可能协助查询，但不能保证结果。提交协助请求之前核对隐私授权要求；不要假定询问、投诉或议员协助会暂停正式期限。

## 15. 搬家需要分别更新记录

邮政转寄与各机构的地址记录应分别处理。列出车辆管理、税务、银行、保险、雇主、职业执照和适用的移民事务，逐项确认要求与完成回执。

**搬家入口：** [USPS：官方 Change of Address](https://moversguide.usps.com/) · [IRS：地址变更](https://www.irs.gov/faqs/irs-procedures/address-changes/address-changes) · [USCIS：Change of Address](https://www.uscis.gov/addresschange)。

选民登记只适用于具备资格的人员，不是所有移民都应办理。具备资格者可从 [Vote.gov](https://vote.gov/) 查本州官方登记方式；移民地址义务及具体期限须查对应机构，不在本章用一个规则概括。使用[搬家清单](../checklists/move-checklist.md)记录完成情况。

## 16. 一次咨询要带回可执行的信息

先问：“这件事是否由你们处理？正式办理入口、所需材料和期限在哪里？”随后记录工单号、日期、部门、答复、下一步和复查日期。

如果被转介，核实接收单位确实受理；重要问题请求书面指引。公开反馈时遮盖证件、完整案号和个人联系方式。

**本项目方法论：** 一次咨询至少带回“主管机构 + 正式入口 + 材料 + deadline + case / confirmation number”；没有这些信息就继续追问或核验 [USA.gov](https://www.usa.gov/)。

## 最小执行集与核验范围

- [ ] 已保存当地紧急与非紧急入口。
- [ ] 适用的税务、社会安全、车辆及地方服务账户可登录和恢复。
- [ ] 重要文件有主管机构、办理期限与回执记录。
- [ ] 能区分客服投诉、监管举报与正式上诉。
- [ ] 搬家后分别确认各机构地址记录。
