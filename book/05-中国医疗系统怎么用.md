# 05 — 中国医疗系统怎么用

长期在海外生活后，回中国就医需要重新确认预约、身份登记、支付和后续照护。不要假设美国保险、转诊方式或患者账户能够直接沿用。本章以中国内地为范围，港澳台应另查当地制度。

## 1. 紧急情况先拨 120

**优先级：** P0

中国内地医疗急救拨 **120**。先报告地点、楼层、进入方式、患者反应与呼吸情况，再按调度指令行动。怀疑严重急症时，不要先比较专家排名或等待普通门诊号。

急救识别和训练边界见[第 03 章](03-紧急情况与急救.md)。

**官方原文 / 旅行核对：** [国家卫生健康委：《院前医疗急救管理办法》](https://www.nhc.gov.cn/fzs/c100048/201808/6878dddd2a3d48c59de1c43a6c68423d.shtml)明确全国院前医疗急救呼叫号码为 120，并要求急救中心（站）24 小时受理 · [美国国务院：中国旅行信息](https://travel.state.gov/en/international-travel/travel-advisories/china.html)可作为境外旅行者的补充入口。

## 2. 非急救转运单独安排

出院接送、常规复诊和非紧急转院，应先向医院询问适用的非急救转运服务，确认患者是否适合该方式、是否需要医护陪同、供氧或其他设备。

非急救并不等于没有医疗风险。患者状况突然恶化时重新联系医疗或急救人员，不要因为已经预订接送就坚持原计划。各地服务与收费不同，本章不提供全国统一号码。

**本项目实务建议：** 非急救转运先从出院医院、接收医院或当地卫健部门确认合规服务与患者适配性；不能把普通网约车、普通救护车和医疗转运视为同一种服务。急症仍回到 120。

## 3. 普通就诊先确认当地入口

可从社区卫生服务中心、家庭医生、综合医院普通门诊或所需专科入手。具体哪条路径合适，取决于症状、既往诊断、当地资源及医院要求。

本章不把中国概括成“只能直接去大医院”，也不把美国概括成“看任何专科都必须转诊”。先向当地机构确认怎样挂合适的科室；无法确定时利用医院官方导诊。

**查医院 / 医生资质：** [国家卫生健康委：信息查询](https://www.nhc.gov.cn/wjw/sjcx/sjcx.shtml) · [卫健委政务服务平台：查信息](https://zwfw.nhc.gov.cn/cxx/)。可查询医院执业登记、执业医师、执业护士及部分专项机构；具体挂号仍使用医院自己的官方网站、App、公众号 / 小程序或现场渠道。

## 4. 医院等级不能替代具体能力判断

选择医院时，除了等级与声誉，还应考虑相关专科、急救能力、距离、可预约时间和复诊便利。普通问题不必自动升级为跨城寻找最知名医院。

复杂或重大诊断可请当前医生解释转诊需要。不要仅凭宣传中的“国际”“高端”或专家头衔判断治疗质量。

**核验入口：** [国家卫生健康委：医院执业登记 / 医卫人员查询](https://www.nhc.gov.cn/wjw/sjcx/sjcx.shtml)。专项能力还可从卫健委公开的器官移植、辅助生殖、产前诊断等机构名单核对。

## 5. 私下建立常用医院索引

| 场景 | 建议记录 |
|---|---|
| 日常就诊 | 机构、科室、官方预约入口、所需证件 |
| 紧急就医 | 附近急诊位置、进入方式、现场接应人 |
| 父母长期照护 | 常用医生、病历位置、下一次复诊及备用联系 |

这是一份私人安排表，不应在公开仓库填写真实姓名、住址、病史或电话号码。

这张表方便需要时联系医院，不用于给医院排名。机构资质从[国家卫健委查询入口](https://www.nhc.gov.cn/wjw/sjcx/sjcx.shtml)核对，具体挂号和急诊入口用医院官方渠道。

## 6. 出发前测试预约与身份登记

提前确认医院官方应用或小程序能否登录、手机号是否可接收验证码、就诊人证件是否仍有效，以及历史病历是否在同一账户下。

**互联网医疗背景：** [国家卫健委：关于进一步优化“互联网+医疗”服务的公开答复](https://www.nhc.gov.cn/wjw/jiany/202507/909fae6633034bedabb35046d5400b6b.shtml)说明互联网医院和互联网诊疗已纳入准入与监管框架；具体能否初诊、复诊、开药和医保支付仍以医院及当地政策为准。

证件更换、姓名拼写或身份类型变化，应问医院如何合并记录，不自行用另一人的身份挂号。不会使用手机的家人，应另问电话、现场或人工协助渠道。

**预约原则：** 优先从医院官网、官方公众号 / 小程序或当地卫健部门入口进入；国家卫健委已长期推动预约诊疗和互联网医疗，但具体挂号渠道仍由地区和医院决定。

## 7. 医保资格、异地结算与备案分别问清

从[国家医疗保障局官网](https://www.nhsa.gov.cn/)及参保地医保部门寻找官方渠道，再确认自身参保状态、待遇、就医地和医院是否支持所需结算。

**直接办理 / 查询：** [国家医保服务平台](https://fuwu.nhsa.gov.cn/) · [国家医保服务平台 App / 小程序指南](https://www.nhsa.gov.cn/art/2025/2/15/art_14_15697.html) · [国家政务服务平台：跨省异地就医备案](https://gjzwfw.www.gov.cn/col/col885/) · [国家医保局：跨省异地就医直接结算公共服务信息](https://www.nhsa.gov.cn/art/2023/10/20/art_114_11408.html)。

不要从“可以打开医保应用”推断保障有效，也不要从“医院能刷医保”推断自己的全部费用可以报销。是否需要备案、哪些材料可用于手工报销、办理期限是什么，应向实际经办机构核实。

截至 2026-09-21，国家医保局对跨省异地就医的当前公开说明比旧攻略更宽，但仍不是“全国完全一样”：

- 异地就医备案材料和流程已进一步统一，并可通过国家医保服务平台 App / 微信小程序等渠道跨省办理；
- **允许在跨省出院结算前补办备案**；若已自费出院，再补备案后能否手工报销及待遇标准，仍按参保地规定；
- 跨省异地长期居住人员办理备案后，可按现行政策在**备案地和参保地双向享受医保待遇**，但具体报销政策、定点范围和备案变更规则仍由参保地落实；
- 当前跨省直接结算已覆盖住院、普通门诊，并扩展到 **10 种门诊慢特病**。这 10 种为：高血压、糖尿病、恶性肿瘤门诊放化疗、尿毒症透析、器官移植术后抗排异治疗、慢性阻塞性肺疾病、类风湿关节炎、冠心病、病毒性肝炎、强直性脊柱炎；
- 要享受门诊慢特病跨省直接结算，通常仍需先按**参保地**规定完成相应门诊慢特病待遇资格认定，并选择已开通相应病种直接结算的跨省联网定点机构。参保地没有把某病种纳入本人门诊慢特病待遇时，不能因为就医地支持该病种就自动获得同样待遇。

因此实际操作顺序仍是：**查本人参保资格 → 必要时备案 → 查本人门慢特资格 → 查就医地联网定点机构 / 病种 → 到院主动说明跨省参保身份 → 保存结算凭证。**

**当前政策说明：** [国家医保局：2026-05-27 跨省异地就医直接结算最新公开说明](https://www.nhsa.gov.cn/art/2026/5/27/art_14_20753.html) · [国家医保局：10 种门诊慢特病跨省直接结算攻略](https://www.nhsa.gov.cn/art/2024/12/1/art_52_14919.html) · [国家医保局 / 财政部：跨省异地就医直接结算通知](https://www.nhsa.gov.cn/art/2022/7/26/art_104_8629.html)。

## 8. 基本医保与商业保险分别核对

先确定本次使用基本医保、单位补充保障、商业医疗保险、国际医疗保险还是自费。向对应支付方询问：是否限定医院或门诊类型，是否需要事先授权，能否直接结算，先垫付时需要哪些票据和报告。

保存费用明细、发票、病历和支付凭证。不要默认美国医疗保险承担中国就医费用；应向美国计划另行确认境外保障和申报流程。

**美国保险反向核对：** [State Department：境外健康与就医](https://travel.state.gov/content/travel/en/international-travel/before-you-go/your-health-abroad.html) · [Medicare：美国境外医疗保障](https://www.medicare.gov/coverage/travel-outside-the-u.s.)。商业保险仍以本人计划文件 / 会员网站为准，并单独核对境外医疗与医疗转运。

## 9. 特需与国际门诊要问服务能力

特需或国际门诊可能提供预约、语言、隐私或结算方面的便利，但具体项目由机构决定。问清急症、住院、重症监护、复杂手术和夜间情况如何处理，必要时转到哪里。

比较医疗机构时，应核对诊疗能力、后续照护安排与费用。

**核验入口：** [国家卫健委：医院 / 医卫人员信息查询](https://www.nhc.gov.cn/wjw/sjcx/sjcx.shtml)。所谓“国际 / 特需”不是统一能力等级，具体床位、ICU、手术与转诊能力直接向医院确认。

## 10. 用一页摘要帮助医生快速理解

准备症状时间线、已经完成的检查、现用药与过敏、手术史、本次主要问题，并附关键原始报告。不要用大量无序手机截图代替病史说明。

**病历取得依据：** [国家卫健委《医疗机构病历管理规定（2013 年版）》解读](https://www.nhc.gov.cn/zwgk/jdjd/201312/e26a5dc4bee8411e92352b0e7a5e02fd.shtml) · [《医疗纠纷预防和处理条例》](https://www.nhc.gov.cn/wjw/xwdt/201808/b2b4ee8f65534257a998b5f5ba938701.shtml)，后者明确患者有权查阅、复制规定范围内的病历资料。

不确定的诊断写明“曾怀疑”或“待确认”，不要在翻译时把它变成确诊。

## 11. 影像尽量带原始文件和报告

预约前询问医生是否需要原始医学影像文件（DICOM）、云影像权限、光盘或纸质报告，并确认访问期限。截图可能不足以重新阅片。

不同机构支持的方式不同，不必为了形式齐全重复检查。资料包结构见[第 06 章](06-医疗记录药物与跨境Continuity.md)。

**国内机构 / 医生资质核验：** [卫健委政务服务平台：查信息](https://zwfw.nhc.gov.cn/cxx/)。

## 12. 检验结果保留单位和参考范围

跨境交接时提交完整报告，保留日期、单位、参考范围及检测方法等信息。不要只抄一个数值或擅自改成另一国常用单位；需要换算时由接诊团队核对。

**获取记录：** 美国接诊时可通过 [HHS：获取个人病历](https://www.hhs.gov/hipaa/for-individuals/medical-records/index.html)取得 / 交接病历。

## 13. 药物清单以通用名为基础

列出通用名（generic name）、商品名、剂型、规格、实际剂量、频率和用途，并保留原包装或清晰照片。品牌名相似不代表相同药物，名称相同也不保证规格和释放方式相同。

**核对美国药品名称 / 标签：** [药品说明书数据库（DailyMed）](https://dailymed.nlm.nih.gov/dailymed/) · [FDA：个人用药记录表](https://www.fda.gov/media/73856/download)。中国药品则以实际包装、说明书和医生 / 药师核对为准。

## 14. 药物替换请医生或药师核对

跨境取得药物前，明确有效成分、剂量、剂型和服法，尤其留意缓释与普通制剂差别。不要自行替换抗凝、精神科、抗癫痫或其他需要密切监测的药物。

没有找到熟悉品牌时，先联系专业人员，不自行停药、加量或把多种产品拼成“等效剂量”。携药入境另查目的地规定。

**继续看：** [FDA：仿制药基础知识](https://www.fda.gov/drugs/generic-drugs/generic-drug-facts) · [药品说明书数据库（DailyMed）](https://dailymed.nlm.nih.gov/dailymed/)；是否可替换到另一剂型 / 强度仍由医生或药师按具体药物判断。

## 15. 抗生素按诊疗需要使用

抗生素（antibiotics）不能治疗病毒感染。不要因容易买到、过去曾用过或家里有剩药就自行服用，也不要与他人分享处方。

已开药时按医生指示使用；出现副作用或对疗程有疑问，联系医生，不把“必须吃完任何剩药”或“好一点就停”当作通用规则。

**继续看：** [CDC：抗生素使用与耐药性](https://www.cdc.gov/antibiotic-use/about/index.html) · [国家卫生健康委：合理用药 / 抗微生物药物相关政策可从官网检索](https://www.nhc.gov.cn/)。本节引用 CDC 仅支持通用用药安全原则，不用于证明中国药店或处方监管细节。

## 16. 跨境牙科与择期治疗先安排随访

比较价格与预约便利时，把复诊次数、恢复期、并发症处理、旅行限制和资料转交一起计算。种植牙、正畸和手术等长期项目尤其要问：回到另一国后谁接手、原团队如何提供记录、紧急问题在哪里处理。

先取得完整方案，再安排跨境旅行；不要只按首次治疗价格作决定。

**旅行医疗参考：** [CDC Yellow Book：境外就医](https://wwwnc.cdc.gov/travel/page/medical-tourism)。CDC 特别提醒跨境择期医疗要考虑后续跟进、感染 / 并发症和返程后的连续性照护。

## 17. 康复方案需要双向交接

物理治疗（physical therapy，PT）或其他康复在两地衔接时，准备诊断、手术限制、已有训练方案和当前目标。由新团队评估后调整负荷，不把旧动作表当作永久处方。

疼痛、功能或神经症状变化时重新评估，不为了维持训练进度强行继续。

**本项目实务建议：** 把康复诊断、限制、当前练习和目标当作转诊摘要的一部分；美国侧病历取得与传送入口见 [HHS：获取个人病历](https://www.hhs.gov/hipaa/for-individuals/medical-records/index.html)。

## 18. 父母需要现场支持

在父母知情与授权下，整理常用医院、用药、医保和紧急联系，并安排当地能够接应的人。远程能登录应用不能替代有人陪同、取药或接应救护车。

同时尊重父母的自主决定与隐私，不能仅为方便子女而无限共享医疗资料。

以上是家庭照护安排。医院与医保办理可从国家卫健委和[国家医保服务平台](https://fuwu.nhsa.gov.cn/)核对；家庭授权与隐私边界按本人同意和机构要求处理。

## 19. 出院时确认下一步

离院前询问出院摘要、诊断、用药增减、操作或手术记录、待出的病理或检验结果，以及复诊日期和需要提前求助的情况。

**复制病历：** [《医疗纠纷预防和处理条例》第 16 条相关页面](https://www.nhc.gov.cn/wjw/xwdt/201808/b2b4ee8f65534257a998b5f5ba938701.shtml)列出患者可查阅 / 复制的门诊病历、住院志、医嘱、检验、影像、病理、手术与护理等资料；实际申请路径问医院病案室 / 医务部门。

明确谁负责查看尚未出齐的结果。回美国继续治疗前，向接诊机构确认翻译和资料格式要求。

**跨境交接参考：** [HHS：获取个人病历](https://www.hhs.gov/hipaa/for-individuals/medical-records/index.html)说明美国患者取得病历副本的一般权利；中国侧具体病历复制 / 调取方式按就诊机构和当地规则办理。

## 20. 最小执行集

- [ ] 保存 120，知道所在地急救进入方式。
- [ ] 确认日常就诊与急诊入口。
- [ ] 测试实名预约、证件和手机号。
- [ ] 向实际支付方确认保障、结算和票据要求。
- [ ] 准备中英用药摘要、病史及原始报告。
- [ ] 跨境治疗有随访、续药与并发症预案。
- [ ] 父母有知情同意下的现场接应安排。
