# 18 — 中美双栖生活基础设施

两地生活的准备，不是多装几个应用，而是确认在需要时能完成身份核验、联系、付款、就医和授权交接。长期不用的号码、账户和文件，最容易在紧急时才暴露问题。

本章是一份维护框架。具体办理规则分别见政府办事、医疗、税务与文件章节，避免把摘要当成完整操作依据。

## 1. 两地各列出最低需要

| 事项 | 在美国确认 | 在中国确认 |
|---|---|---|
| 身份与文件 | 适用的旅行、居留、工作及办事证件 | 本人身份可用的证件及更新方式 |
| 通信 | 日常号码、备用联系与账户恢复 | 号码、验证信息与异地恢复 |
| 支付 | 日常银行、付款与应急备用 | 可用支付方式、限额与线下替代 |
| 医疗 | 就医、保险、药物与急诊 | 就医、医保或自费、病历与接应 |
| 住宅与家人 | 进入住所及突发事务联系人 | 当地接应、房屋管理及必要授权 |

不要求两地复制同样的产品；按停留频率、身份和实际责任安排。

**两地总入口：** [美国政府办事入口（USA.gov）](https://www.usa.gov/) · [国税局个人账户（IRS Online Account）](https://www.irs.gov/payments/online-account-for-individuals) · [移民局在线账户（myUSCIS）](https://my.uscis.gov/) · [国家政务服务平台](https://gjzwfw.www.gov.cn/) · [国家社会保险公共服务平台](https://si.12333.gov.cn/) · [国家医保局](https://www.nhsa.gov.cn/)。

## 2. 重要手机号要主动维护

**优先级：** P1

确认号码费用、实名记录、漫游接收验证信息及补换卡要求。长期离境前向运营商了解在海外遗失设备时如何恢复，不能假设所有 SIM 卡或电子卡（eSIM）都能远程补发。

更换号码前先列出绑定它的银行、医院、政务及通信账户，按机构流程迁移。不要等旧号码失效后再找绑定清单。

**美国号码安全参考：** [FTC：手机卡转移诈骗](https://consumer.ftc.gov/consumer-alerts/2019/10/sim-swap-scams-how-protect-yourself)。中国号码的实名、补卡和海外漫游规则则直接查实际运营商当前官方说明。

## 3. 不让所有恢复都依赖微信或一部手机

保存银行、运营商和政务机构的独立官方联系入口。重要材料导出到受保护的资料系统，备份恢复码和可用的备用登录方式。

请可信联系人知道紧急时去哪里找资料，但不应借此默认他们有权使用所有账户。数字访问与法律授权分别准备，见[第 15 章](15-网络安全与身份盗窃.md)。

**数字恢复参考：** [CISA：网络安全日常防护](https://www.cisa.gov/secure-our-world) · [Apple：遗产联系人](https://support.apple.com/en-us/102631) · [Google：闲置账户管理工具](https://support.google.com/accounts/answer/3036546)。

## 4. 政务咨询与紧急求助分开

中国大陆非紧急政务问题可查目标地区 12345，报警、火警和医疗急救则分别使用当地紧急入口。异地拨打和网络受理方式应提前核实。

热线服务的分工与受理边界见[第 12 章](12-中国政府与办事入口.md)。不要在现场发生危险时等待普通政务工单处理。

**中国办事入口：** [国家政务服务平台](https://gjzwfw.www.gov.cn/) · [全国 12315 平台](https://www.12315.cn/)；紧急医疗仍使用 120。

## 5. 消费纠纷准备清楚材料

中国市场监管领域投诉举报可使用全国 12315 等公布渠道；美国按行业找发卡行、消费者保护或其他主管机构。保存合同、支付、交付与沟通记录。

两地都不应把“已投诉”当作自动退款或其他期限暂停。入口和程序分别见第 12 章及[第 16 章](16-银行信用卡消费者纠纷与诈骗.md)。

**直接投诉：** 中国市场监管事项用[全国 12315 平台](https://www.12315.cn/)；美国金融产品用[CFPB：提交消费者投诉](https://www.consumerfinance.gov/complaint/)，一般诈骗用[联邦贸易委员会诈骗举报（FTC ReportFraud）](https://reportfraud.ftc.gov/)。

## 6. 跨境文件先问接收机构

确认用途、签发机关、认证副本、公证、附加证明书（Apostille）和翻译要求。公约适用时，附加证明书简化认证环节，但不保证文件内容和授权一定被接收。

具体路线见[第 19 章](19-文件公证Apostille与跨境授权.md)。不要仅凭旧攻略沿用一整套领事认证程序，也不要把所有跨境材料一律送去认证。

**跨境文件入口：** [HCCH：附加证明书公约](https://www.hcch.net/en/instruments/conventions/specialised-sections/apostille) · [U.S. State Department：文件认证](https://travel.state.gov/en/replace-certify/authenticate-documents.html) · [中国领事服务网：附加证明书](https://cs.mfa.gov.cn/zggmcg/fjzms/)。

## 7. 停留和工作模式改变时复查税务

中国税务居民判断不能只看 183 天，美国也可能涉及联邦、州及地方规则。远程工作、房屋与家庭联系变化，应完整告知熟悉两地事务的专业人士。

记录实际停留与工作地点，不用名义请假或付款账户所在地替代事实。基础区别见[第 14 章](14-美国税务与State-Residency.md)，具体跨境问题见[第 38 章](38-中美跨境税与Work-from-Abroad.md)。

**税务入口：** [IRS：跨境纳税人资料](https://www.irs.gov/individuals/international-taxpayers) · [国家税务总局](https://www.chinatax.gov.cn/) · [自然人电子税务局入口：从税务总局“纳税服务”进入](https://www.chinatax.gov.cn/)。

## 8. 医疗信息能跨境交接

维护药物通用名、剂量、过敏、重要诊断、手术和近期治疗摘要；需要时准备准确的双语版本。影像既要有报告，也应询问接收医院所需的原始格式。

药品能否携带或在目的地获得需单独核对，不能因有处方就推定任何国家都允许入境。准备步骤见[第 06 章](06-医疗记录药物与跨境Continuity.md)。

**携药入口：** [CDC：携药出境](https://wwwnc.cdc.gov/travel/page/travel-abroad-with-medicine) · [美国国务院：Country Information](https://travel.state.gov/content/travel/en/international-travel/International-Travel-Country-Information-Pages.html)。

## 9. 父母照护要单独安排

自己的中国银行和通信能使用，不等于父母出事时有人到场。确认本地接应人、备用人、病历药物、住所进入方式、付款和必要授权。

现场人员先联系适当救援，不能等海外子女回话才启动。详见[第 20 章](20-父母养老与远程照护.md)。

**美国老人照护资源：** [老年照护服务查询（Eldercare Locator）](https://eldercare.acl.gov/) · [NIA：照护安排](https://www.nia.nih.gov/health/caregiving)。中国侧则从父母实际居住地的社区、街道、医院和养老服务官方入口建立本地联系人。

## 10. 文件索引只记录必要信息

| 文件类别 | 原件保管位置 | 可合法取用的人 | 接收机构要求 | 下次复核条件 |
|---|---|---|---|---|
| 身份与旅行证件 |  |  |  |  |
| 出生、婚姻与学历文件 |  |  |  |  |
| 授权与财产文件 |  |  |  |  |
| 医疗摘要 |  |  |  |  |
| 税务和资产记录 |  |  |  |  |

这是空白模板。填好的表格属于私人资料，不上传公共仓库或公开反馈区。

**本项目方法论：** 索引只记录“在哪里、谁可合法取得、接收方需要什么”，不复制密码、完整证件号码或敏感原件。数字安全参考 [CISA：网络安全日常防护](https://www.cisa.gov/secure-our-world)。

## 11. 支付有备用方式

按实际可用条件安排备用卡、适量应急现金或其他合法付款路径。确认手续费、限额、设备依赖和身份核验，避免所有手段同时依赖唯一手机。

备用方式不必复杂。跨境汇款提前确认资金来源、用途及申报，不借名或拆分规避要求，见[第 13 章](13-高收入家庭财务Operating-System.md)。

**美国金融机构核验：** [受保存款机构查询（FDIC BankFind）](https://banks.data.fdic.gov/bankfind-suite/bankfind) · [证券投资者保护组织会员查询（SIPC Member Search）](https://www.sipc.org/list-of-members)；跨境税务报告另看 [境外金融账户申报（FinCEN FBAR）](https://www.fincen.gov/report-foreign-bank-and-financial-accounts)。

## 12. 用小规模演练代替只看应用图标

出行前及定期复查时，测试正常登录、读取必要文件、联系备用人和查看恢复路径。涉及真实交易时仅按实际需要操作，不为测试制造不必要的资金流。

演练的结果应具体：哪个入口失败、需要什么材料、谁处理、何时完成。更新设备、号码或证件后加查一次。

**建议测试的几个入口：** [国税局个人账户（IRS Online Account）](https://www.irs.gov/payments/online-account-for-individuals)、[移民局在线账户（myUSCIS）](https://my.uscis.gov/)、[国家政务服务平台](https://gjzwfw.www.gov.cn/)、[国家社会保险公共服务平台](https://si.12333.gov.cn/)。只做正常登录 / 恢复测试，不为了演练制造虚假交易。

## 13. 优先维护关键连接

备份重点是身份、通信、资金、医疗记录与可信人员，而不是两边购买相同服务。给每项维护安排负责人和触发条件，取消没有作用的重复订阅。

任何一项长期无法恢复时，先安排可用替代路径，再考虑是否需要回国到场办理。

**本项目方法论：** 优先级按“身份 → 通信 / 恢复 → 资金 → 医疗 → 本地接应”排序，而不是按应用数量。具体官方入口见本章各节。

## 14. 跨境事务卡住时，把“办不了”变成可追踪案件

文件被退、汇款被 hold、手机号失效、本人不能到场时，先记录具体机构与业务、提交日期、退件／拒绝原文、case number、缺件、下一期限和对方给出的正式要求，再判断是身份信息、文件形式、授权、银行合规、技术访问还是地方程序问题。

很多跨境问题不是靠增加一个“万能证明”解决，而是先向最终接收机构问清它到底接受什么。逐项使用[跨境办事失败排查清单](../checklists/cross-border-problem.md)。

## 最小执行集与核验范围

- [ ] 两地紧急联系、身份与必要付款方式已确认。
- [ ] 手机、关键账户和资料恢复不依赖唯一设备。
- [ ] 父母及住宅事务有本地接应。
- [ ] 跨境文件先取得接收要求。
- [ ] 停留、工作和重大资金变化触发税务与合规复核。
