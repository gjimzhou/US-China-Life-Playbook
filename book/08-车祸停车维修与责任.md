# 08 — 车祸、停车、维修与责任

发生事故后，先处理现场安全和伤情，再跟进法定报告、保险与维修。提前保存需要联系的机构和号码；朋友在另一个州的处理经验，未必适用于你所在的地方。

## 1. 现场先保人，再保车

**优先级：** P0

观察车流、火灾和其他危险，确认伤情，必要时呼叫急救。能够安全且依法移动车辆时，移出车流，再交换资料、记录事实和联系保险。

不要把争论责任或拍照放在生命安全前面。

**事故后继续看：** [NAIC：车险理赔指南](https://content.naic.org/article/what-you-should-know-about-filing-auto-claim) · [USA.gov：州机动车办事入口](https://www.usa.gov/state-motor-vehicle-services)。前者给出现场取证和报险的一般流程；事故报告义务仍按事故所在地州规则核对。

## 2. 有严重伤情立即求助

**优先级：** P0

明显受伤、失去反应或怀疑严重急症时拨打 911，并按调度员指示行动。不要因担心保费或救护车账单延误。是否移动伤者与现场危险有关，不凭网络口诀处理。

急救详见[第 03 章](03-紧急情况与急救.md)。

**直接入口：** [美国911应急服务](https://www.911.gov/calling-911/) · [American Red Cross：急救步骤](https://www.redcross.org/take-a-class/first-aid/performing-first-aid/first-aid-steps)。

## 3. 不为了拍照停留在危险车道

能否移车应结合车辆状态、现场安全和当地要求判断。无法移车时按救援人员指令处理，不在车流中布置拍摄角度。

原稿“先拍几张照片再移车”过于绝对，本章明确以安全为先。取证只能在不增加危险的情况下进行。

**继续看：** [NAIC：车险理赔指南](https://content.naic.org/article/what-you-should-know-about-filing-auto-claim)强调先处理伤情与现场安全，再收集信息；车辆是否必须 / 可以移动仍按事故所在地州规则。

## 4. 交换必要资料，记录可确认事实

记录对方姓名与联系方式、保险信息、车牌和车辆信息，以及证人联系和警方报告编号。保存时间、地点、天气及安全条件下取得的照片。

如实配合警方和保险调查，不猜测自己不清楚的事实。不在压力下签署不理解的文件或私人和解承诺；有争议时让适当专业人员协助。

**现场信息清单：** [NAIC：车险理赔指南](https://content.naic.org/article/what-you-should-know-about-filing-auto-claim)列出对方保险、车牌、车型、证人、警员信息、事故编号、时间地点及道路状况等常用记录项。

**车内有儿童安全座椅时，事故后不要凭肉眼自行决定继续使用。** NHTSA 当前建议：**中度事故或严重事故后应更换儿童安全座椅**；轻微事故后不一定必须更换，但只有同时满足下面全部条件才属于 NHTSA 的轻微事故定义：

1. 车辆可以自行驶离事故现场；
2. 最靠近儿童安全座椅的车门没有受损；
3. 车内无人受伤；
4. 如果车辆有安全气囊，本次没有展开；
5. 儿童安全座椅没有任何可见损伤。

只要任一条件不满足，就不要按“轻微事故可继续用”理解；同时还必须遵守该儿童座椅制造商的说明，保险是否赔付更换费用也另按实际保单和理赔规则处理。

**直接核对：** [NHTSA：事故后的儿童座椅使用](https://www.nhtsa.gov/car-seats-and-booster-seats/car-seat-use-after-crash)。

## 5. 警方记录与车辆管理部门申报分开查

警方是否出警、何时需要自行申报、损失金额门槛及期限因州和事故情形而异。向当地警方或车辆管理部门（DMV）核实，不能因为警员到过现场就自动认为全部申报已完成。

**查本州 DMV / MVC：** [USA.gov：州机动车办事入口](https://www.usa.gov/state-motor-vehicle-services)。事故发生在外州时查事故所在地，而不是只看车辆注册州。

## 6. 肇事逃逸与盗车及时报警

NAIC 提醒，遇到肇事逃逸或车辆被盗，应尽快联系警方，并通知保险公司。不要追赶逃逸车辆或自行与疑似盗车者对峙。

保存报案信息，询问保险还需哪些文件，不能假设报警本身就是保险报案。

**继续看：** [NAIC：车险理赔指南](https://content.naic.org/article/what-you-should-know-about-filing-auto-claim) · [NAIC：州保险监管部门目录](https://content.naic.org/state-insurance-departments)。

## 7. 及时通知保险，不必等全部估价齐全

按保单规定报案，先提供已知时间、地点、当事人和事实。尚未取得的报告或维修资料，询问如何补交。保存理赔编号和负责人的联系方式。

不要为了“先看看多少钱”而错过通知义务，也不要把报案等同于已经确认承保。

**理赔入口：** 先使用保单、保险卡或保险公司官方应用 / 网站上的理赔渠道；对处理有争议时，从 [NAIC：州保险监管部门目录](https://content.naic.org/state-insurance-departments)找到本州消费者服务或投诉页面。

## 8. 理赔人员与私人律师角色不同

保险理赔人员（claims adjuster）负责调查和处理理赔，可能为保险公司雇员或受托人员。按保单要求配合，要求重要决定和理由以书面提供。

涉及严重伤害、诉讼或重大责任时，询问保险公司是否提供抗辩及律师，并考虑是否需要独立法律意见。不要假设每位参与者都在代表你的全部利益。

**找帮助：** [NAIC：州保险监管部门目录](https://content.naic.org/state-insurance-departments) · [ABA：律师转介目录](https://www.americanbar.org/groups/lawyer_referral/resources/lawyer-referral-directory/)。

## 9. 车身修复与机械维修分别确认

钣金喷漆、结构修复、动力系统、底盘和电子诊断可能需要不同能力。询问维修机构是否熟悉你的车型，以及哪些步骤外包、由谁负责最终验收。

**维修参考：** [FTC：汽车维修基础知识](https://consumer.ftc.gov/articles/0211-auto-repair-basics)。涉及碰撞修复时，再向制造商或品牌认证维修网络核对本车型所需设备与程序。

## 10. 按具体车型确认辅助驾驶系统校准

车辆涉及摄像头、雷达、挡风玻璃或相关部件维修时，向维修方询问制造商规定的扫描、定位和高级驾驶辅助系统（ADAS）校准要求。

不要断言每次碰撞都需要同一套校准，也不要用“警告灯没亮”替代维修记录。完工时取得实际执行项目及结果。

**技术入口：** [NHTSA：驾驶辅助技术](https://www.nhtsa.gov/vehicle-safety/driver-assistance-technologies)。是否需要维修前扫描 / 维修后扫描 / 校准仍以车辆制造商维修程序和本次维修范围为准。

## 11. 维修前取得书面估价

美国联邦贸易委员会（FTC）建议估价写明待修问题、零件及人工，并约定超过指定时间或金额前需取得批准。复杂维修可考虑第二意见，先问是否收取诊断费。

**继续看：** [FTC：汽车维修基础知识](https://consumer.ftc.gov/articles/0211-auto-repair-basics)。该页同时说明如何挑维修店、询问诊断费、取得书面估价、约定超额维修需授权，以及维修完成后取得明细维修工单。

## 12. 零件、质保和额外费用写清楚

问明使用原厂零件（OEM）、非原厂零件、再制造件还是旧件，以及适用质保、租赁要求和保险支付范围。不要简单推断非原厂件必然不合格，或保险永远必须支付原厂件。

追加维修使用书面变更确认。取车时核对维修清单、费用和未解决问题，保存质保文件。

**继续看：** [FTC：汽车维修基础知识](https://consumer.ftc.gov/articles/0211-auto-repair-basics) · [FTC：汽车质保与服务合同](https://consumer.ftc.gov/articles/auto-warranties-and-auto-service-contracts)。

## 13. 拖车后立即确认保管地点

记录拖车公司、车辆去向、保管费、提车所需文件及保险是否安排转移。核对收据和授权范围，不签空白文件。

取回车内物品或安排转场前先联系保管方，避免不了解条件便反复跑现场。收费争议按当地监管途径处理。

**查当地主管机关：** [USA.gov：州与地方政府入口](https://www.usa.gov/state-local-governments) · [USA.gov：州消费者保护机构](https://www.usa.gov/state-consumer)。拖车费率、通知、保管费和放车规则高度地方化。

## 14. 代步租车与租车损坏保障不是一回事

车险中的代步租车报销、对方保险可能承担的费用，以及信用卡针对租赁车辆损坏的保障，是不同安排。

租车前确认车型、每天和总额上限、批准期限、自付及事故维修延期如何处理，不因销售人员一句“保险会付”就延长租期。

**继续看：** [FTC：租车须知](https://consumer.ftc.gov/articles/renting-car)。信用卡租车权益则看本人发卡行当前权益指南，不能与车险租车费用报销混为一谈。

## 15. 新出现或加重的症状应重新评估

事故后如出现令人担忧或加重的疼痛、神经症状、头部受伤表现、呼吸或胸腹部问题，应联系医疗人员；怀疑急症时立即求助。

就医依据是健康需要。向医生准确说明经过和症状，不为理赔夸大，也不因现场感觉尚可而忽略后续变化。

**继续看：** [CDC：创伤性脑损伤与脑震荡](https://www.cdc.gov/traumatic-brain-injury/about/index.html) · [美国911应急服务](https://www.911.gov/calling-911/)。是否需要急诊由症状与临床判断决定。

## 16. 保存证据，谨慎公开讨论

私下保存原始照片、视频、医疗文件和通信，不随意修改或删除可能相关的材料。重大争议中，公开猜测责任、评论伤情或发布当事人信息可能增加问题；向律师询问保存与披露要求。

材料保全和披露义务依案件与州法而异，请律师确认哪些必须保留、向谁提供。

## 17. 理赔分歧要求书面理由

先与理赔人员及保险公司沟通，必要时请维修方解释分歧。要求书面决定，查看保单约定的估价或争议程序，再考虑州保险监管部门或律师。

监管投诉不一定暂停诉讼或合同期限。

**理赔争议处理：** [NAIC：车险理赔指南](https://content.naic.org/article/what-you-should-know-about-filing-auto-claim) · [NAIC：州保险监管部门目录](https://content.naic.org/state-insurance-departments)。NAIC 指南建议先要求理赔人员书面解释决定，仍有分歧时再联系州保险监管部门。

## 18. 罚单、道路收费与拖车分别处理

辨认开具机构、违规类型、车牌、日期、异议途径和期限。停车罚单、行驶违法、私人停车收费和道路通行费不可混为一谈。

通过独立找到的官方渠道核对，不直接相信短信中的付款链接。涉及驾照记分或其他后果时，在决定认罚前确认规则。

**找官方入口：** [USA.gov：州机动车办事入口](https://www.usa.gov/state-motor-vehicle-services) · [USA.gov：州与地方政府入口](https://www.usa.gov/state-local-governments)。法院罚单与私人停车账单不是同一制度，先识别开具机构。

## 19. 按制造商要求维护，定期查召回

检查轮胎、制动、灯光、雨刷、注册、适用检验和保险状态。维护周期看车型手册与使用条件，不把维修店自行推荐的每项套餐都视为必要。

召回可用 VIN / 车牌查询，注意数据库覆盖与更新限制。NHTSA 当前消费者指引说明，尚未完成维修的安全召回应尽快联系品牌经销商处理；**符合联邦免费补救条件的召回维修不应向车主收费**。但联邦免费补救有车辆年龄限制：一般要求在缺陷 / 不合规被确定时，车辆从首次售给消费者算起不超过 **15 年**；更老车辆制造商仍可能自愿免费处理，但不是所有情形都由联邦法保证。

NHTSA VIN / 车牌查询也明确说明：它通常**不会显示已经修好的召回、部分刚公布还没完全匹配 VIN 的召回、15 年以上的安全召回、某些小型 / 特殊类型制造商召回，以及制造商的普通服务活动**。所以“查询显示 0 尚未完成维修的召回”不等于历史上从未召回，也不等于制造商没有技术 / 服务活动。

如果怀疑存在安全缺陷但没有召回，可以向 NHTSA 提交安全投诉；很多调查和召回会从消费者投诉开始。

**直接查询 / 报告：** [NHTSA：车辆召回查询](https://www.nhtsa.gov/recalls) · [NHTSA：车辆安全缺陷与召回：免费补救的限制](https://www.nhtsa.gov/node/36016) · [NHTSA：报告车辆安全问题](https://www.nhtsa.gov/report-a-safety-problem) · [NHTSA：车辆调查、投诉与制造商通告](https://www.nhtsa.gov/resources-investigations-recalls)。

## 20. 车内留一张事故步骤卡

- [ ] 先确认安全与伤情，必要时拨打 911。
- [ ] 安全且依法移车；不为拍照增加危险。
- [ ] 交换必要资料，保存证人及警方信息。
- [ ] 联系保险与道路救援，记录车辆去向。
- [ ] 核对当地申报和通知期限。
- [ ] 重大伤情或法律争议联系适当专业人员。

证件保存方式按当地要求和个人隐私需要安排；公开模板不填写真实信息。

**随车入口：** [USA.gov：州机动车办事入口](https://www.usa.gov/state-motor-vehicle-services) · [NAIC：车险理赔指南](https://content.naic.org/article/what-you-should-know-about-filing-auto-claim)。保险卡、注册和事故报告要求按车辆与事故所在地核对。

## 21. 没有撞车也会进入车辆应急流程

路边抛锚、车被拖走、被加车轮锁、收到停车 / 行驶违章时，处理逻辑不同于事故理赔。先保证人不暴露在高速车流或其他危险，再确认道路主管部门 / 拖车场 / 开具通知的机关；拖车前问目的地、基础费、里程费、保管费和非营业时间费用。

找不到车时先确认是否被合法拖走，同时保留“可能被盗”的分支；收到罚单时看清开具通知的机关、应答期限、是否必须出庭，以及是否可能影响违章记分、驾照或保险。

**完整路径：** [车辆抛锚、被拖、被 boot 或收到交通罚单](../checklists/vehicle-roadside-ticket-tow.md)。
