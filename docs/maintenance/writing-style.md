# 写作与去重复标准

本记录回应2026-09-23的阅读反馈：减少正文的模板感与机器生成感。下面是后续改稿标准，不代表全书已经完成这一轮修改。

## 优先解决什么

问题不只是出现了哪些词，而是读者读完后能否更快理解自己的处境、找到下一步。事实准确、适用边界和可追溯来源优先于文风；不为追求自然口吻而删除限定条件，也不以检测器评分为验收标准。

1. **删去没有新增信息的段落。** 某节已经说明分工和权限，段末就不必再用“本项目方法论”或英文术语复述一次。来源如果支持的是权限规则，应紧跟规则；不能用官方来源替经验建议背书。
2. **让问题决定篇幅和结构。** 简单礼仪可能两句话就够；有期限和例外的税务事项需要展开。不要求每节都有原则、行动、误区、总结和同样数量的条目。
3. **把抽象名词改成具体动作。** 少说“建立家庭运行系统”“形成管理闭环”，写清楚谁联系哪家机构、要问什么、拿到什么才算办完。若记录反而增加负担，可以只保留一张纸或一份文件。
4. **经验建议给读者选择。** 社交、家庭分工和生活偏好说明适合什么情况，也容许不采用。少用无条件的“应该”“必须”；明确法律要求、急救动作和真实期限不能因此弱化。
5. **统一中文表达，保留有用英文。** 英文保留给查表、搜索、识别文件和实际沟通；首次出现用中文（English）。完整英文问法配中文解释，不把普通中文句子拆成中英碎片。
6. **把笼统免责声明集中，具体边界留在原处。** 首页和声明页解释整体定位；正文写真正改变判断的地区、身份、年龄、保单或日期条件。不在每段机械加“请咨询专业人士”，而是说明该找谁、带什么问题。
7. **案例要帮助判断，不能制造权威。** 可以写明确标为假设的情境、问法或空白表。不要编造作者亲历、客户故事、使用次数或未经证实的成功结果。

## 专业书面语与句式控制（2026-09-23补充）

自然、准确、克制，保持专业书面语。去除“AI味”应靠具体内容和清晰组织，不靠口语、俚语或刻意模仿个人腔调。

1. 直接陈述实质。少用“核心在于”“本质上”“值得注意的是”等空泛引导，明确说明问题、条件和行动。
2. 避免反复套用句式。控制“不是……而是……”“真正的……”及排比、设问的密度；有实际辨析或顺序关系时保留。不把一种模板换成另一种模板。
3. 使用准确表达。“系统、框架、闭环、赋能、抓手”等词只在确有含义时保留，优先说明谁处理、处理什么、需要哪些材料。
4. 保持专业书面语。避免“搞定、踩坑、抄作业、兜底、拉满”等随意表达，不刻意加入感叹、调侃或网络用语。对话示例可以自然，正文保持稳重。“就够了”“就好”等表达还须检查是否造成无依据的充分性承诺。
5. 严谨优先于简短。保留适用对象、地区、日期、例外、权限与证据限制；区分事实规则、专业意见和经验建议，不把“可能”润色成“必然”。
6. 结构服从内容。不强求每节都有原则、步骤、误区和总结；不重复已有信息。标题、加粗、表格和清单应有助理解或检索，必要安全提示允许在独立页面重复。
7. 尊重读者。说明判断依据和可选做法，减少无依据的命令、价值评判和安慰套话；明确义务与紧急指令仍须清楚有力。

验收标准：读者能准确理解、找到下一步，并知道建议的适用边界；文章应像经过认真编辑的实用参考书。已依据这些标准形成[下一轮定位批注](../style-annotations-next-pass.md)，第二轮落实范围与验证见[实施记录](../editorial-second-pass-2026-09-23.md)。

## 初次诊断时识别的改稿例子

| 现有写法或重复模式 | 改稿方向 | 必须保留的内容 |
|---|---|---|
| 第34章：“每项任务写 owner + backup + next step + completion evidence” | 前面的表格已经有负责人、备用方案和完成证据，这句可删除；未接手事项的提醒保留 | 谁已同意接手，不能默认为家人负责 |
| 第34章：“review timing 由事件和 capacity 决定” | 正文已有“不要求在一至四周内恢复正常”，不再重复造术语 | 不规定恢复时限；真实办事期限另行管理 |
| 第24章：多节重复“具体习惯优先于通用建议” | 章首保留总体边界，各节只写该场景真正需要确认的信息 | 邀请人数、饮食过敏、家属明确要求等不能省略 |
| “建立家庭财务操作系统”一类表达 | 按家庭实际复杂度说明需要哪些账户和资料；简单家庭允许用简单安排 | 资金可用性、授权、安全和适用税务义务 |

## 如何确认改稿有效

- 单看一节，读者能否说出下一步；若本节只是解释概念，也能明确指出它解决了什么误解。
- 删掉总结句后若没有损失信息，就不恢复；没有必要的表格、清单和加粗也同样处理。
- 让首次遇到问题的人试读，记录其找不到入口、看不懂术语或误以为必须执行的地方；朗读检查只作为补充。
- 比较修改前后事实、数字、适用条件与来源，防止语言润色改变规则含义。
- 标题改动同步处理历史锚点；网站与离线版一起检查。不为改善语气破坏旧链接。
