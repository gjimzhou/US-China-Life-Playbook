# 阅读网站旧段落链接兼容

阅读网站通过 `doc` 和 `section` 路由定位文档及段落。标题变化会改变自动生成的段落标识，因此在 `site/anchor-aliases.json` 维护已确认的旧标题到当前标题映射。

## 修改标题时

1. 保存原标题的段落标识。
2. 确认新旧段落表达同一内容，再将旧标识映射到新标识。
3. 若该段落已有更早的映射，把那些映射也直接指向当前标识；不使用多级跳转。
4. 运行网站构建和检查。不存在的目标、重复标识和冲突映射会导致失败。

不得用模糊标题匹配或当前段落序号推断历史含义。已有 `s0`、`s1` 等序号别名仍保留，但跨版本新增、删减或重排段落后可能不再表示原段落，不能据此承诺全部旧链接正确。

本轮回看稳定锚点引入版本、上次审阅基线、近期审阅版本，以及五笔仅修改标题的提交；仅登记可确认的映射。GitHub 原文页的历史标题链接不受网站映射控制。

2026-09-23起，序号别名不再按当前标题顺序重新生成；`scripts/legacy_routes.py`固定读取543c79b6版本。构建需完整Git历史。改题继续使用`site/anchor-aliases.json`，并保留所有已有别名；新增章节不虚构历史序号。无法确认的旧目标不猜测映射。离线版使用同一旧路由来源。
