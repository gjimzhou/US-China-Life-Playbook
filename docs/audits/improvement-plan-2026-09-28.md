# 2026年9月28日改进方案规则对照与实施审计

[修订方案](../maintenance/improvement-plan-2026-09-27.md) · [审计索引](README.md)

## 检查范围

对照 `AGENTS.md`、`STYLE.md`、`CONTRIBUTING.md`、`METHODOLOGY.md`、来源规范、维护工作流及当前网站实现，审计原改进提案。此次为方案与工程审阅，不是正文事实复核。

## 发现与处理

1. 原提案要求所有试点使用固定七段模板，违背按问题组织、不过度填字段的规则；改为行动与条件清楚即可。
2. 原提案多项功能已存在：高级筛选折叠、静态页、站点地图、场景路线、带小节ID的反馈入口、核验台账。修订方案明确复用，不列为新增工作。
3. 原提案另设月／季／年度周期，与现有14／30／90天、八周轮查和指定到期日机制冲突；撤回另设周期。
4. 固定五个场景重写、90天排期和五人成功率门槛没有真实需求与基线支持；撤回强制数量和工期，真实试读只保留为待实际开展的方法。
5. 保留可通过现有内容实现的改进：六个首页直接入口、自然语言搜索映射与20条回归用例、章节登记核验范围和证据入口。
6. 维护说明中仍有以提交标题触发正式发布的旧说法和分散检查命令；改为当前共享检查及手动发布入口。

## 实施边界

没有改正文或清单标题、内容ID、任务ID、医学法律税务结论、核验台账和事实核验日期。首页及下载页的版本标签随v1.3更新。既有高级筛选、收藏、清单、离线与导出功能保留。

核验展示只匹配台账的 `path`，不把章节登记范围传播到其他清单；没有记录的章节不作已审或低可信推断。部分尝试、旧完整核验和下一次复核分别呈现。页面中有“登记范围已完成核验”不代表整章专业审定。

## 验证记录

最终自动化验证以本次发布PR与GitHub Actions中 `validate` 的结果为准；正式发布还会在main提交重新执行完整共享检查。

本地专项与完整流水线的执行结果在本PR说明中记录，不以本方案中的目标代替结果。

## 仍有的限制

- 20条搜索用例由编辑选择，验证的是目标定位与回归，不代表真实用户成功率或全部查询覆盖率。
- 浏览器窄屏检查是模拟视窗，不是实体手机、Kindle或其他真实阅读器测试，继续由Issue #5跟踪。
- 未招募真实新读者试读，未执行整本PDF逐页视觉审阅。
- 未重新核验医学、法律、税务及移民事实；现有证据记录中的缺口与适用限制继续有效。
