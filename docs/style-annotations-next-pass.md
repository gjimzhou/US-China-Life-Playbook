## 编辑尺度

自然、准确、克制，使用清晰的专业书面语。去除模板化表达依靠具体内容与合理组织，不靠俚语、网络语言、聊天口吻或虚构个人经验。通俗不等于随意，专业也不等于堆砌术语。

本次按40章的开篇、候选句式和相邻段落定点审阅，并结合第04、24、34章完整试读及清单走查。不是全书逐句穷尽审阅；没有问题的句子无需强改。以下标注均有当前源文位置，属于编辑判断，不是事实错误认定。“优先”指编辑顺序，与正文P0／P1证据优先级无关。

- 改写：处理口语化、空泛、训诫或套式表达。
- 合并：删重复时保留新增条件、证据属性与来源。
- 调整结构：先解决阅读顺序，避免只换同义词。
- 保留：明确不应机械“去AI化”的句子。
- 示例文字是局部候选，并非可直接替换整个段落的审定稿；其余事实、条件、日期和链接仍须逐项保留。
