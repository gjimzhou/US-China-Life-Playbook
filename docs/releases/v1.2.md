# v1.2：中文表达与阅读工具更新

发布日期：2026-09-25。本版汇总v1.1发布后的阅读功能、内容维护和本轮中文编辑，保留v1.0、v1.1固定附件。

## 内容修订

- 完整调整第23、25、27章，分别集中家庭事务安排、日常交往与本地联系、专业服务的查询与委托。减少直译搭配、抽象管理用语、相邻复述和跨章重复。
- 统一写作规范、术语表和贡献指南：保留准确专业术语，以具体动作说明生活事务，按内容安排篇幅，避免为显得正式而增加公文化表达。
- 修改其他指定位置及行动清单标题；来源、专业条件和原核验日期保留。逐小节范围见[中文表达与章节结构修订](../audits/editorial-chinese-2026-09-25.md)。
- 纳入9月24日起的定点事实复核，继续保留未取得全文、地方及个案规则等缺口；范围见[维护台账](../../maintenance/review-registry.json)。

## 阅读功能

- 收藏与继续阅读在当前浏览器保存；内容和段落使用稳定标识，改题后旧链接仍可使用。
- 清单可逐项勾选，提供字号、行距、阅读备份与恢复。
- 新增独立分享页、按章离线保存、场景阅读路线及便于返回原阅读位置的章节目录。
- RSS用于发布重要更新；评论和邮件订阅是否可用取决于服务配置，不因发布新版自动启用。

## 版本与验证

首页、下载页、离线阅读版和构建清单标明v1.2。网站及EPUB、PDF、DOCX、HTML、Markdown、源码ZIP由同一次部署生成，固定附件保留源码提交和校验值。

本轮文风修订已在[PR #3验证](https://github.com/gjimzhou/US-China-Life-Playbook/actions/runs/36207656922)中通过Python测试、Firefox回归、全部导出及网站检查。正式发布流程会在当前发布提交上重新执行同一套部署检查，通过后才上传网站和固定附件。

仍未进行整本PDF逐页视觉审阅、所有实体阅读设备测试或真实新读者试读。版本发布不代表全书医学、法律和税务事实重新获专业审定，也不代表已消除所有文风问题。
