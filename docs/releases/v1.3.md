# v1.3：场景入口与核验记录

本版汇总v1.2之后的维护改动，并改善场景查找与核验范围展示。保留v1.0、v1.1、v1.2固定标签和附件。

本轮按[Serena 完整项目交接手册](../PROJECT-HANDOFF-SERENA.md)的核验透明度与搜索导航方向实施；不表示交接路线图的所有长期事项已完成。

## 阅读体验

- 首页新增六个直接入口：刚到美国、收到医疗账单、失业或保险中断、父母需要照护、准备回国、收到政府通知。连接已有内容，不新增统一办理规则。
- 新入口无需JavaScript也能打开独立阅读页；启用脚本时进入互动阅读，保留稳定章节及小节定位。
- 补充自然中文查询与无结果时的目录入口。通知含义不明时先进入事件索引，“保险拒赔”继续区分医疗和其他保险。准备优先级与证据筛选不改变推荐入口的性质。
- 登记章节的互动页与静态页新增“核验范围与记录”。复用现有台账，区分完整核验、部分尝试、计划复核和证据记录，不自动更新日期或为整章背书。

## 维护与兼容

- 对照写作规范、方法论、维护周期与现有功能修订改进提案，撤回强制统一清单、重复实现和固定90天排期。
- 保留正文标题、既有内容／段落／任务ID、收藏、勾选、备份、历史路径和个人下载功能。
- 纳入v1.2之后的共享构建检查、维护任务追踪、版权与发布流程维护；校正旧站点维护说明中的发布方式。
- 首页、下载页、版本文件与构建清单使用v1.3。正式工作流在同一main提交完成完整检查后，生成并上传六种固定附件与校验信息。

## 验证范围与限制

共享验证入口 `python scripts/validate.py` 包含Python单元测试、维护台账、网站与历史路由、Firefox回归、六种导出、网站检查及EPUBCheck。新增回归覆盖20条中文查询、六个直接入口、无脚本阅读、键盘与窄屏、核验信息两种页面一致性，以及部分核验不重置完整核验日期。

正式发布以本次工作流成功结果和下载清单中的源码提交、SHA-256为准。CI通过不代表全书事实获医学、法律或税务专业审定。

仍未招募真实新读者试读、完成全部实体设备检查或整本PDF逐页视觉审阅；20条编辑选定查询不代表全部搜索质量。本轮未修改事实核验日期，现有证据缺口继续保留。详见[本轮审计](../audits/improvement-plan-2026-09-28.md)。
