# v1.0：首个完整参考版

发布日期：2026-09-23。

本版面向长期在美国生活、同时与中国保持家庭和社会联系的读者，提供40章正文、40份清单目录页面（含生活事件索引），以及首页导读、免责声明、术语表、方法论和实用来源入口。

## 本版包含

- 按事件找第一步、按章节深入阅读；全文搜索、优先级与证据筛选、内容性质提示、深浅色切换和打印。
- 医疗、保险、税务、政府办事、法律文件、宠物、父母照护、家庭关系与跨境生活的准备事项及官方办理入口。
- 普通英文混用改为中文；必要术语保留中文对照，实际沟通示例保留双语。
- 网页与EPUB、PDF、DOCX、单文件HTML、单文件Markdown、源码压缩包由同一次构建生成。本次发布附件固定保存此版，网站和在线下载随后会继续更新。
- 保留旧章节与段落链接兼容；修复窄屏宽表格，支持触控和键盘横向滚动。

## 验收范围

本轮检查90份网站文档的内部链接、片段目标、历史路由和版本一致性；检查响应式网页、打印样式，并在EPUB阅读器实际打开、翻页、跳目录、查看表格和点击书内链接。

830个外链的本地与GitHub独立扫描均未发现明确404／410；受限、超时和其他HTTP警告单独保留，不算验证成功。逐项记录见仓库中的 `docs/reader-qa-2026-09-23.md`。

## 已知限制

- v1.0表示首个经过本轮验收的完整参考版，不表示覆盖所有生活情形，也不表示所有内容获医学、法律、税务或保险专业审定。
- 动态规则须结合适用年份、地区、身份与具体事实重新核对。事实规则、指南解读、经验建议和专业咨询准备应按各自性质使用；具体限制与最后核验日期保留在正文。
- 部分来源有自动访问限制；社区照护、学生隐私等尚存未取得全文核验的资料，不能据此声称全文审定。
- 实体Kindle、亚马逊转换后的电子书及iOS Safari尚未实测；未逐页检查整本PDF的分页。
- 后续继续改进文风、减少重复、更新失效入口和动态事实。本版不是对个人行动结果的保证，请交叉验证并在需要时寻求合格专业人士帮助。
