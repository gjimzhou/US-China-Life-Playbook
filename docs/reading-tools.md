# 读者工具与独立阅读页

本轮不增加收费服务或账号依赖。核心内容与现有配色保持不变。

## 读者入口

- `#view=paths`：六条编辑选择的阅读路线，不收集身份信息。配置在 `site/reading-paths.json`，绑定稳定内容 ID。
- `#view=tools`：字号、行距、备份恢复、离线入口。
- 清单页：原有 Markdown 待办项可勾选，本页计数、重置和打印。计数不是家庭管理评分或安全认证；不适用的项目可以不做。
- 每小节的“分享 / 报错”：复制稳定独立网址；支持时调用系统分享。GitHub 问题反馈会预填稳定位置和问题类型，明确需要 GitHub 账号，用户手动提交。没有伪装成免登录评论。
- `offline.html`：主动保存选择的独立章节副本，显示保存时间与正文版本，支持手动更新、删除。没有自动后台下载整站。

## 本地数据与备份

原收藏与阅读进度 key 不变。`us-china-playbook.tools.v1` 保存清单状态与阅读设置。三者不上传，也不自动跨设备同步；浏览器清除数据后可能丢失。存储读取、写入失败和检测到其他标签页更改时明确提示，不能假报保存成功。

JSON 备份包含收藏、最后阅读位置、清单状态和阅读设置。导出只是交给浏览器下载，不等于操作系统已持久保存。恢复先校验格式和最大 2 MB 文件大小，再预览数量。按类别点击恢复，避免多个 localStorage key 之间非原子写入造成“全部恢复”假成功：

- 收藏合并去重，不删除现有收藏；未找到的内容仍保留，页面提示无法定位。
- 清单完成状态按并集合并，保留已完成。失效任务 ID 不绑定给别的条目，仍保留供备份。
- 阅读位置、字号与行距要明确确认后替换。
- 损坏的现有数据不自动覆盖。请先保留原数据，排查损坏后再人工处理。

新收藏记录 `savedAt`。重要修订的 `updates/entries.json` 可填写 `affectedContentIds`，用来在相关收藏显示“收藏后有重要更新”。标题、发布日期、GUID 仍由编辑手动维护；小修、构建与部署不触发。旧收藏没有日期时不猜测“收藏后更新”，读者仍可查看订阅更新页。

## 稳定任务 ID

`site/task-ids.json` 为本轮 714 项清单分配固定 ID。查找键由稳定小节 ID 加任务 Markdown 行内容的 SHA256 前 20 位构成；值为 `t-` 加随机 12 位十六进制。

构建不自动修改身份文件。新增项必须分配新 ID；移动或措辞修改时，若仍是同一行动，把原 ID 迁移到新查找键。若行动含义改变，应分配新 ID，不能继承已完成状态。已删除任务的旧记录可保留为 tombstone，不重用 ID。不因条目顺序变化重新分配。构建缺少映射、重复 ID 或当前重复绑定均失败。

维护者可运行 `python scripts/task_identity.py` 查看缺少映射；`--assign-new` 只为新键分配 ID。使用前应先审阅是否需要迁移原 ID，不能把修改一律当成新任务。脚本不会自动推断相同任务。

## 静态网址与离线

构建为 90 份文档生成 `read/<contentId>.html`，小节使用 `#<sectionId>`。每页内含正文、目录、canonical、Open Graph 标题摘要，不依赖 JavaScript 读取正文。平台是否展示预览及何时刷新，由分享平台自身决定。

静态页的清单控件禁用；“进入互动阅读”会携带对应小节标识。不能在静态页勾选后假称保存。旧 SPA hash 链接继续可用。

Service worker 仅在读者主动保存时注册，且仅处理指定静态章节与离线阅读组件。它不缓存 SPA、统计、评论 API 或其他域请求。新副本全部存储成功后才替换旧副本；在线优先请求当前页面，断网时回退读者保存的版本。正文版本是内容指纹，不是核验日期。

离线阅读不保证浏览器永久保留；外部来源和没有主动保存的章节不能离线打开。统计目前仅覆盖互动网站的手动路由事件，独立静态页和离线页不发送统计；不能把后台数值称为所有阅读的完整计数。

## 验证

`test_tools.cjs` 覆盖清单保存/重置/刷新、损坏与额度失败、分享复制与失败回退、备份校验/重复合并、阅读设置、六条路线、手机布局、无 JS 静态正文、真实 service worker 离线保存/打开/删除。已有收藏与阅读服务回归继续执行。

`check_site.py` 检查生成页的本地链接、稳定小节锚点、元数据、离线资产和阅读路线。第三方服务的真实验收仍按 `reader-services.md`，不能用这些测试替代。
