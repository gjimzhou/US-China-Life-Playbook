## 访问统计怎么读

使用站主现有 GoatCounter 站点，统计路径以 `/US-China-Life-Playbook/` 开头。普通页面统计按照 GoatCounter 的会话规则去重；`page-open` 事件单独记录进入页面的次数，刷新或离开后返回会再次记录。同一章内锚点跳转不重复计章节打开。

章节按稳定内容 ID 区分，来自 `site/content-ids.json`。按钮事件表示尝试，不保证操作成功；末节进入视口也不证明读完。独立静态页与离线页当前不发送统计；拦截器、DNT/GPC 等可能造成漏计。访问数不是精确人数，也不等于 IP 数量。

不发送原始搜索词、邮箱、昵称、留言、收藏清单、原始查询参数或 referrer。统计后台不对本站读者公开。详见[统计维护说明](../maintenance/analytics.md)。旧 Umami 适配器保留供兼容，当前服务是 GoatCounter。

## 以后启用评论或邮件

当前代码支持配置独立评论服务及邮件订阅表单，但提供商账号、后端、审核、确认订阅与退订仍需单独配置和实际验收。无需为了现有收藏、RSS 或统计再注册新账号。

启用评论前验证审核、限流、垃圾信息处理、删除和故障回退。游客昵称不代表经过核实的身份；回复通知与全站更新订阅分开。启用邮件更新前验证确认订阅和退订，未完成时保持关闭。密码、数据库连接串和私密凭据只留在服务商后台，不进入 Git、聊天或网页。
