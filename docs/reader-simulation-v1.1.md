## 方法与限制

这是编辑者模拟首次读者的认知走查，不是真人访谈、盲测或临床／法律事实认证。没有声称真实用户耗时、成功率或主观评分。完整阅读第04、24、34章，并从首页事件索引、搜索与相关清单走查三个假设场景：宠物刚去世、医疗保险拒赔、中国父母突然住院。搜索在本地构建的v1.1网站、Firefox、390像素视口实际输入，下列结果可复现。

结论：首轮语言修改有帮助，但尚不足以宣称“首次读者容易使用”。主要障碍是口语搜索、急事入口与准备模板混用，以及行动步骤被规则说明挤到后面。应先修这些，再继续扩大文风改写。

## 三个场景走查

### 1. 宠物刚在家里去世

路径：生活事件索引 → “宠物刚刚去世，不知道遗体、火化、保险、芯片怎么办” → 宠物去世处理清单。

**能回答的问题：** 第一联系对象是日常或急诊兽医；需要说明异常情况，询问确认、暂存、运输及病理解剖；火化是否单独处理、返还什么、费用和保险通知均有对应条目。没有要求读者自己判断死因或照搬统一保存办法。

**卡点：** 夜间联系不到原兽医时，没有更显眼的下一条寻找路径。已有“急诊医院”，但读者仍需要自己理解如何查找当地可接收机构及电话确认。这里适合补办事问法，不应擅自增加通用医疗处置方法。

**语言瑕疵：** “联系 宠物火化服务方”“是否做病理解剖 是”“以及 保障何时终止”“登录 芯片登记平台”“询问 哀伤支持资源”仍有不自然空格。说明首轮未覆盖该清单的全部逐句校对。

**判断：** 从事件索引进入基本可用；口语搜索提示与细节校对仍需改。

### 2. 已看完病，收到医疗保险拒赔

路径一：搜“保险拒赔” → 付款困难清单开篇，没有直接到拒赔流程。

路径二：搜“拒赔” → 第04章第6节。

**能回答的问题：** 获取书面理由和计划条款，找保险公司确认材料及期限，联系医疗机构／医生，保留提交证据；重新编码不自动暂停正式申诉计时。规则适用边界有明确说明。

**卡点：** 在“实际操作”之前，要读初始决定、内部申诉和外部复核的多组天数及例外。刚收到拒赔的人先需要知道手上的文件是什么、现在找谁，不一定有精力先学习整个制度。信息准确与出现顺序是两件事。

**建议结构：** 先放已有操作中的三件事——找拒赔通知与截止日、核对原因与所缺资料、确认谁提交与保存凭证；随后保留完整期限说明。不能为简短删掉适用条件，也不能把一般最长时限写成个人可等待的时间。

**判断：** 找到正确小节后能用，但入口和信息顺序不通过首次使用验收。

### 3. 人在美国，父母在中国突然住院

路径：搜“父母住院”失败；事件索引 → “父母在中国突然住院、失能或需要现场接应” → 父母紧急应对计划。

**能回答的问题：** 本地接应人、病史用药、医院联系、医保、现场分工和子女返程都有内容；第20章也强调紧急救援不能等待家属赶到，子女联系不等于有代理权限。

**卡点：** 链接落到“空白模板”，开篇让每位父母填一份，先出现身份、联系、医疗、用药、财务、数字账户等字段。“今天住院时如何分工”在中后部。一个从未准备的人可能误以为必须先把表填齐，才知道现在该做什么。

**建议：** 在原页面顶部清楚区分“已经住院，现在处理”和“尚未出事，提前填写”；把已有现场分工与医院联络内容前置或提供直接锚点。保留模板与所有权限条件，不必新增整章。

**判断：** 有内容，但急事入口指向准备表，流程仍需调整。

## 优先处理清单与复测条件

1. **优先：口语检索。** “父母住院”直接找到父母应对；“医疗保险拒赔”直达拒赔程序；“保险拒赔”能分清医疗与其他保险；“宠物死了”不再同时出现相互矛盾的结果提示。既测命中，也测是否错误引导。
2. **优先：急事与准备分开。** 父母清单顶部可读到当下步骤，空白模板供之后填写；第04章拒赔段先见行动再见期限解释。
3. **随后：真实可用的表达。** 着装英文对照、小费问法、宠物清单空格；不增加未经核对的事实。
4. **随后：减少管理压力。** 第24章章末可选事项、第34章给协助者的说明与重复分工段。
5. **最后再评估结构。** 小节分组若改标题，必须保持旧锚点兼容。不要为了“像真人”重写已经清楚的说明。

复测应重新实际输入查询、打开目标页面，检查第一屏是否能看懂下一步；再确认没有删除规则条件、急救提示或来源。本次只做测试并记录，以上问题尚未修复。真正的首次读者试读仍有价值，尤其能发现编辑者已熟悉术语后看不出的困难。
