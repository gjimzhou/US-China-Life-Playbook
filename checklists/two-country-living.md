# 两地生活：每次往返都能接续的安排

> **内容性质：生活协调与专业咨询准备**
> 适用于中美反复往返、两边都有持续责任的家庭。本页帮助安排日常事务，不认定个人的入境、工作、税务或福利资格。计划改变主要居住地时，另用[长期迁居清单](long-term-relocation.md)；父母临时来美另用[探亲清单](parents-us-visit.md)。所有表格只在私人副本填写。

## 先为每个人排一张年度表

不要只记下一张机票。把每位成员的计划与实际行程分开，列出证件、停留、医疗、工作和学校各自约束的日期。伴侣、孩子和父母的身份及责任可能不同，不能共用一套判断。

| 成员与所在地区 | 预计抵离日期 | 实际抵离及凭证位置 | 必须在场的事 | 变更后通知谁 |
|---|---|---|---|---|
| 私人填写 |  |  | 复诊／上学／工作／办证等 |  |

- [ ] 每次往返后更新实际日期和工作地点，保存行程及必要凭证，不靠年底回忆补齐。
- [ ] 保留当年及前两年的在美天数记录，交给税务专业人士时同时说明身份、工作、住所与例外情况。
- [ ] 确定下一次复查日期；遇到延期、住院、雇主变化或家庭成员不同程时提前复查。

美国实质居留测试涉及当年与前两年的加权天数及例外，不是“今年不到183天就一定没有美国税务问题”。本表只收集事实，不能直接当作税务计算器。规则见[美国国税局（IRS）：实质居留测试](https://www.irs.gov/individuals/international-taxpayers/substantial-presence-test)；美国公民、绿卡持有人及两国／州层面的具体判断另见[跨境税务主章](../book/38-中美跨境税与Work-from-Abroad.md)。

## 出发前先看哪些安排会卡住

| 分开核对的事项 | 本次要取得的答案 |
|---|---|
| 能否入境、能停留多久 | 本人适用文件、此次目的、实际获准期限及更新入口 |
| 能否在当地工作 | 实际工作活动、当地资格、雇主书面许可及限制 |
| 税务与申报 | 两国及相关州需要哪些记录，由谁判断和申报 |
| 医疗与福利 | 当前资格、境外适用范围、续办及必须到场的要求 |

- [ ] 把预计离境长度与过去往返记录一起核对，不把“每隔几个月回来一次”当作维持身份的保证；按[身份与文件主章](../book/37-移民身份与文件维护.md)确认本人情况。
- [ ] 境外办公前向雇主说明所在国家、起止日期、工作内容及设备／数据使用，保存批准范围；批准后计划有变再确认。
- [ ] 整理必须本人出现的预约、学校安排、法律或行政通知，先解决冲突再订不可退款项目。

这些问题分别向主管机关、雇主、保险机构或合格专业人士确认。一项得到同意，不代表其他项也已解决。

## 两边都有人管住所和通知

离开的住所也会继续产生费用、邮件和维修需求。对留空、出租或亲友暂住分别问物业与保险机构，确认适用条件；不要只把钥匙交出去就认为完成交接。

| 留在当地的事务 | 主要／备用联系人 | 允许处理的范围 | 异常时怎样反馈 |
|---|---|---|---|
| 漏水、停暖、门锁与物业通知 |  | 进入方式、可先处理的事项 |  |
| 邮件、账单与正式文件 |  | 可查看哪些内容、怎样安全转交 |  |
| 车辆、宠物与日常照护 |  | 费用、预约及紧急接手范围 |  |

- [ ] 实测接应人能否进入住所，核对其可用时间；临时帮忙不自动产生签字或账户操作权限。
- [ ] 列出两边固定费用、扣款账户和到期日，保留够用且可动用的付款安排，避免重复服务一直扣费。
- [ ] 分别按银行、保险、税务、移民及其他机构要求维护地址与联系方式；邮寄转递不能替代各机构要求的地址报告。
- [ ] 对正式通知约定发现后及时转交，由本人确认真实期限；普通邮件可以定期整理，法律文件不能等回国再拆。

授权事项先问最终接收方需要什么文件，见[跨境授权主章](../book/19-文件公证Apostille与跨境授权.md)；住房检查见[住房与物业主章](../book/09-住房物业与Contractor.md)。

## 医疗交接跟着人走

- [ ] 两地各确认实际能接诊的医生、预约方式、保险／医保或自费安排，不只保存医院名称。
- [ ] 指定谁保存最新用药表，标明最近一次更改及开药医生；将另一地新增药物、非处方药和补充剂一并告诉接诊团队。
- [ ] 离开前处理将到期的续配与复诊，核对药物可携带量、冷藏和途中供药；具体步骤见[探亲清单的医疗与用药](parents-us-visit.md#医疗与用药先接得上)，但按本人身份重新核对进口规则。
- [ ] 记录尚未出结果的检查，由谁查看、谁联系医生、最迟何时跟进；不要让“换了国家”变成失访。
- [ ] 在患者同意范围内安排家属沟通、病历传递和紧急接应；电话可联系不等于已获医疗决定权。

[医疗记录与跨境接续主章](../book/06-医疗记录药物与跨境Continuity.md)用于整理交接；[父母紧急计划](parents-emergency.md)用于提前安排在中国的现场协助。保险名称相同或两地都有医生，都不能替代本次服务是否受理、是否承保的确认。

## 手机丢了也能联系和付款

出发前做一次实际测试：在不退出所有账户的情况下，确认备用设备、备用验证方式和恢复说明可找到；不要为了测试主动锁死账户。

- [ ] 核对两边号码的保号、漫游、收信及补卡条件，确认人在境外时怎样联系运营商。
- [ ] 至少准备一种与主手机不完全绑定的联系及付款办法，并确认本人能合法使用；由本人设置账户恢复，家属不靠共享全部密码代管。
- [ ] 将恢复说明放在受保护且不只依赖同一部手机的位置；家庭联系人表只写资料位置，不公开密码和恢复码。
- [ ] 出发前检查银行官方联系方式、交易提醒、可用额度和付款币种；账户受限时走[银行受限清单](bank-account-restriction.md)，不以借用他人身份绕过核验。

日常配置见[两地基础设施主章](../book/18-中美双栖生活基础设施.md)和[数字安全主章](../book/15-网络安全与身份盗窃.md)。

## 突然要回另一边时

先处理现场安全，再决定谁旅行。住院、照护者退出或房屋损坏，都需要在起飞之前有人接手。

| 情形 | 当天先落实 | 随后处理 |
|---|---|---|
| 父母或家人住院 | 当地急救／医院、现场联系人、患者意愿 | 病历沟通、旅行文件、家中责任接手 |
| 同行者暂时不能走 | 当地照护、住所和药物 | 停留期限、保险、改签与后续就诊分别核对 |
| 自己必须提前返程 | 孩子、宠物、房屋有人照看 | 通知雇主／学校、重排预约、更新实际行程 |
| 手机、证件或付款失效 | 用备用联系及官方挂失／求助入口 | 恢复账户、补证和必要行程调整 |

- [ ] 在可支配预算内预留临时住宿、改签和当地协助费用，不以“以后理赔”代替当下付款能力。
- [ ] 做一次桌面演练：主要接应人同时不在时，备用人能否接到电话、找到资料并在权限范围内行动？

航班与行李问题见[旅行中断清单](travel-disruption.md)，证件丢失见[证件清单](lost-wallet-documents.md)。这些是应急分工建议，不能保证入境、改签或保险获准。

## 每次抵达后与离开前各收一次尾

**抵达后：** 核对适用的入境记录，测试住所、通信和付款，确认近期就诊／学校／工作安排，通知当地与另一地联系人。本次获准停留期限与签证有效期分开记录，访客核对方法见[探亲清单](parents-us-visit.md#随身资料与抵达后的三件事)。

**离开前：** 把尚未完成的事交给具体的人，不只留一句“有事联系我”。

| 未结事项 | 负责人 | 真实期限／下次跟进日 | 凭证位置 | 怎样才算完成 |
|---|---|---|---|---|
| 私人填写 |  |  |  |  |

**这一轮完成的标准：** 人已安全抵达，实际行程已更新；两边住房、医疗、通信与付款可用；留下的每件事都有负责人及下一次跟进时间。下一趟重新核对变化，不需要每次重做所有资料。
