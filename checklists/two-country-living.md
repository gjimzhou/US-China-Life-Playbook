# 两地生活：每次往返都能接续的安排

> **内容性质：生活协调与专业咨询准备**
> 适用于中美反复往返、两边都有持续责任的家庭。本页帮助安排日常事务，不认定个人的入境、工作、税务或福利资格。计划改变主要居住地时，另用[长期迁居清单](long-term-relocation.md)；父母临时来美另用[探亲清单](parents-us-visit.md)。所有表格只在私人副本填写。

## 先为每个人排一张年度表

不要只记下一张机票。把每位成员的计划与实际行程分开，列出证件、停留、医疗、工作和学校各自约束的日期。伴侣、孩子和父母的身份及责任可能不同，不能共用一套判断。

| 成员与所在地区 | 预计抵离日期 | 实际抵离及凭证位置 | 必须在场的事 | 变更后通知谁 |
|---|---|---|---|---|
| 私人填写 |  |  | 复诊／上学／工作／办证等 |  |

- [ ] 每次往返后更新实际日期和工作地点，保存行程及必要凭证，不靠年底回忆补齐。
- [ ] 保留当年及前两年的在美天数记录，交给税务专业人士时同时说明身份、工作、住所与例外情况。
- [ ] 确定下一次复查日期；遇到延期、住院、雇主变化或家庭成员不同程时提前复查。

美国实质居留测试涉及当年与前两年的加权天数及例外，不是“今年不到183天就一定没有美国税务问题”。本表只收集事实，不能直接当作税务计算器。规则见[美国国税局（IRS）：实质居留测试](https://www.irs.gov/individuals/international-taxpayers/substantial-presence-test)；美国公民、绿卡持有人及两国／州层面的具体判断另见[跨境税务主章](../book/38-中美跨境税与Work-from-Abroad.md)。

## 出发前先看哪些安排会卡住

| 分开核对的事项 | 本次要取得的答案 |
|---|---|
| 能否入境、能停留多久 | 本人适用文件、此次目的、实际获准期限及更新入口 |
| 能否在当地工作 | 实际工作活动、当地资格、雇主书面许可及限制 |
| 税务与申报 | 两国及相关州需要哪些记录，由谁判断和申报 |
| 医疗与福利 | 当前资格、境外适用范围、续办及必须到场的要求 |

- [ ] 把预计离境长度与过去往返记录一起核对，不把“每隔几个月回来一次”当作维持身份的保证；按[身份与文件主章](../book/37-移民身份与文件维护.md)确认本人情况。
- [ ] 境外办公前向雇主说明所在国家、起止日期、工作内容及设备／数据使用，保存批准范围；批准后计划有变再确认。
- [ ] 整理必须本人出现的预约、学校安排、法律或行政通知，先解决冲突再订不可退款项目。

这些问题分别向主管机关、雇主、保险机构或合格专业人士确认。一项得到同意，不代表其他项也已解决。

## 两边都有人管住所和通知

离开的住所也会继续产生费用、邮件和维修需求。对留空、出租或亲友暂住分别问物业与保险机构，确认适用条件；不要只把钥匙交出去就认为完成交接。

| 留在当地的事务 | 主要／备用联系人 | 允许处理的范围 | 异常时怎样反馈 |
|---|---|---|---|
| 漏水、停暖、门锁与物业通知 |  | 进入方式、可先处理的事项 |  |
| 邮件、账单与正式文件 |  | 可查看哪些内容、怎样安全转交 |  |
| 车辆、宠物与日常照护 |  | 费用、预约及紧急接手范围 |  |

- [ ] 实测接应人能否进入住所，核对其可用时间；临时帮忙不自动产生签字或账户操作权限。
- [ ] 列出两边固定费用、扣款账户和到期日，保留够用且可动用的付款安排，避免重复服务一直扣费。
- [ ] 分别按银行、保险、税务、移民及其他机构要求维护地址与联系方式；邮寄转递不能替代各机构要求的地址报告。
- [ ] 对正式通知约定发现后及时转交，由本人确认真实期限；普通邮件可以定期整理，法律文件不能等回国再拆。

授权事项先问最终接收方需要什么文件，见[跨境授权主章](../book/19-文件公证Apostille与跨境授权.md)；住房检查见[住房与物业主章](../book/09-住房物业与Contractor.md)。

## 医疗交接跟着人走

**情境：在中国看过病，准备回美国继续治疗；或在美国长期服药，准备回中国住一段时间。** 不需要先把所有病历翻译完。先问下一位接诊者要哪些资料，再向原机构申请；药物则逐项查明能否携带、带多少以及带不够时怎样接上。

### 先给目的地诊所发一条能得到答复的请求

美国一侧从保险计划目录和诊所官网找实际接诊入口；中国一侧从拟就诊医院官网找预约挂号、对应科室和病案服务。已有医生优先问原团队能否继续接诊；新患者要明确说明是跨境接续，不只约“普通体检”。

> **中文：** 我将在〔日期〕从〔国家〕到达，需要继续处理〔诊断／问题〕。目前有〔药单、报告、影像〕，药按现医嘱预计用到〔日期〕。请确认是否接诊、最早时间、需先提供哪些资料和翻译、怎样安全发送，以及到诊前缺药或病情变化应联系哪里。
>
> **英文：** I will arrive from [country] on [date] and need follow-up for [condition]. I have [records] and enough medication under my current instructions until [date]. Are you accepting patients for this? What is the earliest appointment, which records or translations do you need, how should I send them securely, and whom should I contact if I run short of medication or my condition changes before the visit?

把答复写进下面这张表。**诊所愿意接诊、保险确认网络和费用、医生决定是否开方要分别落实。** 有国外处方不等于当地药房会配药，也不等于当地医生会照原方案开药。

| 接续事项 | 实际答复与证据 | 尚缺什么、谁补、何时问 |
|---|---|---|
| 目的地接诊 | 诊所、医生、日期、地址／入口、预约确认 |  |
| 付款安排 | 具体保险计划核对或诊所自费报价 |  |
| 所需资料 | 接收清单、格式、翻译要求及安全发送渠道 |  |
| 到诊前用药 | 原医生／药师给出的续配与过渡安排 |  |

### 向原机构要对材料，不只拍手机屏幕

| 材料 | 中国一侧先找 | 美国一侧先找 | 发送前检查 |
|---|---|---|---|
| 就诊／出院摘要、检验报告 | 医院官方应用、病案科；未归档部分问临床科室 | 患者门户；缺项联系病历部门（Medical Records／Health Information Management） | 姓名、日期、页码、检验单位和参考范围是否完整 |
| CT、MRI等影像 | 放射科的影像服务窗口或医院指定入口 | 放射科影像库（Radiology／Image Library） | 报告之外是否有原始DICOM图像；接诊方能否打开 |
| 当前用药与停药变化 | 原开药医生／药师，结合药品原包装 | 原开药医生／药房药物记录 | 通用名、剂型、规格、每次量、频率及停药项是否经确认 |
| 尚未出结果 | 开单／治疗团队 | 开单／治疗团队 | 谁查看、预计日期、人在境外时怎样取得解释 |

资料包可这样命名：`01-就诊摘要-日期.pdf`、`02-当前用药-日期.pdf`、`03-检验-日期.pdf`、`04-影像报告及读取说明`。原文保留，翻译另存并与原文对应；家属翻译不能冒充医院出具或认证翻译。接收方要求专业翻译时按其说明办理。

发出后请诊所确认**收到并能读取哪些文件**。若只能接收机构传真或指定平台，把接收地址／传真号从诊所官方渠道核实后交原病历部门；拿不到全部资料时，先问接诊者最低需要哪些，不自行判断可以省掉关键报告。权限、病历申请及影像格式的规则见[第06章](../book/06-医疗记录药物与跨境Continuity.md)。

### 每一种药先填一行，再分方向核对

| 原标签信息 | 实际需要填写 |
|---|---|
| 名称与成分 | 通用名／活性成分、商品名、生产商；原包装照片另存 |
| 规格与用法 | 剂型、每单位含量、现医嘱每次用量与频率；不确定处交医生核对 |
| 数量与行程 | 现有数量、按现医嘱预计用完日、抵达日、首诊日及回程日 |
| 特殊条件 | 是否需冷藏、注射器材，是否可能受管制；由药师／主管机关确认 |
| 核对结果 | 允许的携带方式与数量、需带证明、目的地接诊或续配安排 |

**中国到美国：** 从[FDA个人进口页面](https://www.fda.gov/industry/import-basics/personal-importation)按旅客身份阅读。该页的“Foreign Nationals”特指**非美国公民且非美国永久居民**，其中有90天药量说明；持绿卡者不能直接套用这一段。未获美国批准的境外药品另有进口限制，受管制药物还涉及DEA；不能把“有处方／自用／不超过90天”单独当成所有药物都会获准的保证。

**美国到中国：** 不把美国的90天说明当作中国额度。向实际入境口岸海关说明药名、成分、剂型、数量、用途、旅客情况及停留时间，问是否涉及限制、需哪些证明、如何申报；[海关携带物办事指南](https://online.customs.gov.cn/static/pages/guides/000629014001/000629014001.html)提供各直属海关咨询入口和12360。人在境外可从对应直属海关官网找可用联系方式，不假定短号码能直接拨通。冷藏注射剂、生物制品或管制属性不清时，单独写出具体产品，不能仅问“常用药能不能带”。

**过境、包装与温控另外问：** 入境允许不等于过境与航空运输条件已解决。按[CDC携药旅行说明](https://wwwnc.cdc.gov/travel/page/travel-abroad-with-medicine)保留标签与处方资料；将温控、随身携带及延误后的处理问题交药师和承运人确认。海关对是否允许进口的答复不能替代药师对储存和使用安全的判断。

可复制给主管机关的询问：

> 我计划〔日期〕经〔口岸及过境地〕入境，身份为〔实际身份〕，停留〔时长〕。本人治疗用药为〔通用名、成分、剂型、规格〕，拟随身携带〔数量〕，附原包装和医生处方／说明。请确认适用的携带限制、证明和申报手续；是否需另向其他机关办理。若不适用于贵部门，请提供负责部门入口。

### 带不够、约不上或两边药名不同，下一步找谁

| 卡点 | 当下做什么 | 不能当成已解决的答复 |
|---|---|---|
| 药预计在首诊前用完 | 把用完日告诉原开药医生／药师及目的地诊所，请其讨论可行过渡；必要时调整行程 | “到当地再买”“朋友能带” |
| 目的地诊所只给很晚的预约 | 说明药量和近期治疗需求，请临床团队判断是否需更早评估，并联系其他实际接诊入口 | 只进入候补名单 |
| 品牌不同、规格相似 | 把两边原标签及医嘱给医生／药师核对成分、剂型和剂量 | 仅因中文名相近就自行替换 |
| 保险不付提前配药 | 先问药房拒绝原因，再向保险和开药团队询问可用安排及费用 | 认为医生写了处方就必然能提前领到 |
| 药品进口要求仍不清楚 | 保存问询记录，继续联系主管机关；同时安排当地合法接诊路径 | 只拿航空公司或售药商答复当海关许可 |
| 已经在境外缺药或病情变化 | 及时联系当地临床团队；有紧急危险先急救 | 为等跨境邮包而自行停药、减量或延误就医 |

邮寄和他人代带不是默认补救方式；需要寄送时重新核对旅客身份、药物和运输渠道适用规则。更多获取失败分流见[药突然拿不到](medication-access-problem.md)。

### 用一个虚构例子检查是否真的接上

假设某人在中国完成一次复诊，打算回美国继续随访，按现医嘱计算现有药可用到11月12日，但美国诊所最早给到11月20日。**发现这八天缺口只是开始**：出发前把两个日期同时告诉原开药团队和美国诊所，取得可行的临床过渡安排，并逐药核对携带条件；若不能落实，就重新安排就诊或行程，不能靠自行减量把药“撑到”预约日。

抵达后，请当地医生核对当前药单与国外新增／停用项目；将后续变更反馈给仍参与治疗的另一地团队。未出检查结果仍由原定的人跟进，不能因为换了国家就无人查看。

**完成凭证：** 接诊确认、材料接收确认、逐药携带核对及实际供药安排、未出结果的负责人和日期。缺任何一项，写出当前阻塞和下一步，不勾成“已完成”。

## 手机丢了也能联系和付款

**情境：人在中国，美国银行要给原号码发验证码；或人在美国，中国号码失效，国内账单还要继续付。** 先分清三件事：手机能否联网、原号码能否收短信、具体账户是否接受当前验证方式。当地流量卡解决上网，不代表原号码和银行验证已经恢复。

**出发前，拿两条号码分别问运营商。** 从原账单、运营商官方应用或官网找到人工客服／漫游帮助，说明号码所属地、套餐、目的地和预计停留时间。中国号码按归属省份和实际运营商确认；美国号码按实际账户与套餐确认，不沿用另一家的答复。

> 中文：我将于〔日期〕至〔日期〕在〔国家〕，需要保留本号码接收账户验证短信。请分别确认线路是否有效、目的地收发短信与通话条件、漫游费用、长期境外使用限制，以及手机遗失后能否在境外补换SIM／eSIM。无法接收本号码短信时，怎样完成本人核验？请给办理入口、材料及可从境外联系的方式。
>
> 英文：I will be in [country] from [date] to [date] and need to keep this number for account verification texts. Please confirm line status, messaging and calling availability, roaming charges, extended-use restrictions, and whether I can replace the SIM or eSIM while abroad. How can you verify me if I cannot receive texts on this number? Please provide the required documents and an overseas contact method.

**运营商实例：** [T-Mobile国际漫游说明](https://www.t-mobile.com/support/coverage/international-roaming-services)将“阻止全部国际漫游”和“阻止收费国际数据漫游”分开，前者会阻止漫游中的通话、短信和数据；页面也列明长期境外使用限制。它说明设置和套餐要分别核对，不能推导为所有美国卡在中国都能免费收验证码。中国运营商的资费、补卡及境外核验条件，需向本人线路的客服取得答复。

**把关键账户按依赖列出，不抄密码。** 先列主要邮箱、银行／支付、运营商和近期要用的政务／医疗账户；每个账户只记录下面这些字段。尤其检查“邮箱恢复要旧手机、手机客服又要登录邮箱”的相互依赖。

| 账户／用途 | 当前验证依赖 | 已设置的另一种方式 | 手机不在时如何取得 | 官方求助入口及待办 |
|---|---|---|---|---|
| 私人填写 | 哪条号码／哪台设备，不填验证码 | 仅写该账户实际支持的方式 | 受保护的保存位置 | 材料、联系人、下次跟进日 |

账户支持时，可设置验证器、安全密钥或备用码；只提供短信时先保留短信验证并问恢复流程，不为了方便关闭保护。[FTC双因素验证说明](https://consumer.ftc.gov/articles/use-two-factor-authentication-protect-your-accounts)解释各账户选项不同及短信被冒名换卡截取的风险。验证器也需要安排设备丢失后的恢复，不能只把短信改成同一部手机上的另一个应用就认为已经有备份。

**一个可照着做的账户实例：** 对已开启两步验证、且提供备用码的Google账户，从账户“安全性与登录”进入“两步验证”，找到“备用验证码”并按页面保存；不能只把文件放在该账户的云盘或唯一手机里。登录受阻时可按“试试其他方式”使用未用过的备用码；每个码用后失效，生成新一组会使旧组失效。高级保护计划不提供此备用码下载。步骤见[Google官方备用码帮助](https://support.google.com/accounts/answer/1187538?hl=zh-Hans)，仅用于Google账户，不代表银行也支持；网站在所在地能否访问仍须实测。不要把备用码发给客服或亲友。

**做一次不会锁死自己的测试。** 保留现有可信设备登录，在自己控制的另一台设备或浏览器上，按官方流程测试已设置的备用方法；不删除原SIM、不注销旧号、不退出全部会话。记录实际通过的方法和日期。境内测试只能验证当时的配置，抵达另一国后还要测试该地网络下的收信、登录和必要付款。

- [ ] 核对两边号码的保号、漫游、收信及补卡条件，确认人在境外时怎样联系运营商。
- [ ] 至少准备一种与主手机不完全绑定的联系及付款办法，并确认本人能合法使用；由本人设置账户恢复，家属不靠共享全部密码代管。
- [ ] 将恢复说明放在受保护且不只依赖同一部手机的位置；家庭联系人表只写资料位置，不公开密码和恢复码。
- [ ] 出发前检查银行官方联系方式、交易提醒、可用额度和付款币种；账户受限时走[银行受限清单](bank-account-restriction.md)，不以借用他人身份绕过核验。

**已经收不到验证码：按现象找负责方。** 只记录服务名称、号码尾号、时间和错误原文，不在截图中保留验证码或完整账户号码。

| 现象 | 先做什么 | 交给谁继续处理 |
|---|---|---|
| 原号码没有信号，普通电话和短信也不可用 | 用可信网络联系运营商，核对线路、欠费、漫游权限及当地服务；双卡手机确认看的确是原号码 | 原号码运营商；请其说明恢复步骤与境外身份核验方法 |
| 普通短信能收，只有某家验证码不来 | 核对账户显示的号码尾号、国家码和发送提示，检查垃圾短信；按页面等待，不连续点重发 | 该服务的登录支持；问可用替代验证，并向运营商核对是否有相关短信限制 |
| 能收到码，但登录仍被拒绝 | 记录拒绝原文，分清码过期、设备验证、账户限制等提示；按官方流程操作 | 账户所属机构；运营商不能替它解除风控 |
| 新手机要求旧手机批准 | 保留仍可使用的旧设备或可信会话，选事先设置的替代方法 | 没有替代方式时走该账户正式恢复，不找“代收码”服务 |
| 线路突然中断，同时收到非本人换卡／改号通知 | 经已知官网联系运营商核查，并检查重要邮箱、银行和支付账户异常 | 按[账户安全事件清单](cyber-incident.md)处理；涉及未授权交易立即通知对应机构 |

向账户客服可以这样说：“本人目前在〔国家〕，登录时要求向尾号〔后几位〕发送短信。普通短信〔能／不能〕收到，错误提示为〔原文〕。我还有〔已设置的验证方式／可信设备〕可用。请说明替代核验、材料与安全提交入口；如必须本人回原地办理，请说明原因、预约和材料。”只通过自行核实的正式入口提交资料，不把完整密码、验证码或备用码交给声称能帮忙解锁的人。

**准备换号时，先迁移再停旧号。** 旧号仍可用时，从上表逐个进入账户设置，区分“联系号码”和“登录／交易验证号码”，确认新号码类型和所在国家是否被接受。完成机构要求的验证后，检查新号码是否生效、旧号码是否仍为恢复选项，并记录尚未迁移的账户。有一项只能回网点办理，就先安排该项，不因其他账户已改完而立即注销旧号。怀疑旧号被接管时优先按安全事件处理，不为了迁移继续信任它。

**手机之外的付款要实际可用。** 按已有条件留本人可合法使用的实体卡、适量现金或收款方接受的其他方式，分开保管；无需为了本清单额外开一堆账户。向发卡行问境外使用、拒付后的联系方法和身份核验，再向具体商户确认接受方式。只有手机里的电子卡、或所有备用卡仍需同一条失效号码确认，都不算独立备用。没有真实支付需要时，不为演练制造交易。

**虚构情境：** 回中国后，美国手机号码收不到银行验证码，但一笔房屋费用明天到期。先通过原有银行官方入口确认是验证失败还是账户受限；同时联系收款方说明情况，问其接受的替代付款或延期安排并留书面答复。若自动扣款仍在等待处理，核对状态后再安排人工付款，避免付两次。验证码未恢复不等于钱被冻结，收款方口头说“知道了”也不等于到期日已延后。

**这部分完成的标准：** 原号码在当前所在地的状态已确认；关键账户有实际验证过的可用入口，不能恢复的有正式办理要求；当下必要费用有已确认的支付安排。保存客服编号和下一次跟进日，不以“买了流量包／交了话费”替代上述结果。

日常配置见[两地基础设施主章](../book/18-中美双栖生活基础设施.md)和[数字安全主章](../book/15-网络安全与身份盗窃.md)。

## 突然要回另一边时

先处理现场安全，再决定谁旅行。住院、照护者退出或房屋损坏，都需要在起飞之前有人接手。

| 情形 | 当天先落实 | 随后处理 |
|---|---|---|
| 父母或家人住院 | 当地急救／医院、现场联系人、患者意愿 | 病历沟通、旅行文件、家中责任接手 |
| 同行者暂时不能走 | 当地照护、住所和药物 | 停留期限、保险、改签与后续就诊分别核对 |
| 自己必须提前返程 | 孩子、宠物、房屋有人照看 | 通知雇主／学校、重排预约、更新实际行程 |
| 手机、证件或付款失效 | 用备用联系及官方挂失／求助入口 | 恢复账户、补证和必要行程调整 |

- [ ] 在可支配预算内预留临时住宿、改签和当地协助费用，不以“以后理赔”代替当下付款能力。
- [ ] 做一次桌面演练：主要接应人同时不在时，备用人能否接到电话、找到资料并在权限范围内行动？

航班与行李问题见[旅行中断清单](travel-disruption.md)，证件丢失见[证件清单](lost-wallet-documents.md)。这些是应急分工建议，不能保证入境、改签或保险获准。
