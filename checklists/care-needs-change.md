# 父母逐步需要照护：从变化记录到实际接手

> **内容性质：管理建议**
> 本页帮助沟通与交接，不诊断失智、决定行为能力或代替本人选择居住方式。

## 先区分突然变化与长期变化

突然出现意识、呼吸、行动或其他严重异常时，使用[急救入口](../book/03-紧急情况与急救.md)，不要先完成本清单。长期变化可记录具体事实：何时开始、与以前相比怎样、是否影响吃饭、用药、出门、账单或个人清洁，再预约临床评估。

## 和本人讨论最需要哪一种帮助

用“哪些事更费力、希望谁帮忙”开始，而不是直接宣布搬去机构。记录本人希望保留的自主决定、愿意接受的帮助及不同意的安排；判断权限与实际照护能力分开，参阅[第10章](../book/10-Estate-Planning与失能.md)和[第20章](../book/20-父母养老与远程照护.md)。

**海外子女先和本人、本地协助者排出一周实际任务。** 不必先决定“住家阿姨还是养老院”。先写哪些时段需要谁到场、事情不能延误到何时；时间由本人和照护／医疗团队按实际需要确定，不套用统一小时数。

| 私人记录 | 本人能完成的部分 | 需要别人做的部分与时段 | 已同意的接手人／服务 | 没来时先联系谁 |
|---|---|---|---|---|
| 餐食与购物 |  |  |  |  |
| 洗漱、如厕与移动 |  |  |  |  |
| 医嘱中的用药或护理 |  |  |  |  |
| 预约、交通与取药 |  |  |  |  |
| 夜间需求与照护人休息 |  |  |  |  |

空格代表尚未落实，不能只填“家里人”。如果本人已不能安全独处，应立即向医疗团队／当地服务机构说明当前无人覆盖的时段，讨论可实行的安排，不等待远程家庭会议。出现急症仍走上方急救入口。

## 按任务找人，不只按头衔找人

| 需求 | 向候选服务确认 |
|---|---|
| 买菜、做饭、出门 | 时间、交通、临时取消及备用人 |
| 洗澡、穿衣、移动 | 实际服务范围、人员训练、风险与收费 |
| 用药或医疗操作 | 哪些须由持证人员做、谁开医嘱、如何交接 |
| 夜间或持续照护 | 真正覆盖时段，不能把“住家”当作全天待命 |
| 远程协调 | 谁到场、谁与医护沟通、本人如何获得信息 |

**美国当地服务入口：** [社区生活管理局老年服务查询](https://eldercare.acl.gov/home)。中国侧向所在地社区、民政和医疗机构问清可提供服务，不把美国项目资格套用到中国。

**第一次联系时带着任务表问，而不是只问每月多少钱。**

- 父母在美国：在上面的社区生活管理局查询页输入父母实际居住城市或邮编，取得当地服务联系人，说明需要餐食、交通、生活协助还是医疗护理，请其转介对应服务；查询结果不是对资格、名额或费用的承诺。
- 父母在中国：先联系实际居住地社区／街道的养老服务窗口，说明地点、所需时段和是否需要上门服务，询问由哪个部门登记需求、如何查询当地服务机构、评估如何预约。若需要医疗护理，向治疗医院护理部门或出院协调人员另问；不要让生活服务公司自行决定医疗操作。
- 候选机构先提供服务范围、最低时数／天数、出行及节假日加价、评估费、取消费、付款周期、缺勤替班及投诉联系人。需要资质的服务，取得机构／人员名称及登记或执照信息，再向当地主管机关查询相应范围；“平台认证”不能代替适用资质。
- 付款方式单列：谁签约、谁付款、是否需事先批准、申请未获批时谁承担费用。美国Medicare通常不支付长期日常生活照护；不要因有医保卡就向服务方承诺保险付款。[Medicare：长期照护保障边界](https://www.medicare.gov/coverage/long-term-care)。中国医保、长期护理保险及地方补贴按当地项目和个人条件另问，不把待遇申请中当作已获批。

**可复制询问：**“父母住在____，本人希望保留____自主安排。现在缺少____时段的____帮助。请说明你们能做和不能做什么、首次评估／服务最早时间、完整收费、未能到岗时由谁替班，以及谁处理投诉。我们人在境外，现场联系人为本人同意的____；请明确需要哪些授权才能与我们沟通。”

## 先试运行，再决定扩大

可在本人同意和安全允许时，试运行约定的少量服务，记录是否准时、是否胜任、本人感受及家属实际负担。若服务无法覆盖需要，应与团队重新讨论居家支持或机构选择，不把技术监控当作现场照护。

没有亲属可接手时，主动告诉医疗／社工团队：“没有可承担这项任务的人”，询问实际转介与可负担服务，不填写一个名义联系人就结束。

**开始前，三方各确认一遍。** 本人确认愿意接受的服务及隐私范围；服务方确认具体到岗者、任务与应急联系人；本地协助者确认首次如何进入住所、必要用品及谁能核实确实到岗。钥匙交接留记录，付款由合同约定渠道办理，不共享网银密码、验证码或不必要的病历。

第一次服务后，分别询问本人和服务方“实际做了哪些事、哪些未完成、原因是什么”；核对实际时数和费用，再决定继续、调整还是换人。首次服务做完只证明这一班完成，不能自动认定以后每天有覆盖。

| 实际问题 | 立即联系谁、说清什么 | 怎样确认恢复 |
|---|---|---|
| 人没来或临时辞职 | 服务方排班负责人＋已同意的本地备用人；说明无人覆盖的任务与时段 | 具体替班者确认何时到场；若无法提供安全安排，联系医疗／当地支持团队讨论替代方案 |
| 派来的人不会做必需任务 | 服务方主管；逐项指出合同任务与实际能力差异 | 由合适人员接手、必要时重新评估；不让无能力人员勉强完成转移或医疗操作 |
| 费用高于报价 | 账单联系人；提供约定价格、实际服务日期与争议项目 | 取得逐项解释、更正或争议编号；同时安排后续必要照护，不能只因账单争议突然无人照护 |
| 本人不愿继续或体验很差 | 先听本人具体原因，再与其同意的联系人及服务方沟通 | 改时间、人员或服务范围，按约定结束与交接；不因子女已付款而强迫继续 |
| 需要机构照护 | 请评估／出院团队说明所需能力，再联系候选机构接收部门 | 机构明确接受当前需求、床位及开始日期、费用和资料；候补登记不是已可入住 |

**机构考察时补问四件事：** 当前照护需求超出机构能力时如何处理；夜间实际有哪些人员与服务；急诊转送和家属联系怎样安排；终止合同、离院、押金和个人物品怎样交接。跨国搬去同住还需[迁居流程](long-term-relocation.md)，不能用一张赴美机票替代当地照护。

## 复查触发点

跌倒、住院、照护人退出、费用无法承担或本人意愿变化后，重新核对。确认每件必要的事都有人同意接手，并留下服务中断时的备用联系方式。
