# 长期离境前退订与跨境大额购物交接

> **内容性质：消费办理建议。** 用于人在中美两地切换、服务仍自动扣款，或买了家具、电器、贵重物品却要由另一地的人收货。取消服务、撤销扣款、退货、退款和解除合同分别处理。

## 先找到真正的收费方

打开最近几期银行／信用卡账单、应用商店订阅和邮件收据，列出服务名称、收费方、账号、币种、下次扣费日、合同期限、设备归还要求。不要只按手机里有没有应用判断是否仍在付费。

把每项分为保留、暂停、取消。先留住账户恢复所需号码、重要云端资料和仍使用的住房服务；医疗保障和贷款不按普通娱乐订阅退订。家人仍在使用共享服务时，先告知变化和具体结束日。

## 退订做到最后一笔账单

1. 从原始收据找到签约渠道：直接向商家买的找商家，通过应用商店买的从该平台订阅管理进入。保存当前方案、续费日和取消政策。
2. 向实际收费方提出取消或暂停，写明账号末几位、希望结束日期、是否还有使用者。索取生效日期、最后一次费用、剩余预付费处理及确认编号。暂停要另问恢复日、暂停费和是否自动恢复。
3. 需退路由器、机顶盒等设备时，先索取设备序列号清单、退还地址／标签和截止日。人在中国而设备在美国，由本人授权现场人按指定方式归还；保留交寄凭证及设备清单，继续追对方入库确认。
4. 在约定结束日检查服务状态，再核对最后账单和后续扣款。费用有差异时把取消编号、设备入库证明、账单项目交给收费方，索取更正或争议编号。
5. 已取消却继续收费，向付款机构及时提出适用争议；按其正式要求补书面通知和证据。不要只换卡或删应用就当合同结束，也不要自行停止所有无争议付款。

[FTC退订说明](https://consumer.ftc.gov/articles/getting-and-out-free-trials-auto-renewals-and-negative-option-subscriptions)支持保留取消记录、监测后续账单并向付款机构争议。不同付款方式的期限见[消费者主章](../book/16-银行信用卡消费者纠纷与诈骗.md)，不在此设统一退款保证或“一键取消”法律结论。

**没有取消按钮怎么办：** 保存当前页面和合同，按官方客服／书面渠道明确提出请求；写出此前尝试的日期和结果。索要案件号及适用替代方式，必要时通过付款机构和监管投诉渠道推进。退款仍未实际回到原付款账户时，继续保留未结项。

## 下单前，把两地收货与退货同时安排

第一动作不是付定金，而是问实际卖方：“货送到____，我在____，由____代收；若到货不符、损坏或我已离境，怎样报问题、退货和取回钱？”答复不清时先不付款。

| 付款前写清 | 两端怎样确认 |
|---|---|
| 商品和卖方 | 型号、尺寸、状态、配件、实际销售方、发票及售后方；平台名不一定是卖方 |
| 总成本 | 商品、配送、安装、税费、退货运费、重入库费；进口另核清关责任，不凭“包邮”推定包税 |
| 能否使用 | 向厂家确认电压、插头、频段／网络、地区功能与保修服务范围；不自行改装解决不兼容 |
| 配送 | 具体地址、楼层、电梯、安装条件、预计日期及谁接电话；迟到时是否能改期或取消 |
| 验收与退货 | 代收人可检查什么、何时拍照、何时报告、退货窗口从哪天算、是否需要原包装或退货授权 |

[FTC平台购物说明](https://consumer.ftc.gov/articles/buying-online-marketplace)指出平台保护不同，须查看卖方与平台的退换规则及申请期限。保留站内沟通和认可支付渠道；不因卖方说“转到外面便宜”而放弃平台保护。

## 收货、异常与退款分工

下单人保管合同、付款与投诉权限；现场人负责约定范围内的检查和交接。给现场人的资料只包括订单必要信息，不给银行密码。提前约定遇到型号错误、破损、缺件时先联系谁，以及何时拒收或按送货方程序注明问题；不让现场人签署超出授权的和解或追加购买。

到货后核对型号／序列号、外包装、配件和可安全测试的功能，留下照片与交付单。需专业安装的，待合适人员安装后再测试。损坏或不能使用时，按卖方要求开案，问是否由其上门取走、谁承担运输和何时退款；不要未经确认把商品跨国寄回。

本人已经离境、代收人也无法处理时，立即告知卖方和平台，申请延长、上门取件或认可的代理方式并取得书面答复；申请不等于获准，原期限仍跟进。退货留物流、签收及退款编号，到账后核对币种、金额和扣费。银行争议与商家协商并行时如实报告已退款金额，不重复索赔。

**完成标准：** 退订拿到终止确认、设备入库与最终费用结果；购物拿到可用商品或实际退款，缺件、保修和争议各有明确下一步。跨境携带与海关另看[物品主章](../book/40-高价值物品收藏与Luxury-Assets.md)。

2026-10-23：读取FTC退订与平台购物说明；未核各国消费者法、个别平台政策、商品准入或关税。两地交接和费用表为编辑建议。
