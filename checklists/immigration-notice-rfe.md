# 收到移民局通知：补件、指纹、面试与拟拒绝

> **内容性质：规则说明** 法规说明不等于个案结论；日历、归档和分工属于防遗漏建议。回复内容及救济途径应由合格移民律师结合完整案卷判断。

用于美国公民及移民服务局（USCIS）案件审理期间收到通知的场景。一般身份维护见[第37章](../book/37-移民身份与文件维护.md)。

## 先确认通知属于哪个案件

记录并核对：

- 申请表格类型；
- 收据号码（Receipt Number）；
- 申请人、请愿人或受益人的姓名；
- 通知类型、签发日期、签发办公室；
- 回复期限或预约日期、时间、地点；
- 律师或认可代表是否也收到完整通知。

若在线案件状态显示通知已发出，但没有收到纸件，账户内也找不到，应按官方未收到通知的查询流程处理。不要把“正在查询邮件”理解为回复期限自动暂停。

在线工具不可用时，按[移民文件维护中的电话与账户后备步骤](../book/37-移民身份与文件维护.md#21-收到补件或面试通知立即安排处理)准备收据、记录服务请求并继续守住通知期限。

**官方入口：** [移民案件在线查询请求入口](https://egov.uscis.gov/e-request) · [移民局联系中心](https://www.uscis.gov/contactcenter) · [通知或证件未收到时如何查询](https://www.uscis.gov/forms/filing-guidance/how-to-track-delivery-of-your-notice-or-secure-identity-document-or-card)。通知信与安全身份证件的投递查询方式可能不同。

## 补件通知（RFE / Request for Evidence）

不要只看“缺什么文件”的标题。逐段标出：

- 移民局认为现有案卷缺少哪些事实或证据；
- 要解决什么法律或事实问题；
- 接受哪些材料，是否要求原件；
- 回复截止日，以及寄送地址或上传要求。

不要自行假设可以延期，也不要把别人的补件天数套到自己的通知上。复杂、关键或涉及此前表述矛盾的补件，应尽早把原申请和完整通知交给律师。

**回复材料须一起提交。** 8 CFR 103.2(b)(11)规定，部分提交所要求的证据将被视为请求按现有记录作决定。缺少材料时，先让律师判断解释、替代证据及程序选择，不要先交一部分再期待系统允许补齐。

**规则原文：** [联邦法规：补件与拟拒绝通知的回复规则](https://www.ecfr.gov/current/title-8/section-103.2#p-103.2(b)(11))。按通知和适用规则确认收件要求，给投递、整理和复核留出时间。

**人在中国，美国收件人拿到补件通知：先取得全件，再安排跨境材料。**

1. 请已获授权的收件人保存信封、实际收到日期和全部页码，按安全渠道传完整扫描件；本人对照收据号核实案件，将原申请、通知和当前位置交给代理律师。通知还没读全时，不让亲友凭第一页概括缺件内容。
2. 以通知的具体要求建立一张材料表：每项由中国哪家签发机构提供、谁能申请、是否要原件、由谁翻译、美国由谁汇总和递交。先问签发机构能否本人远程申请或授权代办、实际时间和费用，再安排快递；不把跨境寄件的发出日当成USCIS收到日。
3. 递交USCIS的外文文件须附完整英文翻译，以及译者对完整准确性和翻译能力的认证；不能仅交家属摘译的重点段落。原件／复印件按通知和适用表格说明，不能把翻译认证、公证和附加证明书混为一项。[8 CFR 103.2(b)(3)–(5)：翻译与原件](https://www.ecfr.gov/current/title-8/section-103.2#p-103.2(b)(3))。请律师或实际递交负责人核对姓名、日期、页码及与原申请的差异。
4. 文件来不及时，立即把已采取的索取步骤、机构答复和时间交律师判断替代证据及程序选择；保留真实索取记录，不倒签或造文件。按上文整包回复规则安排最终材料，不先随意上传一部分期待以后补齐。涉及指纹或面试则另按通知处理改约与到场，不能用寄材料替代本人出席。
5. 寄送／上传前留最终完整副本、目录、指定地址／入口和截止日核对记录；美国接收人确认收到跨境原件后，再由有权递交的人将完整回复连同原补件／拟拒绝通知按要求提交。保存实际提交与签收凭证，继续查USCIS是否接收及后续通知。

完成凭证分两层：中国材料已交到正确负责人手中；USCIS回复已按要求提交并跟踪接收。亲友代收、快递签收或律师说“收到邮件”均不代表案件批准。2026-11-17定点核对翻译、原件及整包回复规则；不提供统一补件宽限期或个案法律结论。

## 生物信息采集预约（Biometrics Appointment）

- [ ] 看清日期、时间及申请支持中心（ASC）地址。
- [ ] 按通知携带指定身份证件和预约通知。
- [ ] 无法出席时，及时使用通知或官方页面指定的改约渠道，保存请求及处理结果；不直接缺席。
- [ ] 已错过预约时，立即联系移民局及代理律师处理，不自行到场就假设已经补救。

缺席可能导致申请被视为放弃并遭拒绝，而不只是“慢一点”。一般规则要求移民局在预约时间前收到其认为足以免除缺席后果的地址变更或改约请求；入籍等程序可能另有适用规定。**发出请求不等于获得批准。**

**核对入口：** [移民局：生物信息采集预约准备](https://www.uscis.gov/forms/filing-guidance/preparing-for-your-biometric-services-appointment) · [联邦法规：未出席的后果及例外](https://www.ecfr.gov/current/title-8/section-103.2#p-103.2(b)(13))。

## 面试通知（Interview Notice）

- [ ] 确认是哪个申请或案件的面试。
- [ ] 按通知准备原件、身份证明、更新材料及口译安排（如适用）；不要默认所有面试都允许相同的陪同人员或口译方式。
- [ ] 逮捕或违法传票、婚姻与工作变化、旅行与身份变化等，应提前让律师判断是否需要说明及提交材料。
- [ ] 如发现历史填写错误，向律师如实说明并讨论更正方式，不隐瞒，也不凭记忆临时改写事实。

## 拟拒绝、拒绝、撤销或终止通知（NOID / Denial / Revocation / Termination）

拟拒绝通知（NOID）与已经作出的拒绝决定不是一回事。尽快让律师阅读完整文件，确认：

- 是否仍可回复，或有重新开启／复议动议（Motion）、上诉（Appeal）等途径；
- 适用期限、受理办公室及提交方式；
- 对身份、工作许可、旅行及家属申请的影响。

不要把所有决定都当作可上诉。例如，依据放弃申请作出的拒绝通常不能上诉，但可能有申请重新开启的程序；能否使用及怎样提交须按具体决定核对。

**规则入口：** [联邦法规：撤回或因放弃而拒绝的后果](https://www.ecfr.gov/current/title-8/section-103.2#p-103.2(b)(15))。

## 通知没收到或地址变更

邮政转寄不等于向移民局变更地址。通过[USCIS：更新地址](https://www.uscis.gov/addresschange)在线办理时，填入每个待审申请的收据号并保存确认；纸质地址变更卡（Form AR-11）不会自动更新系统中的案件地址。不要假设改了一份申请、一个家庭成员或律师的地址，其他记录就全部更新；受保护案件等可能有专用渠道，按官方说明办理。案件已转美国国家签证中心（National Visa Center，NVC）办理领事程序时，还需另向国务院更新。

地址报告期限、担保人的额外义务及办理入口见[第37章第5–6节](../book/37-移民身份与文件维护.md#5-搬家后及时核对地址报告义务)。本段局部核验：2026-09-28，已读取USCIS公开地址说明与NVC联系入口；未测试登录后的界面、未收通知或改约功能。[依据与范围](../maintenance/reviews/2026-09-28-immigration-address.md)。

## 完成标准

- 通知已完整扫描保存；
- 截止日、提前提醒及负责处理的人已明确；
- 回复材料有目录和完整副本；
- 邮寄追踪或在线提交确认已保存，并继续确认接收状态；
- 律师副本及代理登记表（G-28）情况已核对；
- 有人持续检查案件状态和后续通知。
