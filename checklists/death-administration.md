# Death Administration Checklist

> 这是 survivor/executor 的 routing checklist，不替代 estate attorney / probate counsel。

---

# First 24 Hours

- [ ] immediate family
- [ ] children/pets
- [ ] hospital/funeral home
- [ ] home security
- [ ] medication / critical care for survivors
- [ ] accessible cash
- [ ] employer notice
- [ ] key documents located
- [ ] do not rush account transfers

---

# First 72 Hours

## Documents
- [ ] will
- [ ] trust
- [ ] marriage certificate
- [ ] beneficiary records
- [ ] insurance
- [ ] deeds/titles
- [ ] tax returns
- [ ] employer benefits
- [ ] account inventory

## Professionals
- [ ] estate attorney
- [ ] CPA
- [ ] financial custodian contacts
- [ ] insurance agent
- [ ] China-side counsel/notary if relevant

---

# Death Certificates

- [ ] ask funeral home / vital records how to obtain certified copies
- [ ] estimate number needed
- [ ] keep one scanned copy
- [ ] track which institution receives original certified copy

---

# Government

- [ ] confirm SSA death reporting
- [ ] survivor benefit eligibility
- [ ] passport/consular issue if cross-border relevant
- [ ] state/local probate filing
- [ ] vehicle/property records

SSA:
https://www.ssa.gov/personal-record/when-someone-dies

---

# Employer

- [ ] final payroll
- [ ] unpaid bonus/compensation
- [ ] life insurance
- [ ] AD&D
- [ ] retirement
- [ ] HSA/FSA
- [ ] pension if any
- [ ] survivor health coverage
- [ ] equity/deferred comp
- [ ] company property return

---

# Insurance

- [ ] employer life
- [ ] individual life
- [ ] home
- [ ] auto
- [ ] umbrella
- [ ] health
- [ ] valuables

Do not assume agent notification = formal claim.

---

# Bank / Brokerage

For each account identify:

- [ ] joint?
- [ ] beneficiary?
- [ ] POD/TOD?
- [ ] trust?
- [ ] estate/probate asset?
- [ ] outstanding autopay?
- [ ] direct deposit?

Do not use deceased credentials to bypass institution estate process.

---

# Home

- [ ] mortgage/rent
- [ ] home insurance
- [ ] utilities
- [ ] HOA
- [ ] security
- [ ] mail
- [ ] maintenance
- [ ] property tax
- [ ] vacant-property insurance issue

---

# Tax

- [ ] final individual return
- [ ] prior-year returns if needed
- [ ] estate EIN if needed
- [ ] Form 1041 screening
- [ ] estate tax screening
- [ ] state tax
- [ ] foreign assets
- [ ] China tax/property issues

IRS:
https://www.irs.gov/individuals/deceased-person

---

# Digital

- [ ] primary email
- [ ] phone
- [ ] password manager
- [ ] cloud
- [ ] photos
- [ ] subscriptions
- [ ] social media
- [ ] domains
- [ ] crypto if any

Do not factory reset devices before evaluating records/access.

---

# China / Cross-Border

- [ ] China bank
- [ ] China property
- [ ] parent/family coordination
- [ ] death certificate Apostille/translation
- [ ] local inheritance procedure
- [ ] WeChat/Alipay
- [ ] China tax
- [ ] one China coordinator

---

# First Month

- [ ] probate/trust administration underway
- [ ] survivor benefits
- [ ] insurance claims
- [ ] account classification
- [ ] bills stabilized
- [ ] tax professional engaged
- [ ] home secure
- [ ] fraud monitoring
- [ ] estate tracker active

---

# Do Not Rush

Unless required:

- [ ] home sale
- [ ] major gifting
- [ ] portfolio overhaul
- [ ] relocation
- [ ] sentimental item disposal
- [ ] closing every account
- [ ] large family distribution
