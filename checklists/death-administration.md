# 死亡后的事务处理清单

供家属和依法有权限的执行人安排事务。先保障在世家人的安全与照护，再按法律权限和实际期限办理；不能把本表当作遗产分配授权。详见[第35章](../book/35-死亡后的实际操作与Estate-Administration.md)。

> 公开版本仅为空白模板。实际资料请保存在受保护的私人位置。下列顺序是整理建议；具体期限以法律、合同、计划文件及机构通知为准。

## 最初的安全与安排

- [ ] 联系医院、当地适当机构及殡葬服务，处理遗体相关安排。
- [ ] 通知必要家人，安排孩子、父母、宠物、用药与住所安全。
- [ ] 确认家属合法可用的日常资金，保存关键文件。
- [ ] 按需要通知雇主，暂缓未经确认的账户转移或遗产分配。

**第一站：** [美国政府：亲人身故后的办事入口](https://www.usa.gov/death-loved-one) · [SSA：亲人身故后的社保办理](https://www.ssa.gov/personal-record/when-someone-dies) · [IRS：身故者税务事项](https://www.irs.gov/individuals/deceased-person)。

**家属还在另一国，先把首次安排交接清楚**

先向医院、警方或实际负责机构确认遗体目前在哪里、由谁保管、何时以及由谁可以作安排。情况不明时请其说明下一步，不让亲友自行搬运。指定一名沟通协调人，同时请当地机构确认谁依法有权签署；亲属关系、付款人和合法决定人可能不同。

1. 记录负责机构和案件／登记号，询问家属未到场时可接受的身份、亲属关系与授权材料，是否能按其程序远程签署。存在家属争议或权限不清时先向当地律师确认，不让协调人越权决定不可逆事项。
2. 联系当地殡葬机构时先说明目前保管地点、预计家属到达时间、希望比较的服务和暂未决定事项。逐项问接运、保管、具体仪式／处理、证明副本及其他费用，避免只收到一个套餐总价。
3. 对美国殡葬服务，FTC说明可电话询问服务和价格；接受安排前应取得所选项目的分项书面清单。可请求电子邮件发送，但不能把一般价格资料必须邮件发送当成联邦统一义务。[FTC远程安排指南](https://consumer.ftc.gov/articles/shopping-funeral-services-phone-or-online)说明这一区别；此规则不直接适用于中国机构。
4. 由有权限者确认选择、签署和付款渠道，把临时保管与后续最终安排分别写清。家属赶不上时，询问延期、保管费用和可行替代方案；不要把已付订金当成已授权全部处理。
5. 需要遗体或骨灰跨境运输，先让出发地服务方、接收方、相关使领馆及实际承运人分别确认文件与接收条件，再安排运输。保留交接地点、接手人、运输凭据和最终收件确认，不凭单方承诺先买运输服务。

首次安排的完成证据是合法签署人已确认、保管及后续服务有人接手、费用与交付有记录。死亡证明、福利申请和遗产程序继续按下文独立办理，不能等葬礼结束才看有期限的通知。

## 文件与专业人士

- [ ] 找到遗嘱、信托、婚姻证明、受益人记录、保单、产权、税表及账户索引。
- [ ] 联系遗产律师和税务专业人士，确认谁有权办理、需要什么证明及期限。
- [ ] 涉及中国资产时，协调中国当地专业人士和现场联系人。

**找专业人士：** [ABA：律师转介目录](https://www.americanbar.org/groups/lawyer_referral/resources/lawyer-referral-directory/) · [IRS：选择税务专业人士](https://www.irs.gov/tax-professionals/choosing-a-tax-professional) · [中国法律服务网 12348](https://www.12348.gov.cn/)。

## 死亡证明

- [ ] 向殡葬机构或登记机关确认认证副本取得方式。
- [ ] 按机构要求估计所需份数，安全保存扫描件。
- [ ] 记录向谁提交了哪份文件、是否退回及后续要求。

**办理入口：** [USA.gov：死亡证明](https://www.usa.gov/death-certificate)。跨境使用前再按接收机构要求核对附加证明书与翻译。

## 政府手续

- [ ] 确认死亡信息是否已向社会安全局报告；报告死亡与申请遗属福利分别办理。
- [ ] 咨询遗属福利资格与申请资料，保存受理回执。
- [ ] 按律师指导办理适用的法院、信托或其他遗产程序。
- [ ] 涉及护照、领事或跨境事项时，核对对应机构要求。

**政府 / 福利入口：** [SSA：遗属福利](https://www.ssa.gov/survivor) · [SSA：联系社会安全局](https://www.ssa.gov/agency/contact/) · [U.S. State Department：境外身故处理](https://travel.state.gov/content/travel/en/international-travel/while-abroad/death-abroad1.html)。

## 雇主及福利

- [ ] 核对最后工资、奖金、未付款项与费用报销。
- [ ] 查询人寿、意外死亡及伤残保险、退休计划、养老金与遗属医疗保障。
- [ ] 对IRA、401(k)、403(b)等退休账户，先确认受益人指定、账户持有人死亡日期、其是否已到法定开始提取日，以及受益人类型；不要只把账户“转成继承IRA”就认为后续税务已经完成。
- [ ] 如果逝者当年原本已有最低提取要求（RMD），确认死亡当年的最低提取是否尚未完成，以及应由谁在何时补足。
- [ ] 对继承IRA或退休计划，书面确认适用的是配偶选项、合格指定受益人的预期寿命提取规则、十年规则，还是其他计划特定规则；特别确认第1—9年是否仍有年度最低提取要求，不能只记住“第十年清空”。
- [ ] 确认健康储蓄／灵活支出账户、股权及递延报酬处理。
- [ ] 记录每项申请截止日与生效条件，依法归还公司财物。

**退休账户直接核对：** [IRS：退休账户受益人规则](https://www.irs.gov/retirement-plans/plan-participant-employee/retirement-topics-beneficiary) · [IRS：最低提取要求](https://www.irs.gov/retirement-plans/plan-participant-employee/retirement-topics-required-minimum-distributions-rmds) · [个人退休账户提取规则（IRS Publication 590-B）](https://www.irs.gov/publications/p590b)。

## 保险

- [ ] 区分通知经纪与正式索赔，分别取得受理凭证。
- [ ] 办理适用的人寿与雇主保险，核对所需认证文件。
- [ ] 维持必要住房、汽车、责任与贵重物品保障；住所空置等变化告知保险人。

**保险入口：** [NAIC：人寿保险保单查找](https://eapps.naic.org/life-policy-locator/) · [NAIC：州保险监管部门目录](https://content.naic.org/state-insurance-departments)。

## 账户分类与访问

- [ ] 逐一确认联名、指定受益人、死亡时支付／转移、信托或遗产账户。
- [ ] 列出自动扣款、直接入账和未完成交易，由有权限者与机构协调。
- [ ] 不使用死者凭证绕过机构遗产处理程序。
- [ ] 未确认债务性质及清偿顺序前，不自行以家属资金承担或分配遗产。

**债务 / 遗漏资产：** [CFPB：身故后债务处理](https://www.consumerfinance.gov/ask-cfpb/does-a-persons-debt-go-away-when-they-die-en-1463/) · [USA.gov：无人认领资产查询](https://www.usa.gov/unclaimed-money)。

## 住所与日常账单

- [ ] 维持房贷或租金、水电、必要维修、保险及物业沟通。
- [ ] 处理邮件、房产税与业主协会事项，记录费用由谁支付。
- [ ] 保存钥匙与访问记录，检查空置期间的保障条件。

## 税务

- [ ] 请税务专业人士判断最终个人税表、以前年度欠报及遗产识别号码是否适用。
- [ ] 分别评估遗产所得税、遗产转移税、州税及境外资产申报。
- [ ] 整理收入、扣除、估值与付款凭证，不把某一金额门槛当作唯一申报条件。

**税务入口：** [IRS：身故者最后一份所得税表](https://www.irs.gov/individuals/file-the-final-income-tax-returns-of-a-deceased-person) · [遗属、遗产执行人与管理人税务指南（IRS Publication 559）](https://www.irs.gov/publications/p559) · [IRS：遗产与信托所得税表（Form 1041）](https://www.irs.gov/forms-pubs/about-form-1041)。

## 数字资料

- [ ] 通过合法路径处理邮箱、手机号、密码管理器、云端照片、订阅、域名及数字资产。
- [ ] 评估证据与访问需要后再注销服务或重置设备。
- [ ] 区分暂停扣费、保存记录与永久删除，保留必要交接凭证。

**数字账户示例：** [Apple：申请访问已故家人的账户](https://support.apple.com/en-us/102431) · [Google：已故用户账户申请](https://support.google.com/accounts/troubleshooter/6357590)。

## 中国与跨境

- [ ] 核对中国银行、房产、支付平台及继承手续。
- [ ] 按接收机构要求办理死亡证明的附加证明书、翻译或其他文件手续。
- [ ] 确定一名联络协调人，但不把协调角色当作法律代理权。

**跨境文件入口：** [HCCH：附加证明书公约](https://www.hcch.net/en/instruments/conventions/specialised-sections/apostille) · [中国领事服务网：附加证明书](https://cs.mfa.gov.cn/zggmcg/fjzms/)。

## 持续跟进与暂缓事项

- [ ] 确认遗产程序、福利和保险申请的真实状态，不以“已发邮件”算完成。
- [ ] 稳定家属日常账单、照护、住所及反诈骗提醒。
- [ ] 非期限所迫的卖房、搬迁、大额赠与、投资重组和纪念物处置可先讨论再决定。
