# 退休与减少工作：把医保、收入和生活衔接起来

> **内容性质：专业咨询准备**
> 本页整理跨章节问题，不计算个人领取年龄、投资提取率或参保资格。

**何时使用：** 已有退休、减少工作或停止雇主医保的计划时开始；收到正式通知或临近保障结束时立即核对相应期限，不等年度复查。

## 先写四个不同日期

- 最后工作日、最后发薪日；
- 本人及家属各项雇主保障的最后有效日；
- 计划开始领取各项退休收入的日期；
- 新医疗保障实际生效日。

这些日期不必相同。把每项资料的确认人和书面来源一起保存，不只记录“已问人事”。

## 医疗保障先接上

把年龄、现有保障、本人／配偶工作情况和居住地交给福利部门与保险机构核对。符合联邦医疗保险（Medicare）条件者，分别确认各部分的申请、药品保障及原雇主保障衔接；不符合者比较配偶计划、医保市场及适用续保方案。

**规则说明：** 联邦医疗保险A／B部分中，符合当前就业团体保障条件的特别参保期通常在就业或该保障结束后八个月结束，取较早者；COBRA续保不会延后这个期限。这不是所有医保的统一八个月窗口，也不表示可以等八个月而没有保障空档。个人适用例外与实际生效日必须另核。

**查依据与办理：** [Medicare：医保保障何时生效](https://www.medicare.gov/basics/get-started-with-medicare/sign-up/when-does-medicare-coverage-start) · [社会保障署：医疗保险准备](https://www.ssa.gov/medicare)。如有健康储蓄账户（HSA）供款，将拟申请Medicare／社会安全福利的日期交给福利部门与税务顾问，确认本人和雇主何时停止供款，并核对追溯生效的影响；直接查看[Medicare：65岁后工作与参保前HSA安排](https://www.medicare.gov/basics/get-started-with-medicare/medicare-basics/working-past-65)，不要从最后工作日直接推定停止供款日。

**把每个人从旧保障交接到新保障**

1. 向福利管理员索取本人和每位家属的最后保障日，再向拟加入的计划索取申请入口、所需材料、缴费要求及预计生效日。把这两份答复并排比较，不用最后发薪日代替保障终止日。
2. 提交后取得案件／申请编号，追踪缺件和实际资格决定；如需首期保费，确认支付与入账。只有报价或申请回执时，继续标为待确认。
3. 收到生效确认后，与计划、常用医生和药房核对可使用的具体计划与服务；配偶尚未到Medicare年龄等情况单列处理。本人参保不自动替家属解决保障。
4. 新计划未按预期生效或拒收申请，立即把两端日期和原因交给旧福利方及新计划，询问个人仍可使用的衔接／补正方案与期限，必要时寻求合适的保险协助。不能默认能追溯，也不要为等结果错过已有窗口。

只有实际生效、付款条件及必要服务接续已确认，才按旧计划规则处理退出或后续缴费；某些旧保障会按就业终止自动结束，不能靠“不主动取消”延长。长期回中国者另问境外承保，不以美国保卡可查推断中国可用。

## 收入与账户逐个确认

| 要问什么 | 交给谁、看什么 |
|---|---|
| 退休后固定支出和不确定支出是多少 | 本人先列预算；用[第13章](../book/13-高收入家庭财务Operating-System.md)整理资产、债务和流动资金 |
| 何时领取、是否仍工作、配偶或遗属权益如何关联 | 社会保障署／养老金计划；保留方案说明，不用一条“最佳年龄”代替比较 |
| 哪些账户需要分配、哪些操作可能有税务后果 | 计划管理员与税务顾问；参阅[年度复查](annual-review.md)，不要为整理账户立即全部提现 |
| 两地长住如何影响保障、税务与照护 | [长期迁居清单](long-term-relocation.md)与[第38章](../book/38-中美跨境税与Work-from-Abroad.md) |

## 确认完成，而不是确认已经递交

- [ ] 新保障、医生与药房能实际使用；家属分别确认。
- [ ] 首笔收入、自动付款与预留现金有衔接安排。
- [ ] 税务、退休账户和雇主未结事项各有负责人。
- [ ] 日常活动、社会联系和照护安排符合本人意愿；不把退休变成另一套绩效考核。

若某项资格未定，记录待补材料、实际截止日及备用安排；不要据“申请中”推断已生效。
