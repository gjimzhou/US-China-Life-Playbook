# 辅助生殖与跨境收养：先确认路径，再安排两地事务

> **内容性质：专业咨询准备。** 两种路径分别处理：辅助生殖涉及医疗、同意与可能的亲子法律问题；收养涉及儿童利益、收养程序及移民资格。本页帮助准备咨询、识别不能继续的条件和交接资料，不制定治疗方案，不保证成功、国籍或入境结果。

## 辅助生殖先约哪一方

先由本人联系现居地的妇产科／生殖医学团队，说明想解决的问题、既往治疗和预计在哪些国家停留，取得适合自己的评估安排。若考虑另一国治疗，再联系拟接诊医院的正式国际患者或生殖中心窗口，不先向中介购买完整套餐。

给每家团队同一份必要摘要：相关病史、既往检验和治疗日期、用药、已有胚胎／配子储存位置（如有）、本人和相关参与者能到场的日期、希望谁参与沟通。先问安全传输渠道，避免把完整身份证件与病历发到公开群。

选美国机构可从[CDC辅助生殖数据与解释](https://www.cdc.gov/art/success-rates/interpret.html)进入诊所资料。其数据有时间滞后，病例构成不同，诊所成功率不能直接当作个人成功概率。中国机构的准入与实际可开展项目向医院和所在省级卫生健康主管部门分别核对，不能凭广告或“海外合作中心”名称判断。

## 治疗前把两端职责书面问清

| 找谁 | 必须取得的答案 |
|---|---|
| 主治团队 | 还需哪些检查、哪些旧结果可用、何时须本人到场、哪些变化需立即联系、可否按现有行程开展 |
| 另一地的接续团队 | 是否同意承担监测／复诊，接收什么记录、谁下订单与解释结果；未接受前不假定可远程接续 |
| 诊所财务与保险 | 初诊、检查、药物、操作、麻醉、实验室、储存、取消或未进入下一阶段的分项费用；保障和自付分别确认 |
| 实验室或储存机构 | 文件、同意、续费、变更联系资料与停止储存的程序；任何转运须由两端机构先确认可受理 |
| 独立法律专业人士 | 涉及捐赠、代孕、亲子确认、跨境材料或不同国籍时，哪些安排可行、需谁同意、在何地处理 |

不要自行携带、邮寄或安排胚胎／配子跨境运输，也不要用另一人的处方购买药物。转运的合法性、机构条件和承运要求须由有资格的两端团队确认，本页不提供运输操作方案。

## 从咨询走到可执行安排

1. 收到评估方案后，由本人复述各步骤、时间是否可调整、风险和替代选择；不理解的同意文件先请团队解释。
2. 把医疗计划与请假、住宿、陪同和返程分开安排。具体复诊与能否旅行问治疗团队，先保留可调整行程，不用机票日期倒逼治疗。
3. 给每个已同意接续的机构登记联系人和资料格式；转出的检查报告、操作记录、用药计划由接收方确认能读、能处理，不只看上传成功。
4. 保险授权、费用报价和临床同意各自保留，付款前问取消／延期会损失哪些费用。没有获得接续确认时先调整治疗或旅行安排。
5. 周期取消、结果与预期不同或本人想停止时，直接联系团队说明意愿，询问后续临床随访、费用结算和储存安排；亲属不代替本人作超越有效权限的决定。

**本场景完成标准：** 得到明确评估／治疗或暂缓决定，负责团队、费用和两地接续实际落实；不以怀孕或生育结果作为办理流程的验收指标。后续家庭安排见[孕产家庭准备](pregnancy-family-preparation.md)。

## 跨境收养先判断是否有可走路径

**先读当前国家规则，再交钱。** 截至2026-10-23实际读取的[国务院中国收养页面](https://travel.state.gov/content/travel/en/Intercountry-Adoption/Intercountry-Adoption-Country-Information/China.html)（页面更新2026-05-28），中国至美国的一般跨国收养已停止，只有很有限的亲属等例外；符合例外仍须满足适用程序。不能仅凭“认识孩子”“亲戚愿意”判断符合条件。

不要把此结论套到所有中国国内收养、所有国籍或所有居住情形。不同国家路径从[国务院国家信息目录](https://travel.state.gov/content/travel/en/Intercountry-Adoption/Intercountry-Adoption-Country-Information.html)选择实际国家，不复制另一国流程。

## 第一次咨询怎样准备与分工

先写一份私人事实表：拟收养人各自国籍与通常居住地、孩子所在地与现有法律关系、是否亲属、是否已经有案件或法院文件、希望最终居住国家。不在论坛公布儿童身份、照片或家庭经历。

1. **来源国主管机关：** 从上述官方国家页的主管机关联系方式进入，询问当前是否受理这类事实、例外需哪些证明、如何取得正式回复。旧政策或中介承诺不能替代主管机关答复。
2. **美国路径：** 按官方[收养办理说明](https://travel.state.gov/content/travel/en/Intercountry-Adoption/Adoption-Process.html)确认适用机构与专业帮助，把国籍、居住地和孩子资料交给合资格收养／移民专业人士，问拟采用什么程序、各方负责什么、哪一步必须先获决定。
3. **费用和服务：** 索取服务机构资质、分项合同、退出与退款条件、投诉方式、翻译和后续报告费用；逐项核对实际开展国家及服务范围，不因有执照就推定它能处理所有国家。
4. **文件先后：** 在获确认的路径上建立材料表，注明谁签发、谁接收、有效期和原件去向；认证翻译按[跨境文件流程](../book/19-文件公证Apostille与跨境授权.md)先问接收方。没有明确路径时不先为整套材料支付大额费用。
5. **停止条件：** 不符合国家路径、无法确认例外、儿童或家庭资格未确定，先停止新增不可退支出并保存书面答复；已有案件请主管机关及服务方说明如何处理既有申请和费用。不能改用旅游、临时监护或非正式抱养绕过程序。

**本场景完成标准：** 有当前是否可继续的明确答复；可继续者拿到适用路径、负责机构、先后条件及下一步受理凭证，不能继续者知道停止原因和既有费用／文件的处理。取得某国收养文件不自动代表儿童已获美国入境或公民资格；不把儿童带来后再补身份当作方案。
