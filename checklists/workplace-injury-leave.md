# 工作中受伤、职业病或突然无法工作

> **内容性质：管理建议** 勾选项用于整理任务，不代表每项都是法律义务；期限、资格与合同要求按所在地和实际文件确认。

用于工伤、职业暴露、因疾病／伤残暂时无法工作，以及医疗、工伤补偿、《家庭与医疗假法》（FMLA）／伤残福利同时交叉的情况。失业见[失业应对清单](job-loss.md)，一般员工福利见[第22章](../book/22-工作失业与Employee-Benefits.md)。

## 先处理医疗与安全

- [ ] 有急症先求医或拨打 911，不要为了等雇主批准延误紧急治疗。
- [ ] 能安全做到时，记录事故时间、地点、发生经过、相关设备／环境和目击者。
- [ ] 按雇主规定尽快向主管／人力资源／安全团队报告，但不要只依赖口头报告。
- [ ] 让医疗人员知道伤病与工作有关，并按实际情况记录。

## 工伤补偿（Workers’ Compensation）不是全国统一一个系统

美国政府服务网／美国劳工部当前说明：大多数私营企业、州／地方政府雇员的工伤补偿由州系统管理；联邦雇员和少数特定行业另有联邦项目。

- [ ] 从实际工作州的工伤补偿机构开始核对；跨州工作、出差或远程工作涉及哪个制度，需要结合雇佣和受伤事实确认。
- [ ] 问雇主谁是承保公司／第三方管理机构、理赔编号和医疗网络规则。
- [ ] 保存工伤报告、医疗记录、工作限制、理赔通信。
- [ ] 理赔被拒时不要只和主管口头争论；查州机构的申诉／听证路径和期限。

**官方入口：** [USA.gov：工伤补偿](https://www.usa.gov/workers-compensation) · [州工伤补偿主管部门](https://www.dol.gov/agencies/owcp/wc)。

## 工伤补偿、家庭与医疗假、残障合理便利与短期伤残保障可能同时存在

同一伤病可能触发多套制度，但它们不是互相替代的：
- 工伤补偿：主要处理工作相关伤病的医疗与收入替代等；
- 《家庭与医疗假法》（FMLA）：符合条件时提供保职假并延续适用的团体医保条件；联邦法本身通常不要求带薪，可与其他合资格假期并行；
- 《美国残障人士法》（ADA）：符合条件时可能涉及合理便利；
- 雇主短期／长期伤残保障（STD/LTD）：按计划文件处理收入替代。

**制度对照：** [美国劳工部：医疗与伤残相关假期及制度交叉](https://www.dol.gov/agencies/odep/publications/fact-sheets/employment-laws-medical-and-disability-related-leave)。

不要因为工伤补偿理赔在处理，就默认人力资源部门（HR）已自动处理请假、福利或合理便利。

## 医生的工作限制要具体

让主治医疗人员根据实际情况写清：
- 是否完全不能工作；
- 搬重物／站立／打字／出差／工作时间等限制；
- 预计持续多久；
- 何时复查；
- 是否可调整工作任务／远程工作。

人力资源部门（HR）／理赔管理方需要什么表格，应从实际雇主／计划／州制度获取。

## 工资、医保和福利连续性

- [ ] 确认带薪休假（PTO）、病假、工伤补偿收入替代、短期伤残保障（STD）是否重叠或协调。
- [ ] 问医疗保险、健康储蓄账户／弹性支出账户（HSA/FSA）、401(k)、奖金／股权在请假期间怎样处理。
- [ ] 记录无薪期间和工资发放变化。
- [ ] 长期无法工作时，提前了解长期伤残保障（LTD）、社会保障伤残福利等是否可能相关，但不要假设资格。

**多份申请分别追踪，境外休养也保持可联系**

用一行记录一个事项：工伤理赔、请假、工资替代或伤残福利、医保续接，各写受理方、案号、所缺材料、回复时间和实际决定。某一方收到病假条，不表示其他申请自动完成。

让医生按实际受理要求提交工作限制或必要证明，敏感资料使用各方指定的安全渠道，不把完整病历群发给主管和同事。人在境外时确认可用的个人联系方式与正式收件安排；所在地或复诊计划变化，分别询问对现有申请与服务的影响。已提交但无回执的项目向该受理方补查，不仅向HR口头询问总进度。

**在中国探亲时病倒，美国雇主要医疗证明**

先接受当地医疗照护，同时按雇主请假渠道通知缺勤；不要等英文证明做好才报备。以下医疗证明规则针对符合条件的联邦FMLA请假，不能自动套给工伤赔偿、短期伤残保险或所有境外岗位。

1. 向美国HR／假期管理方拿本次要求、表格或必要字段、安全提交入口及截止日，确认员工和雇主是否适用FMLA、缺勤如何登记。单列工资替代与医保缴费联系人，医生证明不会自动触发发薪。
2. 把工作必要职责和表格交中国实际诊治医生，按真实病情说明不能履职的原因、预计期间与复诊安排；索取医生联系信息和签署件。不要让家人自己补写诊断或把短病假条当成所有字段已齐。
3. [29 CFR 825.307(f)](https://www.ecfr.gov/current/title-29/subtitle-B/chapter-V/subchapter-C/part-825/subpart-C/section-825.307)规定，员工／家属在外国访问，或家属居住外国并发生严重健康状况时，雇主须接受当地执业医疗人员的证明；雇主要求时，员工须提供非英文证明的书面翻译。这不免除完整性、资格与其他要求。先问清译文格式和提交方式，再安排翻译，保留原文与对应译文。
4. [29 CFR 825.305(b)–(c)](https://www.ecfr.gov/current/title-29/subtitle-B/chapter-V/subchapter-C/part-825/subpart-C/section-825.305)一般要求在雇主提出要求后 **15个日历日**交证明；雇主可给更长时间，尽到勤勉善意努力仍不可行另有例外。证明不完整／不足时，雇主应书面说明缺项，一般给 **7个日历日**补正，也有上述不可行例外。记录请求收到日和实际期限；医院来不及出具时，在期限前说明预约、催办及预计交付，保存努力记录并请求确认处理，不能自行宣布延期。

被退件先拿到具体缺项，再请原医生补充。若仅因“中国医生”被拒，向假期管理方引用上述境外证明条款请求复核；仍有争议可从[DOL FMLA入口](https://www.dol.gov/agencies/whd/fmla)求助。费用按当地诊疗、证明和翻译分别确认，不承诺雇主报销。完成以管理方收到并确认处理结果、批准期间及复查／复工要求为准；上传回执不等于批准，也不表示伤残福利已获批。

2026-11-19定点核对上述两条联邦法规（页面截至11月18日）；未重核州假、工伤和各雇主计划。

## 返回工作

复工前应确认以下事项：
- 医疗准许复工证明／限制；
- 调整工作任务；
- 时间安排；
- 后续治疗；
- 理赔是否仍开放；
- 复发／恶化如何报告。
