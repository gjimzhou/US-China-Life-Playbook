# 国际旅行清单

从预订时开始核对，疫苗、签证与许可可能需要更早准备。以[第29章旅行与长期停留](../book/29-旅行长期停留与全球Mobility.md)为主，贵重物品见[第40章](../book/40-高价值物品收藏与Luxury-Assets.md)。

> 公开版本仅为空白模板。实际资料请保存在受保护的私人位置。下列顺序是整理建议；具体期限以法律、合同、计划文件及机构通知为准。

父母来美另看[探亲全流程](parents-us-visit.md)；两边都有持续责任另看[两地生活接续](two-country-living.md)。

已经遇到问题时直接用[航班中断与改线](travel-disruption.md)、[境外丢证补办](lost-wallet-documents.md)或[跨境用药交接](two-country-living.md#医疗交接跟着人走)，不必从准备清单重新查起。

## 预订前

- [ ] 核对护照、目的地及过境入境要求、返程身份文件。
- [ ] 理解不可退款部分、取消策略和旅行保障的生效条件。
- [ ] 确认境外医疗、必要的医疗转运及租车保障，不能只看保险名称。

**预订前核验：** [U.S. State Department：各国旅行信息](https://travel.state.gov/content/travel/en/international-travel/International-Travel-Country-Information-Pages.html) · [美国护照办理](https://travel.state.gov/content/travel/en/passports.html) · [State Department：境外健康与就医](https://travel.state.gov/content/travel/en/international-travel/before-you-go/your-health-abroad.html)。

## 医疗与药物

- [ ] 根据目的地和个人情况提前咨询旅行健康建议、疫苗与用药。
- [ ] 按目的地及过境地规定核对药品合法性、数量、包装及证明，处方不自动构成进口许可。
- [ ] 准备足够且允许携带的药物、用药清单和协助电话。
- [ ] 偏远行程确认医疗接应与转运入口及保险限制。

**医疗 / 携药：** [CDC：旅行健康](https://wwwnc.cdc.gov/travel/) · [CDC：携药出境](https://wwwnc.cdc.gov/travel/page/travel-abroad-with-medicine) · [TSA：药品安检规则](https://www.tsa.gov/travel/security-screening/whatcanibring/medical)。

**中美往返经第三国中转，常用药怎样逐段核对**

以下是出发前的安排建议。CDC提醒同时向目的地和中转地核对药物规则；美国可处方或非处方取得的药物，在另一地可能受限。它建议尽量在出发前4–6周咨询旅行健康专业人员，并保留原标签、处方及药物通用名；这不是各国统一的准入或携带数量规则。[CDC：携药出境](https://wwwnc.cdc.gov/travel/page/travel-abroad-with-medicine)，2026-11-17读取，页面复核日仍为2022-08-18。

1. **先列路线和药物，不只写商品名。** 把中国、美国及每个中转国家／地区、是否出机场或需重新提取行李、停留日期列清；药单写通用名、成分、规格、剂型、数量及本人用途。处方药、非处方药、注射剂和其他随身治疗用品分别列出，别默认同品牌在两国成分相同。
2. **按国家逐项问主管方。** 从目的地及中转地官方药品／海关说明或其使领馆核对是否允许、数量、是否需事先许可、证明语言、申报与携带方式。把答复和适用路线记下来；只得到航空公司“可以上机”的答复，尚未解决进口／过境许可。看不懂分类时把成分交主管方核对，不自行猜测属于豁免。
3. **让开药方安排合法且临床可行的方案。** 把获确认的限制给原医生和药房，讨论允许数量、处方／说明、保险提前配药及目的地接续。申请许可、翻译、配药和冷链用品的费用与所需时间分别确认；不能携带或赶不上许可时由医生讨论替代及行程，不自行停药、换药或让亲友拆包代带。
4. **出发前核对实物。** 原标签与处方、姓名、规格、数量及许可一致，按实际安检与承运要求安排随身携带及冷藏／针具；储存和时差用药问医生或药师，不用论坛时刻表。副本留在可安全访问的位置，原件随实际要求携带。
5. **改线就重新检查。** 航班变化增加新中转地、需出机场或延长停留时，重新核对该地规则和合法可用的药量。药物遗失、被扣或即将用尽时联系当地合资格医疗／药房及主管机关，保留处理记录；不要寄送未经确认可进口的补给。完成以每一段规则已确认、必要许可已取得、实际药物与后续供药安排均可用为准。

**疫苗另做一项，不用携药许可替代：** 将旅行日期、年龄、既往接种记录和特殊健康情况交给临床团队评估。[CDC麻疹旅行页](https://www.cdc.gov/measles/travel/index.html)（2026-04-29）强调出境前核对免疫保护；未保护者即使离出发不足两周仍应尽快咨询，不能因来不及理想提前期就跳过。婴儿、妊娠或免疫抑制等需个别评估，本页不提供个人补种处方。

## 文件与资金

- [ ] 备妥护照、签证或许可、保险及适用驾驶文件，安全保存副本。
- [ ] 准备主要与备用付款方式、小额应急资金及银行官方联系电话。
- [ ] 核对提款费用、支付限制和必要安全设置，避免所有备用方式都在同一钱包或手机。

## 出发前再次确认

- [ ] 机票姓名与证件一致，确认行李、接送和住宿地址。
- [ ] 合法永久居民（绿卡持有人）如计划长期离境，分别确认：返美旅行证件、是否需要回美证、放弃永久居民身份的风险，以及对入籍连续居住和实际在美停留要求的影响；不要用“每6个月回来一次”替代分析。
- [ ] 如果预计连续离美超过1年，出发前核对旅行文件申请（Form I-131）及回美证要求；不要假设人在国外后还能补办同样的申请流程。
- [ ] 如未来计划入籍，任何单次超过6个月的离境都应记录支持连续居住的真实事实；离境1年或以上，另核对是否打断连续居住，以及本人是否属于可用Form N-470的特殊情形。
- [ ] 核对天气与安全通知，保存必要离线路线。
- [ ] 测试漫游或电话卡、账户认证及恢复在境外是否可用。
- [ ] 安排住所、邮件、宠物及家人照护，确定谁能处理限期通知。

**绿卡 / 入籍入口：** [USCIS：永久居民国际旅行](https://www.uscis.gov/green-card/after-we-grant-your-green-card/international-travel-as-a-permanent-resident) · [USCIS：旅行文件申请（Form I-131）](https://www.uscis.gov/i-131) · [USCIS：连续居住与实际在境时间](https://www.uscis.gov/citizenship/continuous-residence-and-physical-presence-requirements-for-naturalization) · [USCIS：保留入籍连续居住资格申请（Form N-470）](https://www.uscis.gov/n-470)。

**2026-11-17定点核对：** [8 CFR 223.2(b)(1)](https://www.ecfr.gov/current/title-8/chapter-I/subchapter-B/part-223/section-223.2)明确回美证申请须在美国境内、持合法永久或有条件永久居民身份递交。不要把难民旅行文件的境外例外套给普通回美证；生物信息采集、费用、表格版本及个案出行仍须另核。

## 关键随身物品

- [ ] 在安检允许范围内妥善随身保管入境文件、关键药物、付款备份及到达即需的钥匙。
- [ ] 贵重或不可替代物品按实际携带与保险条件安排，不随意混入托运行李。
- [ ] 工作设备与数据按雇主要求处理，不因旅行方便绕过规定。

## 手机丢失预案

- [ ] 启用适当锁屏和设备查找，确认号码及认证恢复流程。
- [ ] 准备不依赖丢失手机的官方联系方式和恢复材料。
- [ ] 保留独立付款与联系家人的方式，检查云端照片和证件访问权限。

## 适用的领事资源

- [ ] 按本人国籍保存对应使领馆官方入口。
- [ ] 美国公民可查看国务院旅行提示，并考虑智能旅行者登记计划（STEP）。

出发前按[使领馆目录后备查找步骤](../book/29-旅行长期停留与全球Mobility.md#20-护照遗失按签发国流程补办)保存适用领区的常规及紧急联系方式。

**领事入口：** [智慧旅客登记计划（STEP）](https://step.state.gov/) · [美国使领馆目录](https://www.usembassy.gov/) · [State Department：国际旅行](https://travel.state.gov/content/travel/en/international-travel.html)。
- [ ] 理解领事协助与医疗保险的作用不同，不假设领事馆承担全部费用。

## 中国旅行或长期停留

- [ ] 核对中国手机号、银行、微信或支付宝、医院及当地联系人。
- [ ] 确认所用证件与入境身份，必要文件提前办理。
- [ ] 在中国工作或停留方式改变前，检查雇主许可、身份、两国及相关州税务。

**中国 / 跨境入口：** [国家移民管理局](https://www.nia.gov.cn/) · [国家政务服务平台](https://gjzwfw.www.gov.cn/) · [IRS：跨境纳税人资料](https://www.irs.gov/individuals/international-taxpayers) · [自然人电子税务局入口：从税务总局“纳税服务”进入](https://www.chinatax.gov.cn/)。

## 贵重物品

- [ ] 检查保险地域、运输、酒店存放及列保条件。
- [ ] 保存识别照片与证明，按需要在出境前咨询海关登记。
- [ ] 如实申报应说明的物品与境外维修，不把免税待遇当作免申报。
- [ ] 避免公开实时位置与具体收藏信息。

**贵重物品 / 海关：** [CBP：Form 4457 官方入口](https://www.cbp.gov/document/forms/form-4457-certificate-registration-personal-effects-taken-abroad?language_content_entity=en) · [CBP：离美前办理个人物品登记](https://www.help.cbp.gov/s/article/Article1833) · [CBP：海关税费说明](https://www.cbp.gov/travel/international-visitors/know-before-you-visit/customs-duty-information) · [TSA：安检可携带物品查询](https://www.tsa.gov/travel/security-screening/whatcanibring/all)。

## 返程后

- [ ] 保存申报、医疗、费用与保险索赔凭证，核对适用期限。
- [ ] 检查交易异常、漫游续费和药物补充。
- [ ] 把实际出现的问题写回私人清单。

**返程后若有异常：** 身份盗用用 [身份盗用举报与恢复（IdentityTheft.gov）](https://www.identitytheft.gov/)；航空或旅行文件问题回到实际承运航空公司与对应政府机关；医疗理赔按保险公司的官方理赔说明办理。
