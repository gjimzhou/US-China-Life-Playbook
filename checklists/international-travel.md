# International Travel Checklist

目标不是把旅行变成项目管理，而是避免少数高后果失误。

## Booking stage

- [ ] passport validity
- [ ] destination entry/visa rules
- [ ] transit-country rules
- [ ] trip cancellation strategy
- [ ] medical coverage abroad
- [ ] evacuation coverage if remote/high-cost destination
- [ ] rental-car coverage if applicable
- [ ] nonrefundable exposure understood

---

## 30 days before

### Health
- [ ] vaccines / destination health advice
- [ ] prescriptions sufficient
- [ ] controlled-medication import rules if relevant
- [ ] medication list
- [ ] travel medical insurance
- [ ] preferred hospital/assistance route for remote destinations

### Documents
- [ ] passport
- [ ] visa / permit
- [ ] travel insurance
- [ ] driver permit/license if needed
- [ ] secure digital copies
- [ ] emergency contact

### Money
- [ ] primary card
- [ ] backup card different issuer/network where practical
- [ ] ATM strategy
- [ ] small emergency cash
- [ ] card travel/security settings if needed
- [ ] no single wallet contains every payment method

---

## 7 days before

- [ ] airline reservation names match documents
- [ ] seat/baggage
- [ ] airport transfer
- [ ] roaming/eSIM
- [ ] MFA/recovery can work abroad
- [ ] home/pet care confirmed
- [ ] package/mail plan
- [ ] hotel addresses/offline itinerary
- [ ] weather/safety alerts

---

## Carry-on only critical items

Do not check the only copy of:
- passport/entry docs
- critical medication
- wallet/payment backup
- keys needed immediately
- high-value jewelry/watches if you cannot tolerate loss
- laptop/critical work data where policy allows
- irreplaceable item

---

## Phone loss plan

Before leaving:
- [ ] device tracking enabled
- [ ] strong passcode
- [ ] eSIM/SIM recovery understood
- [ ] password manager recovery
- [ ] backup payment not in phone-only wallet
- [ ] carrier contact
- [ ] cloud photo/identity document security

---

## US citizen resources if applicable

- [ ] State Department travel advisory reviewed
- [ ] STEP considered for destinations where useful
- [ ] nearest embassy/consulate awareness

https://travel.state.gov/

---

## China travel / long stay

- [ ] China mobile number active
- [ ] WeChat/Alipay work
- [ ] bank login works
- [ ] ID/passport appropriate
- [ ] hospital app/payment
- [ ] local emergency contacts
- [ ] work-from-China/tax implications if stay changes
- [ ] cross-border document need

---

## High-value items

For jewelry/watches/cameras:
- [ ] insurance territory
- [ ] scheduled coverage
- [ ] hotel safe/storage strategy
- [ ] serial/photo/appraisal
- [ ] customs declaration if legally required
- [ ] no unnecessary public posting of real-time location/valuables

---

## Return

- [ ] customs declaration
- [ ] expense receipts if needed
- [ ] insurance claim deadlines
- [ ] roaming plan reset
- [ ] suspicious card transactions review
- [ ] medication restock
- [ ] incident lessons added to checklist
