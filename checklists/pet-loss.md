# 宠物去世、临终与身后处理清单

用于宠物自然死亡、意外死亡、重病临终或计划安乐死后的实际处理。详细医疗与日常照护见[第17章：宠物照护运行系统](../book/17-宠物Operating-System.md)。

> 如果宠物仍可能活着、死亡原因不明、存在中毒／创伤／传染病疑虑，先联系日常兽医或急诊兽医确认，不要仅凭外观自行判断或立即处置遗体。

## 如果宠物刚刚在家里去世

- [ ] 联系日常兽医或急诊医院，说明死亡时间、已知病史和是否存在中毒、外伤、传染病或其他异常情形。
- [ ] 询问是否需要送院确认、是否建议病理解剖（necropsy），以及遗体暂时保存和运输方式。
- [ ] 将其他宠物、儿童与遗体安全分开；需要搬动时按兽医建议操作。
- [ ] 不急着自行土葬、丢弃或跨州／跨境运输；先查所在地规定和住房规则。

## 如果正在考虑安乐死

- [ ] 让兽医解释当前症状、可逆性、疼痛／呼吸／进食／活动情况，以及继续治疗、舒缓照护和安乐死各自意味着什么。
- [ ] 询问地点：医院内、上门服务或当地允许的其他安排。
- [ ] 提前决定谁在场、是否需要镇静、何时付款、遗体之后如何处理。
- [ ] 想保留爪印、鼻印、毛发、项圈或其他纪念物，应在操作前告诉医院。
- [ ] 如果主人临时无法到场，确认谁有权代表作医疗决定；不要假设普通 pet sitter 自动具有该权限。

AAHA 当前面向宠物主人的临终照护说明明确建议与兽医讨论 comfort、euthanasia setting 以及 burial、cremation 或 necropsy 等 aftercare 选择。

**继续看：** [AAHA：End-of-Life Care for Pets](https://www.aaha.org/resources/end-of-life-care-for-pets/)。

## 遗体处理：先问“有哪些选择、最终拿回什么”

常见选择可能包括私人火化（individual/private cremation）、共同火化、土葬，以及部分地区可提供的其他服务；实际名称、是否单独处理、骨灰如何识别与交付必须向服务方书面确认。

- [ ] 问兽医是否直接代办，还是需要自己联系 crematory / cemetery。
- [ ] 要求书面列出服务内容、价格、运输、预计返还时间和返还物。
- [ ] 如果选择火化并希望取回骨灰，明确是否为单独火化、识别流程和容器。
- [ ] 如果考虑在自家或其他土地土葬，先查当地卫生、土地、租约／HOA 与环境规定。
- [ ] 若要把遗体或骨灰带到另一州或国家，先问目的地、承运方和有关主管机关，不能把人的跨境规则直接套给宠物。

## 是否需要病理解剖（necropsy）

在死亡突然、原因不明、怀疑中毒／感染、涉及其他动物安全，或诊断结果对家庭和兽医有重要意义时，可以询问兽医是否建议 necropsy、应多快安排、遗体应怎样保存，以及结果需要多久。

是否做 necropsy 是医疗与个人决定，不是所有宠物死亡都需要。

## 保险、医院账单与预付计划

- [ ] 先提交尚未完成的合资格治疗费用，再按保险公司的死亡／取消流程处理保单。
- [ ] 询问是否需要死亡证明、兽医记录或其他材料，以及 coverage 何时结束。
- [ ] 若有 wellness plan、预付护理套餐、药物自动续订、处方粮订阅、寄养或遛狗服务，分别取消并保存确认。
- [ ] 不要因为宠物已去世就直接拒付此前真实发生的医疗账单；有争议时先按医院／保险流程核对。

## 芯片、许可证与登记

- [ ] 登录 microchip registry，将状态更新为 deceased 或按登记机构流程关闭／备注记录。
- [ ] 如当地有 dog license / municipal pet registration，询问是否需要注销。
- [ ] 更新家中紧急信息表、宠物照护说明和备用照护安排，避免以后仍按旧资料行动。

## 家里还有其他宠物

其他动物可能出现寻找、叫唤、食欲或作息变化。保持日常喂食与活动相对稳定；若出现明显不吃不喝、持续行为改变或身体症状，联系兽医，不把所有变化都简单归因于“悲伤”。

## 人的悲伤也需要被当回事

宠物去世后的悲伤可以非常强烈。可以向自己的医生、治疗师、支持团体或宠物医院询问 grief resources。若悲伤演变为危机、自伤想法或无法保证安全，美国可拨打或短信 **988**；紧急危险时联系 911 或当地应急服务。

**心理支持入口：** [SAMHSA：Find Help & Support](https://www.samhsa.gov/find-help) · [988 Suicide & Crisis Lifeline](https://988lifeline.org/)。

## 最后做一次收尾

- [ ] 取回骨灰、纪念物和最终记录。
- [ ] 保存最终发票、保险理赔与取消确认。
- [ ] 处理药物时按兽医、药房或当地药物回收规则，不随意转给其他动物使用。
- [ ] 更新家庭日历、自动付款和宠物服务。
- [ ] 在情绪允许时再决定用品捐赠、保留或处置，不需要当天全部完成。
