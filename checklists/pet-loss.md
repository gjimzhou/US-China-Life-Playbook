# 宠物去世、临终与身后处理清单

> **内容性质：指南解读** 临终医疗决定由兽医结合病情判断；保险、登记、运输与土葬事项是向当地机构核对的问题，不是统一法律规则。

用于宠物自然死亡、意外死亡、重病临终或计划安乐死后的实际处理。详细医疗与日常照护见[第17章：宠物日常照护与应急安排](../book/17-宠物Operating-System.md)。

> 如果宠物仍可能活着、死亡原因不明、存在中毒／创伤／传染病疑虑，先联系日常兽医或急诊兽医确认，不要仅凭外观自行判断或立即处置遗体。

## 如果宠物刚刚在家里去世

- [ ] 联系日常兽医或急诊医院，说明死亡时间、已知病史和是否存在中毒、外伤、传染病或其他异常情形。
- [ ] 询问是否需要送院确认、是否建议病理解剖（necropsy），以及遗体暂时保存和运输方式。
- [ ] 将其他宠物、儿童与遗体安全分开；需要搬动时按兽医建议操作。
- [ ] 不急着自行土葬、丢弃或跨州／跨境运输；先查所在地规定和住房规则。

### 夜间联系不到原兽医时

**办事建议：** 查看原诊所官网或电话留言中是否列有非营业时间的联系安排；若无法接通，可搜索“所在城市＋急诊兽医”（emergency veterinarian），通过医院官网号码确认当前是否营业、能否接收。出发前说明宠物的实际状况，询问到院、暂存和运输要求；若不能接收，询问可联系的其他机构。不要仅凭搜索结果中的营业时间判断可以直接前往。

可按实际情况使用以下问法；尚未确认死亡时，不要把猜测说成已确定的事实：

> 中文：我的宠物在家中没有反应，我还没有请兽医确认。你们现在可以接诊吗？我应该立即做什么、怎样送来？如果不能接诊，我可以联系哪里？
>
> 英文：My pet is unresponsive at home, and a veterinarian has not assessed them yet. Can you see my pet now? What should I do immediately, and how should I bring them in? If you cannot see us, whom should I contact?

若已由兽医确认死亡，说明确认情况，再询问遗体接收与后续安排。这些问法用于联系服务，不代替急诊兽医的判断和指示。

## 如果正在考虑安乐死

- [ ] 让兽医解释当前症状、可逆性、疼痛／呼吸／进食／活动情况，以及继续治疗、舒缓照护和安乐死各自意味着什么。
- [ ] 询问地点：医院内、上门服务或当地允许的其他安排。
- [ ] 提前决定谁在场、何时付款、遗体之后如何处理；镇静等医疗方案由兽医解释并与主人讨论。
- [ ] 想保留爪印、鼻印、毛发、项圈或其他纪念物，应在操作前告诉医院。
- [ ] 如果主人临时无法到场，确认谁有权代表作医疗决定；不要假设普通宠物照护者（pet sitter）自动具有该权限。

美国动物医院协会（AAHA）建议与兽医讨论舒适程度、安乐死地点，以及土葬、火化或病理解剖等身后安排。

**继续看：** [AAHA：宠物临终照护](https://www.aaha.org/resources/end-of-life-care-for-pets/)。

## 遗体处理：先问“有哪些选择、最终拿回什么”

常见选择可能包括私人火化（individual/private cremation）、共同火化、土葬，以及部分地区可提供的其他服务；实际名称、是否单独处理、骨灰如何识别与交付必须向服务方书面确认。

- [ ] 问兽医是否直接代办，还是需要自己联系宠物火化服务方或墓园。
- [ ] 要求书面列出服务内容、价格、运输、预计返还时间和返还物。
- [ ] 如果选择火化并希望取回骨灰，明确是否为单独火化、识别流程和容器。
- [ ] 如果考虑在自家或其他土地土葬，先查当地卫生、土地、租约／业主协会（HOA）与环境规定。
- [ ] 若要把遗体或骨灰带到另一州或国家，先问目的地、承运方和有关主管机关，不能把人的跨境规则直接套给宠物。

## 是否需要病理解剖（necropsy）

在死亡突然、原因不明、怀疑中毒／感染、涉及其他动物安全，或诊断结果对家庭和兽医有重要意义时，可以询问兽医是否建议病理解剖、应多快安排、遗体应怎样保存，以及结果需要多久。

是否做病理解剖是医疗与个人决定，不是所有宠物死亡都需要。

## 保险、医院账单与预付计划

- [ ] 及时通知保险公司宠物已去世，同时核对未结医疗费用的理赔期限、所需材料、保单终止／退款及终止后提交既往费用的规则；不要为了等理赔结束而延迟必要通知。
- [ ] 询问是否需要死亡证明、兽医记录或其他材料，以及保障何时终止。
- [ ] 若有健康护理计划（wellness plan）、预付护理套餐、药物自动续订、处方粮订阅、寄养或遛狗服务，分别取消并保存确认。
- [ ] 不要因为宠物已去世就直接拒付此前真实发生的医疗账单；有争议时先按医院／保险流程核对。

## 芯片、许可证与登记

- [ ] 登录芯片登记平台，将状态更新为“已去世”或按登记机构流程关闭／备注记录。
- [ ] 如当地有养犬许可或市政宠物登记，询问是否需要注销。
- [ ] 更新家中紧急信息表、宠物照护说明和备用照护安排，避免以后仍按旧资料行动。

## 家里还有其他宠物

其他动物可能出现寻找、叫唤、食欲或作息变化。保持日常喂食与活动相对稳定；若出现明显不吃不喝、持续行为改变或身体症状，联系兽医，不把所有变化都简单归因于“悲伤”。

## 人的悲伤也需要被当回事

宠物去世后的悲伤可以非常强烈。可以向自己的医生、治疗师、支持团体或宠物医院询问哀伤支持资源。若悲伤演变为危机、自伤想法或无法保证安全，美国可拨打或短信 **988**；紧急危险时联系 911 或当地应急服务。

**心理支持入口：** [SAMHSA：查找心理健康支持](https://www.samhsa.gov/find-help) · [美国988心理危机热线](https://988lifeline.org/)。

## 最后做一次收尾

- [ ] 取回骨灰、纪念物和最终记录。
- [ ] 保存最终发票、保险理赔与取消确认。
- [ ] 处理药物时按兽医、药房或当地药物回收规则，不随意转给其他动物使用。
- [ ] 更新家庭日历、自动付款和宠物服务。
- [ ] 在情绪允许时再决定用品捐赠、保留或处置，不需要当天全部完成。

最后编辑与来源核验：2026-09-22。临终选择和身后处理入口已对照 AAHA 专业指南；具体遗体处理、土葬、运输、保险和登记规则依所在地与服务机构而异。
