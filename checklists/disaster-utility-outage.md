# 区域灾害、停电停水与暂时不能回家

> **内容性质：管理建议** 勾选项用于整理任务，不代表每项都是法律义务；期限、资格与合同要求按所在地和实际文件确认。

用于大面积停电、停水、极端高温／寒潮、洪水、风暴、空气质量事件、楼宇封闭或撤离后几天无法正常生活的情况。住宅维修和保险见[第07章](../book/07-保险与灾难风险.md)、[第09章](../book/09-住房物业与Contractor.md)与[第30章](../book/30-Household-Emergency-Runbook.md)。

人在境外、受灾的是另一处住所时，按[两地住所交接](two-country-living.md#两边都有人管住所和通知)确认现场联系人、物业与保险通知。当地禁止返回或现场不安全时，不要求亲友冒险进屋取证，先从官方／物业渠道核实可进入条件。

## 第一步：先判断“留在家里是否仍然安全”

- [ ] 查看当地应急管理部门、公用事业单位、楼宇／房东的正式通知。
- [ ] 火灾、燃气、一氧化碳、结构危险、快速上涨洪水或其他立即危险时先撤离／求助。
- [ ] 不为取物返回被官方限制进入或明显不安全的区域。
- [ ] 决定留在家里时，也要有“什么条件触发离开”的标准，例如温度、医疗设备、电梯、供水、空气质量或停电持续时间。

## 停电

- [ ] 查公用事业停供地图／通知，记录停供事件编号或预计恢复时间。
- [ ] 给手机与必要设备保留电量；优先通信、照明和医疗设备。
- [ ] 便携式发电机不能在住宅、地下室或车库内运行，即使开门也不安全；应在室外，距门、窗和通风口至少20英尺（约6米），并遵守制造商要求。
- [ ] 冰箱／冷冻食品是否安全按食品安全主管机关当前规则判断，不用“闻起来还行”作为唯一标准。
- [ ] 需要电力维持医疗设备或药物储存时，尽早联系医疗方、公用事业紧急援助项目或撤到有稳定电力的地方。

**停电安全入口：** [疾控中心：发电机、一氧化碳和停电应对](https://www.cdc.gov/natural-disasters/response/what-to-do-protect-yourself-during-a-power-outage.html)。

## 停水、煮沸饮水通知或水质问题

- [ ] 区分完全无水、低压、煮沸饮水通知（Boil Water）、禁止饮用（Do Not Drink）和禁止使用（Do Not Use）；处理方式不同。
- [ ] 只按当地供水单位／卫生部门的通知决定饮用、刷牙、烹饪、洗澡和冰块是否可用。
- [ ] 恢复供水后按官方指示冲洗管线／设备，不自行推断“水龙头出水就安全”。

**不要把所有水质问题都当作“烧开即可”。** 化学污染等情况下煮沸不能保证安全；禁止使用通知可能连皮肤接触也不允许。饮用、洗浴和宠物用水按本次通知处理。

**具体操作：** [疾控中心：三类饮水通知分别怎么做](https://www.cdc.gov/water-emergency/about/drinking-water-advisories-an-overview.html) · [疾控中心：停电后的食品处理](https://www.cdc.gov/food-safety/foods/keep-food-safe-after-emergency.html)。

## 不能回家时先建立 72 小时生活连续性

- [ ] 临时住所；
- [ ] 药物、医疗设备和处方补充；
- [ ] 宠物可入住地点、食物和药物；
- [ ] 孩子／父母照护；
- [ ] 工作设备与网络；
- [ ] 身份证件、支付方式、充电；
- [ ] 房屋、车辆与保险通知；
- [ ] 邮件／包裹／楼宇出入权限。

“72 小时”这里只是用于列出短期连续性需求，不代表官方统一要求你只能或必须准备 72 小时。

## 撤离

- [ ] 优先听从地方应急管理部门的撤离命令、路线和避难所信息。
- [ ] 带药物、证件、充电、基本衣物、宠物运输箱／牵引绳和照护资料。
- [ ] 告诉一个外部联系人你去了哪里；不要公开不必要的家庭空置细节。
- [ ] 酒店／亲友家／避难所是否接受宠物要提前确认。

**准备入口：** [Ready.gov：制定家庭应急计划](https://www.ready.gov/plan) · [Ready.gov：宠物应急准备](https://www.ready.gov/pets)。

## 房屋损失与保险

- [ ] 安全后拍照／录像，记录损失和临时减损支出。
- [ ] 尽快通知保险公司／房东／业主协会中实际相关的一方，取得理赔／事件编号。
- [ ] 只做防止进一步损失所需且安全的临时措施，重大修复先确认责任、保险与许可。
- [ ] 保存酒店、交通、食物、临时维修等收据，是否赔付由保单和事件决定。
- [ ] 灾后上门承包商仍需核验，见[第09章](../book/09-住房物业与Contractor.md)。

**人在中国，美国住所漏水、受灾或断电：先让两端有同一份记录**

第一通电话找现场可信联系人或物业，确认是否有人／宠物受困、谁已通知当地应急部门、当前能否进入。远程摄像头离线不能证明屋内安全；当地禁止返回时，不让朋友代为进屋拍照、复电或启动设备。停电安全按上面的CDC指引和本次地方通知执行。

1. **指定现场与远程各一名联络人。** 现场人负责向物业／应急人员反映情况并记录实际观察；本人联系房东、保险和维修单位。记地址、事件时间及两地时区、官方事件号、最新进入限制和下一次联系时间；不在公开群中贴空屋地址或门禁。
2. **把房屋服务与保险分开开案。** 物业／房东说明建筑和水电处置、可安排的人员；保险方说明报案、查勘、临时减损及收据要求。两边各拿一个编号，不把物业已报修当成保险已报案，也不把理赔号当成维修批准。
3. **只有安全且允许进入时再安排取证和减损。** 请现场人保存可安全取得的照片、受损清单和服务记录。维修方先写做什么、多少钱、紧急措施与永久修复怎样分开；问保险是否需先查勘及如何保留损坏物的证据。不要让亲友自行处理积水中的电器、燃气或结构问题。
4. **说明本人不在美国。** 问保险／物业是否接受远程查勘、现场协助人的授权格式、钥匙如何交付，以及谁能批准额外费用。需要材料时通过指定渠道发送，代理权限由各接收方确认；无人可到场时请物业或正式服务机构给可行方案及报价，不虚构有人值守。

**临时支出留一行记录：** 日期、付款人、用途、金额／币种、收据、谁授权、向哪个案件提交。临时住宿、清理、除湿、运输及永久修复分别问保障和限额；房屋空置或长期离境的事实如实告诉保险方，不凭“已经投保”推定一定赔。

恢复供电或水龙头出水后仍要核对进入、饮水及设备使用通知。由现场负责人确认实际可住、必要设施可用、受损项目处理状态；远程本人核对最终账单和理赔结果。仍不能入住时，延长临时安排并写下负责人和日期。**结案要有现场恢复确认及费用／理赔结果，不能只看停电地图变绿。**

2026-11-07局部复核：[CDC停电安全](https://www.cdc.gov/natural-disasters/response/what-to-do-protect-yourself-during-a-power-outage.html)及[NAIC房屋理赔](https://content.naic.org/article/what-you-need-know-when-filing-homeowners-claim)的安全、通知、照片与收据说明；远程协调是编辑建议，未核具体州规则、灾害援助资格或个人保单。

## 政府灾害援助不是保险替代品

重大灾害后，美国联邦紧急事务管理局（FEMA）／州／地方可能开放特定援助，但资格、申报窗口与可赔项目依具体灾害声明和项目而定。先查 [灾害援助查询（DisasterAssistance.gov）](https://www.disasterassistance.gov/) 与当地应急管理部门，不假设每次停电或风暴都存在联邦补偿。

## 恢复后做一次复盘

- [ ] 哪个联系方式失效？
- [ ] 哪种备用电源／饮水／药物不足？
- [ ] 谁不知道如何接手宠物、孩子或父母？
- [ ] 哪个保险或物业入口最难找？
- [ ] 是否需要把某项用品、联系人或文件加入家庭紧急表？
