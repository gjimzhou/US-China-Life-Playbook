# 区域灾害、停电停水与暂时不能回家

用于大面积停电、停水、极端高温／寒潮、洪水、风暴、空气质量事件、楼宇封闭或撤离后几天无法正常生活的情况。住宅维修和保险见[第07章](../book/07-保险与灾难风险.md)、[第09章](../book/09-住房物业与Contractor.md)与[第30章](../book/30-Household-Emergency-Runbook.md)。

## 第一步：先判断“留在家里是否仍然安全”

- [ ] 查看当地 emergency management、utility、building / landlord 的正式通知。
- [ ] 火灾、燃气、一氧化碳、结构危险、快速上涨洪水或其他立即危险时先撤离／求助。
- [ ] 不为取物返回被官方限制进入或明显不安全的区域。
- [ ] 决定留在家里时，也要有“什么条件触发离开”的标准，例如温度、医疗设备、电梯、供水、空气质量或停电持续时间。

## 停电

- [ ] 查 utility outage map / alert，记录 outage case 或 estimated restoration time。
- [ ] 给手机与必要设备保留电量；优先通信、照明和医疗设备。
- [ ] 发电机、燃烧设备只能按制造商和消防／应急安全规则使用，避免一氧化碳中毒。
- [ ] 冰箱／冷冻食品是否安全按食品安全主管机关当前规则判断，不用“闻起来还行”作为唯一标准。
- [ ] 需要电力维持医疗设备或药物储存时，尽早联系医疗方、utility emergency program 或撤到有稳定电力的地方。

## 停水、boil-water advisory 或水质问题

- [ ] 区分完全无水、低压、boil-water advisory 和 do-not-use advisory；处理方式不同。
- [ ] 只按当地 water utility / health department 的通知决定饮用、刷牙、烹饪、洗澡和冰块是否可用。
- [ ] 恢复供水后按官方指示冲洗管线／设备，不自行推断“水龙头出水就安全”。

## 不能回家时先建立 72 小时生活连续性

- [ ] 临时住所；
- [ ] 药物、医疗设备和处方补充；
- [ ] 宠物可入住地点、食物和药物；
- [ ] 孩子／父母照护；
- [ ] 工作设备与网络；
- [ ] 身份证件、支付方式、充电；
- [ ] 房屋、车辆与保险通知；
- [ ] 邮件／包裹／building access。

“72 小时”这里只是用于列出短期连续性需求，不代表官方统一要求你只能或必须准备 72 小时。

## 撤离

- [ ] 优先听从地方 emergency management 的 evacuation order、路线和 shelter 信息。
- [ ] 带药物、证件、充电、基本衣物、宠物 carrier / leash 和照护资料。
- [ ] 告诉一个外部联系人你去了哪里；不要公开不必要的家庭空置细节。
- [ ] 酒店／亲友家／shelter 是否接受宠物要提前确认。

**准备入口：** [Ready.gov：Make a Plan](https://www.ready.gov/plan) · [Ready.gov：Pets](https://www.ready.gov/pets)。

## 房屋损失与保险

- [ ] 安全后拍照／录像，记录损失和临时减损支出。
- [ ] 尽快通知 insurer / landlord / HOA 中实际相关的一方，取得 claim / incident number。
- [ ] 只做防止进一步损失所需且安全的临时措施，重大修复先确认责任、保险与许可。
- [ ] 保存 hotel、transport、food、temporary repair 等收据，是否赔付由保单和事件决定。
- [ ] 灾后上门 contractor 仍需核验，见[第09章](../book/09-住房物业与Contractor.md)。

## 政府灾害援助不是保险替代品

重大灾害后，FEMA / 州／地方可能开放特定援助，但资格、申报窗口与可赔项目依具体 declaration 和项目而定。先查 [DisasterAssistance.gov](https://www.disasterassistance.gov/) 与当地 emergency management，不假设每次停电或风暴都存在联邦补偿。

## 恢复后做一次复盘

- [ ] 哪个联系方式失效？
- [ ] 哪种备用电源／饮水／药物不足？
- [ ] 谁不知道如何接手宠物、孩子或父母？
- [ ] 哪个保险或物业入口最难找？
- [ ] 是否需要把某项用品、联系人或文件加入家庭紧急表？

最后编辑：2026-09-21。具体撤离、饮水、安全与援助指令应以当次地方政府、utility、FEMA / Ready.gov 及主管机关通知为准。
