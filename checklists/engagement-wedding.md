# 美国订婚到婚礼：手续、预订与当天安排

> **内容性质：筹备建议与办事分流** 不要求举行大型婚礼，也不规定由哪一方家庭付钱。登记要求按实际州、县或市核对；时间顺序是安排建议，不是全国统一的提前月数。涉及双方姓名、预算和宾客资料只填私人副本。

## 先确定你们究竟想办什么

把法律结婚、庆祝活动和婚后安排分开：可以仅办法律手续，也可以先登记、以后宴请，或在同一天完成。双方先决定规模、预算上限、地域、日期范围、哪些传统想保留或不参加，再向亲友作承诺。

- [ ] 列出希望到场的核心人员和大致人数，不先按场地最大容量邀请。
- [ ] 明确父母出资是赠与、借款还是附带约定，谁有选宾客或增加项目的决定权。
- [ ] 讨论双方最重视的三件事和可以省掉的事；给临时变化留可承受的余地。
- [ ] 戒指如需购买，核对尺寸、修改、刻字、交付、退换和保养；不把某个价格比例当成感情标准。

## 法律手续按四步分别确认

[USA.gov说明](https://www.usa.gov/marriage-certificate)：结婚许可（marriage license）允许结婚，结婚证明（marriage certificate）证明已经结婚。具体取得方式取决于所在地；不能把申请许可或拿到纪念证书当成全部手续完成。

| 步骤 | 联系谁、问什么 | 取得什么再进入下一步 |
|---|---|---|
| 申请许可 | 拟举行法律仪式所在地的县／市书记官或登记机构（Clerk／Registrar）；确认谁有管辖权、双方出席方式、身份资料、既往婚姻材料、翻译及预约 | 官方材料清单、预约确认、费用和付款方式 |
| 领取并核对许可 | 原发证机构；分别问等待期、许可有效期、可使用地域、姓名错误更正和改名选择 | 姓名等信息正确的许可；可举行仪式的日期范围 |
| 完成有效仪式并交回记录 | 当地认可的主持人（officiant）或民事仪式机构；问资格、见证要求、签字、谁交回、交到哪里和期限 | 双方知道谁负责交回；有可跟进的记录 |
| 取得认证副本 | 登记机关或官方生命事件记录机构（vital records office）；问何时入档、怎样申领认证副本（certified copy）、费用和送达 | 已登记并收到符合后续用途的副本，检查姓名和日期 |

表格是核对问题，不保证所有州都采用相同顺序或要求。网上填申请不一定等于预约仪式；仪式主持资格与婚礼司仪／主持节目是两回事。以新泽西为例，居民与双方均非居民的申请地点规则不同，见[州卫生部门婚姻许可说明](https://www.nj.gov/health/vital/registration-vital/marriage-licenses/)；这个例子不能推广到其他州。

**可复制询问：** 我们计划在〔地点〕举行法律结婚仪式。请确认应向哪个机构申请、双方需要提供的材料、等待期与许可有效期、主持人与见证要求，以及仪式后谁交回记录、如何取得认证结婚证明。

> We plan to marry in [location]. Which office should issue our license? What documents, waiting period, license validity, officiant and witness requirements apply? Who returns the completed record, and how do we obtain a certified marriage certificate?

已在别处合法结婚、只想再办庆祝活动时，先说明已有婚姻事实，不按首次结婚重新填报。证明在中国使用时，先问最终接收方要求，再看[跨境文件主章](../book/19-文件公证Apostille与跨境授权.md)。

## 先订相互依赖的安排

先协调日期、场地、人数与仪式资源，再确认必须配合这些条件的摄影、餐饮和其他人员。热门档期和定制物品可能需要更早联系，但不设人人适用的“提前一年”。有明确时间限制时，先问可提供的方案，再决定规模。

| 安排 | 下单前问清 |
|---|---|
| 场地 | 可用时段是否包含布置和撤场，人数、无障碍、天气备用、噪声／酒水／外部服务商规则、所需保险材料、清洁 |
| 餐饮 | 含哪些餐食与饮料、工作人员、餐具、最低消费、最后人数确认日、饮食限制怎样处理 |
| 仪式 | 法律手续由谁负责，语言、流程、音响、誓词、见证人与缺席备用人 |
| 统筹 | 是全面策划、当天协调，还是场地方只管本场地；具体谁接电话、催进度、处理迟到 |
| 宾客交通与住宿 | 住宿只是优惠码还是有人承担房量，取消条件、接送路线、迟到与行动不便者安排 |

比较完整总价和取消条件，步骤见[找服务清单](service-booking.md)。

## 化妆、摄影、鲜花与蛋糕分别确认

- [ ] **化妆与发型：** 试妆与正式服务是否同一人，人数、先后顺序和最晚完成时间；提前沟通产品敏感情况、旅费和补妆范围。
- [ ] **摄影与录像：** 看完整同类作品，确认实际到场人员、时长、必要合影、各地点移动时间、精修／剪辑和交付期限；照片宣传使用按双方约定。
- [ ] **花艺：** 用数量、尺寸、色系和用途说明需求；问缺货替代、花器归属、安装撤场及花束何时交给谁。
- [ ] **蛋糕：** 确认份量、设计、配料及过敏问题、配送保管、切分、餐具、蛋糕架归还；图片上的尺寸不等于适合自己的宾客人数。
- [ ] **服装与饰品：** 购买或租赁、修改和试穿、鞋与活动便利、归还和清洁分别安排；为晚交付留替代方案。

## 邀请与婚前活动

邀请只在日期和地点能落实后发出，写清回复截止日、是否包含伴侣／孩子、饮食收集、交通及穿着说明。预留一种不依赖网站账号的回复方式，便于长辈和境外宾客使用。

订婚聚会、婚前送礼聚会、单身派对、彩排晚餐均可按意愿选择，不是婚礼必备套餐。共同旅行先谈每人预算及退出方式，再订不可退款项目。具体问法见[聚会与人情往来](celebrations-social-support.md)。

## 婚礼前做一次交接

| 必须交接 | 负责人／备用人 | 完成确认 |
|---|---|---|
| 许可、证件、戒指及仪式用品 |  | 由谁携带、何时交给主持人 |
| 亲友与服务商到场 |  | 地址、入口、停车、电话、时间 |
| 音乐、发言、合影名单 |  | 最终版本、谁提示开始与结束 |
| 尾款、可选小费与额外费用 |  | 已包含什么、谁可批准加项 |
| 天气、迟到或人员缺席 |  | 什么时候决定换方案、谁通知 |
| 礼物、租用品与撤场 |  | 由谁带走、送回、检查损坏 |

- [ ] 把当天时间表交给真正执行的人，留出走路、换装、进食和休息时间。
- [ ] 让新人以外的人担任当天主要联络人；对方只承担明确答应的职责。
- [ ] 临时变化先确认影响范围，不在同一群聊中让每个人直接指挥服务商。

## 婚礼后还有哪些事

确认婚姻记录已交回、认证副本已取得；跟进照片影片、押金、租用品和未结账单；按双方意愿感谢来宾和帮忙者。婚礼账单结清不代表医保、税务、受益人、改名或证件已经办理，转入[婚后手续清单](marriage-checklist.md)。

完成标准：法律记录可查询或取得所需证明，服务交付与费用可对账，婚后需办事项有明确负责人和期限。最后编辑：2026-10-15。法律事实核验限于USA.gov的许可／证明区分和所链接新泽西申请地点示例；未审定全美各地手续。
