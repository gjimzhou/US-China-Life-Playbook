# Move Checklist — 搬家不是搬箱子，是 systems migration

> Public template：不要填写真实地址、账号或个人身份信息后提交到公开 repo。

## 6–8 周前

### Housing
- [ ] lease / purchase closing dates confirmed
- [ ] old-home notice / termination requirement
- [ ] elevator / loading dock / move permit
- [ ] mover booked
- [ ] building COI requirement
- [ ] parking / street permit if needed
- [ ] pet move rules
- [ ] storage decision

### Insurance
- [ ] renters/homeowners effective date
- [ ] valuables coverage
- [ ] umbrella address/property update
- [ ] auto garaging address impact
- [ ] flood/water risk review

### Utilities
- [ ] electricity
- [ ] gas
- [ ] water
- [ ] internet
- [ ] building services
- [ ] security/alarm

---

## 2–4 周前

### Government / Address
- [ ] USPS Change of Address
- [ ] state DMV/MVC
- [ ] IRS address process as applicable
- [ ] USCIS address update if legally required/applicable
- [ ] state/local tax account
- [ ] voter registration if applicable
- [ ] professional licenses if applicable

**Rule:** USPS forwarding does not update other institutions for you.

### Finance
- [ ] banks
- [ ] brokerages
- [ ] credit cards
- [ ] payroll/employer
- [ ] insurance
- [ ] HSA/FSA/retirement providers
- [ ] checks / billing address where relevant

### Healthcare
- [ ] insurer address
- [ ] PCP
- [ ] pharmacy
- [ ] specialists
- [ ] dental
- [ ] pet vet
- [ ] medical records if moving regions

---

## 1 周前

### Old home
- [ ] photograph condition
- [ ] maintenance requests documented
- [ ] utility shutoff/transfer confirmed
- [ ] mail area checked
- [ ] storage/basement emptied
- [ ] building keys/fobs inventory
- [ ] parking sticker/garage access

### New home
- [ ] smoke alarms
- [ ] CO alarms if applicable
- [ ] water shutoff location
- [ ] breaker panel
- [ ] emergency maintenance number
- [ ] building evacuation route
- [ ] lock / smart-lock reset
- [ ] internet live date

---

## Move day

- [ ] IDs/passports stay with you
- [ ] medication stays with you
- [ ] valuables stay with you or insured specialist mover
- [ ] laptops/critical documents not mixed into random boxes
- [ ] pet plan
- [ ] movers inventory / damage notes
- [ ] old/new meter/photo where useful
- [ ] keys/fobs handoff documented
