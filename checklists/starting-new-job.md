# 新工作入职：从录用确认到第一张工资单

> **内容性质：美国雇员入职的办事建议。** 适用于第一次工作或更换雇主；独立承包、自雇、实习及特殊职业要另核对关系与规则。录用、可开始工作、工资到账和福利生效是不同事项。具体日期以适用法律、雇主及计划文件为准。

## 接受之前把条件放在一起看

通过公司官网或已经核实的人事联系方式确认录用，不能只看邮件署名。要求得到可保存的书面条件，并标出仍未完成的背景调查、资格核验或其他条件。需要身份或工作许可衔接时，先联系负责的人事与合适的移民专业人士，不凭录用信自行推断可以开始工作。

| 要确认的事项 | 具体问什么 |
|---|---|
| 职位与关系 | 法律雇主是谁、向谁汇报、员工还是承包商、工作职责是什么 |
| 地点与时间 | 首日、工作地点、到岗／远程安排、时区、出差要求及是否允许跨州或境外工作 |
| 薪酬 | 年薪／时薪、发薪周期、奖金是否有条件、加班如何记录和处理、股权另有哪些文件 |
| 费用 | 通勤、设备、搬迁、培训哪些可报销，谁先付、需什么凭证 |
| 附带承诺 | 签约奖金或搬迁补助是否有返还条件；保密、知识产权及限制条款不懂时找专业帮助 |
| 福利 | 能选哪些计划、登记截止日、各自生效日、家属材料和员工承担费用 |

不要只用名义年薪除以月份安排房租。确认第一笔工资实际何时到账，给入职至发薪之间留现金安排。换工作还要协调旧单位离职日、设备归还与保障结束日，见[工作主章](../book/22-工作失业与Employee-Benefits.md)。

**招聘诈骗分流：** 要求存入“设备支票”后再向指定商家转钱或退还余款时，停止付款并从独立官方渠道核实。[FTC招聘诈骗说明](https://consumer.ftc.gov/articles/job-scams)提醒，这是假支票骗局的常见方式；银行暂时显示可用不证明支票最终有效。

## 入职前分别找对负责人

先请人事提供一份入职安排，包括入口、负责人、截止日和安全提交方式。不要把护照、社会安全号码或银行账号发进普通群聊。

| 对象 | 本轮应取得的答复 |
|---|---|
| 人事 | 签署材料、首日安排、身份及就业资格核验的具体流程、材料提交渠道 |
| 主管 | 首周目标、会议时间、工作地点、着装／安全要求、谁带你熟悉工作 |
| 信息技术支持 | 设备领取或配送、账号开通、多因素认证、远程接入及故障联系人 |
| 薪资部门 | 工资账户登记、预扣税表、工时提交方式、第一笔工资日期和工资单入口 |
| 福利管理员 | 每个计划的登记截止日、生效日、家属材料、未完成登记时联系谁 |

- [ ] 就业资格核验表（Form I-9）按雇主合法流程办理；先问实际需要的步骤与材料，不自行猜测接受哪些复印件或远程方式。
- [ ] 把有截止日的登记单独放进私人日历；没收到系统邀请就联系负责人，不以“系统还没开”为完成。
- [ ] 询问设备迟到、账号未开或首日联系人缺席时的备用安排。
- [ ] 离开旧单位时只带走依法和依政策可留存的个人工资福利资料，不复制公司客户、代码或商业资料。

如果对就业资格核验中的文件要求、国籍或移民身份差别待遇有疑问，可从[司法部移民与雇员权利部门](https://www.justice.gov/crt/immigrant-and-employee-rights-section)找官方帮助；这里不代替对具体要求是否合法的判断。身份维护见[第37章](../book/37-移民身份与文件维护.md)。

## 福利要登记并核对生效

为每项实际需要的福利填一行，不强制全部购买。阅读福利概要及对应计划文件，遇到冲突向管理员提出具体问题。

| 项目 | 截止日 | 计划生效日 | 提交确认／仍缺什么 |
|---|---|---|---|
| 医疗、牙科、视力 |  |  |  |
| 配偶／孩子加入 |  |  |  |
| 退休计划与受益人 |  |  |  |
| 寿险、失能及其他可选保障 |  |  |  |
| 医疗／托育账户 |  |  |  |

对比保费、实际医生网络、用药、免赔额与自付，而不只看工资扣款。退休计划询问默认登记、供款选择、雇主匹配、权益归属和受益人；不同医疗账户的资格不能仅凭名称判断。具体规则集中在[第22章](../book/22-工作失业与Employee-Benefits.md)，不在本页复制年度限额。

提交后保存确认，检查家属是否加入、保障是否生效。新旧医保若有空档或重叠，联系两边管理员核对，不在尚未确认时先取消旧保障。漏了登记立即询问适用补救，不保证可以补选。

## 首日到首周怎样开展工作

- [ ] 确认门禁、设备、账号和必要培训实际可用；遇到阻塞告诉主管影响了哪项任务。
- [ ] 与主管约定第一个具体交付物、优先顺序、完成标准及第一次反馈时间。
- [ ] 问团队使用哪些沟通渠道、何时需要回复、如何请假、报工时与报销；不靠观察加班最多的人推定正式规则。
- [ ] 认识直接合作的人，问清“这个问题找谁”；必要时预约简短介绍，不要求每个人立即带教。
- [ ] 记录问题和答复，涉及保密、客户或安全的任务先确认权限。

可以这样问主管：**为了避免先做错方向，我想确认本周最重要的交付、判断完成的标准，以及遇到阻塞时应联系谁。**

> Could we confirm this week’s main deliverable, what success looks like, and whom I should contact if I’m blocked?

试用期或阶段性评估以实际制度和约定为准，不假定全国都有同样期限，也不把“通过试用期”理解成之后不能解雇。

## 第一张工资单逐项核对

工资单（pay stub）用于看金额如何组成；银行到账仅能说明收到了一笔钱。首次发薪可能只覆盖部分期间，应先看对应日期。

| 核对项 | 不一致时带什么问题找薪资部门 |
|---|---|
| 计薪期间与工作量 | 覆盖哪几天，工时、时薪或固定薪资是否对应，有无漏报工时 |
| 税前收入 | 基本工资、奖金、报销分别列在哪里；报销不要直接当工资 |
| 扣款 | 预扣税、医保、退休及其他项目是否与选择一致，有无尚未开始或重复扣款 |
| 净额与到账 | 工资单净额、实际到账、账户分配及日期是否对应 |
| 后续更正 | 谁处理、何时答复、更正反映在哪张工资单上 |

预扣税不等于全年最终税额。新工作后可用[IRS预扣税估算工具](https://www.irs.gov/individuals/tax-withholding-estimator)评估联邦预扣并按需要向雇主更新W-4；准备近期工资单及适用的配偶收入资料。**该工具不适用于美国税务非居民**，需按其指向的专门说明处理；州税另核对。跨境及复杂情况见[税务主章](../book/14-美国税务与State-Residency.md)。

## 有问题时与完成标准

未到账、扣错或福利未生效：保存录用条件、选择确认与工资单，通过核实的薪资／福利入口明确提出具体差异及希望核查的结果。用[办事记录](service-follow-up.md)跟进；涉及欠薪、歧视、报复或安全问题时转入[工作权益清单](workplace-rights.md)，不能仅靠等待普通人事回复。

本轮完成标准：能实际开展工作，首个任务和反馈安排明确，工资与所选福利已核对；尚未解决的差异有负责人和跟进日期。不是要求第一天办完所有事。
