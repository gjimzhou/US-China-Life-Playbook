# 换手机或号码：两地账户迁移到实际可用

> **内容性质：数字生活操作建议。** 用于旧设备仍在、计划换机／换号码或运营商的情形。手机已丢失、被盗或账户遭接管，先用[安全事件清单](cyber-incident.md)和[两地号码恢复](two-country-living.md#手机丢了也能联系和付款)，不要继续按正常迁移操作。

## 今天先列依赖旧号码的账户

在旧设备仍可用时，列电子邮件、密码管理器、银行支付、工作学校、医疗、政府和交通账户。每项记下当前验证方式、恢复渠道、是否需要本人到场；密码、验证码和恢复码只存放在自己的受保护系统，不填进共享任务表。

分清三件事：搬数据、迁移电话服务、重新登记账户验证方式。照片已复制不代表银行已认可新设备，手机能上网也不代表原号码能接短信。

## 先问新旧运营商，不先注销

给官方客服实际手机型号、购买地区、本人所在地和希望保留／更换的号码，问兼容性、锁机、实体SIM或电子SIM（eSIM）、是否需本人在服务地区激活、费用和失败恢复方式。不要凭另一款手机或另一运营商经验判断。

若保留号码，向接收运营商索取所需账户资料、转移验证方式和先后顺序；在对方确认流程前不自行注销旧号码。若改用新号码，先列所有需要改绑定的机构，问旧号码还能保留多久、最终账单和号码释放时间怎样确认。

人在中国更换美国号码服务，或在美国处理中国号码时，直接说明境外位置，问是否有合法可用的远程途径；需要到场而无法完成，就保留现有可用服务并安排后续，不用他人实名或冒充本人绕过。

## 按这个顺序迁移与测试

1. 备份并确认能读到所需数据；工作设备先问单位管理要求。准备不依赖待迁移手机的联网和联系途径。
2. 在新设备登录主要账号，按各应用官方说明迁移验证器、通行密钥或恢复方式。没有确认新设备可访问前，暂不移除仍需使用的旧验证途径。
3. 按运营商确认的方法迁移电话服务；记录实际转移时间。以iPhone为例，[Apple的eSIM说明](https://support.apple.com/en-us/118669)明确转移方法取决于运营商，激活新SIM可能停用旧SIM；所以旧机还在手里也不保证能继续收短信。
4. 分别测试拨出／接听、普通短信和所需机构验证码；双卡确认发短信与数据使用哪条线路。用实际需要的银行、支付、工作和医疗账号登录，不只测试一个应用。
5. 更换号码时，逐项在机构官方渠道更新绑定、恢复号码和通知号码；某项失败就留下工单，保留适当旧途径直到解决，不把一次系统迁移当作所有机构同步完成。
6. 新设备经过关键账户验证后，按厂商步骤退出、抹除、移除旧设备和回收卡片；再交出旧机，保留交易与设备交接证明。

[Apple旧机交出前说明](https://support.apple.com/en-us/109511)要求先备份、转移再移除个人信息；仍登录云端时手动删照片等内容可能同步删除其他设备上的资料。安卓或其他品牌按本机厂商文档操作，不照抄iPhone菜单。

**人在另一国，什么时候可以交出旧机？**

先在私人记录里给每个关键账户写一行。由账户本人操作，协助者只帮记录结果；不要为了验收制造一笔转账或触发不必要的账户重置。

| 验收项 | 实际做什么 | 留下什么结果 |
|---|---|---|
| 主要邮箱、密码管理器 | 在新机确认能登录及读取所需资料；查看恢复方式是否仍只指向旧机／旧号 | 测试日期、可用恢复方式的类型；不记录密钥 |
| 两地银行、支付 | 在本人当前所在国家用正常登录流程测试，查看设备登记、绑定号码及通知设置 | 哪个账户通过，哪个需银行进一步核验 |
| 工作、学校、医疗 | 按机构要求登记新设备；遇管理限制交给单位IT或机构账户支持 | 工单、补件要求、下次联系时间 |
| 电话线路 | 分别检查通话、普通短信、实际需要的机构短信；不要用上网成功代替 | 哪条线路、哪一类功能失败；漫游及收费答复 |

若银行能登录但恢复号码还是旧号，继续标为未完成。若新SIM激活后旧SIM已停用，旧手机不能作为收码后备；先用事前准备的独立联网／联系方式找运营商，再用银行认可的核验方式处理账户。不能因为回收旧机的预约快到了就删掉尚未迁出的验证器。

**给客服的描述可以直接照填：**“我本人现在在〔国家〕，〔时间及当地时区〕换了设备／号码。普通短信〔能／不能〕收到，〔具体机构〕登录提示〔原文〕。请确认应由运营商还是账户支持处理、要什么本人验证材料、能否境外完成、是否收费及下一次跟进时间。”只在官方受理渠道提供必要身份资料，保留案件号。

全部关键项通过后再处理旧机交接；旧号码若仍有待改绑定的机构，向运营商确认可保留方案、费用和结束方式。取消另取生效确认并查最后账单，不把“号码不用了”当作停费。

## 卡住时按责任方分流

| 现象 | 联系谁、带什么 | 暂时怎样继续 |
|---|---|---|
| 电话服务迁移失败 | 新旧运营商官方客服，说明号码、设备、转移编号和当前能用的线路 | 请求明确恢复或补件方案，不重复删装eSIM碰运气 |
| 普通短信可收，银行验证码不来 | 银行官方安全／登录支持，说明当前号码类型、所在国家及刚换机事实 | 按机构提供的备用验证；不找陌生“代收码” |
| 验证器未迁移 | 对应账号恢复入口或单位IT，说明已有验证方式 | 使用预先保存且有效的恢复方式；不把密钥发给客服聊天中的陌生人 |
| 旧机已交出且发现账号残留 | 厂商账号管理与相关机构 | 依官方流程撤销会话、修改凭证及处理远程抹除；证据留存，不追踪或接触陌生持有人 |

**完成标准：** 两地实际需要的电话、通知、登录与付款功能逐项通过，旧设备和旧号码不再是唯一恢复途径，旧服务的最后费用有结果。真实运营商和设备测试由使用者执行，本页没有用软件测试替代真机验收。
