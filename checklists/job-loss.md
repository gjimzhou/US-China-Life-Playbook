# Job Loss Checklist

> 适用于 layoff / termination / involuntary separation 的 household routing。  
> 不替代 employment / immigration / tax legal advice。

## Same day

### Documents
- [ ] termination letter
- [ ] severance/release
- [ ] benefits notice
- [ ] equity/bonus documents
- [ ] recent paystub
- [ ] PTO balance
- [ ] employment agreement
- [ ] restrictive covenants
- [ ] lawful personal copies of prior tax/benefit records

Do **not** copy employer confidential/proprietary data.

### Deadlines
- [ ] severance signature deadline
- [ ] revocation period if applicable
- [ ] health coverage end date
- [ ] equity exercise/vesting deadline
- [ ] expense reimbursement
- [ ] unemployment filing
- [ ] immigration/status deadline if applicable

### Access
- [ ] personal contacts
- [ ] personal email/phone
- [ ] benefits portal
- [ ] retirement/HSA
- [ ] payroll/tax documents

---

## First 48 hours

### Health insurance
Compare:
- [ ] COBRA
- [ ] spouse plan special enrollment
- [ ] ACA Marketplace
- [ ] new employer coverage timing

### Cash
- [ ] household liquid cash
- [ ] monthly fixed burn
- [ ] tax reserve
- [ ] severance timing
- [ ] bonus/equity expected
- [ ] pause optional major spending if needed

### Legal
Consider independent counsel if:
- [ ] complex release
- [ ] discrimination/retaliation concern
- [ ] noncompete/nonsolicit
- [ ] large unpaid compensation
- [ ] employment dispute
- [ ] immigration dependency

---

## First week

### Government / benefits
- [ ] unemployment insurance
- [ ] state benefits
- [ ] COBRA election materials
- [ ] HSA/FSA
- [ ] retirement plan
- [ ] disability/life conversion if relevant

### Career
- [ ] resume/CV
- [ ] private accomplishment log
- [ ] recruiter list
- [ ] former colleagues
- [ ] alumni
- [ ] industry contacts
- [ ] references

### Household
- [ ] spouse knows plan
- [ ] parents/family communication as needed
- [ ] travel changes
- [ ] childcare/pet logistics
- [ ] recurring household commitments

---

## First month

- [ ] health coverage active
- [ ] unemployment flowing / status known
- [ ] severance understood
- [ ] tax projection updated
- [ ] state residency/work-location issue reviewed
- [ ] immigration plan if applicable
- [ ] retirement/HSA decision not rushed
- [ ] job-search cadence
- [ ] mental/physical routine maintained
- [ ] household runway updated

---

## Do not

- [ ] sign complex release immediately because HR is waiting
- [ ] assume COBRA is cheapest
- [ ] liquidate investments before computing cash runway
- [ ] move/relocate on day 1 without tax/legal implications
- [ ] copy employer files
- [ ] ignore immigration deadline
- [ ] stop health insurance by accident
- [ ] make career decision only from shock/anger
