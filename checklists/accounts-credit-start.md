# 初到美国开户、建立信用与离境后维护

> **内容性质：办理与财务安排建议。** 面向刚到美国、没有本地账户或信用记录，以及之后仍会往返中国的人。开户资格、税务身份、授信和境外服务由机构分别判断；不推荐具体银行、借贷额度或投资产品。

## 开户前先取得材料清单

第一步是联系实际网点或银行官方开户客服，说明本人现居国家、证件、是否已有美国地址及税号，问能否申请、须到场还是可在线办理。不要先把钱汇到他人账户当作“开户过渡”。

[消费者金融保护局开户清单](https://files.consumerfinance.gov/f/documents/cfpb_adult-fin-ed_checklist-for-opening-an-account.pdf)列出身份、地址与识别号码等资料；部分机构可接受外国护照，但不是所有银行都接受同一套文件。清单为2021年版本，实际材料和费用以当前产品答复为准。

把答复记在一页，预约前缺哪一项就先补哪一项：

| 向银行说明什么 | 索取什么答复 |
|---|---|
| 护照姓名、现有签证／居留文件、是否有社会安全号码或个人纳税识别号码 | 可接受的原件与辅助证明；没有某项时有无替代材料，不猜填号码 |
| 真实居住地址与收信地址不同，或刚入住还没账单 | 哪类地址证明可用、卡寄到哪里；不能用亲友地址掩盖实际居住情况 |
| 主要用于工资、房租、日常付款，之后可能长期在中国 | 是否服务该居住情形，境外登录、补卡、身份更新及客服怎样办理 |
| 预计余额、工资入账方式 | 开户存款、月费及减免条件、透支选择、ATM与汇款费用、关户条件 |

银行要求税务表格时，先确认适用身份；拿不准就问合资格税务人士，不因“外国护照”自动勾选非美国税务居民。账户用途与税务判断分开，见[跨境税务](../book/38-中美跨境税与Work-from-Abroad.md)。

## 申请到真正可用

1. 按官方渠道预约，带所列材料；核对姓名拼写、地址、账户类型和费用披露，保存协议副本。
2. 只通过银行认可方式存入自己可解释来源的资金；较大跨境款先走[汇款两端核对](cross-border-problem.md#汇款收款失败)。不要把“申请编号”当作已能收款的账户。
3. 收到卡后本人激活，设置独立密码和可用验证方式。实际测试登录、查看余额、低余额通知及一笔小额日常付款；尚未收到的钱不能按可用余额支出。
4. 取得银行提供的工资入账资料交给雇主薪资部门；首笔工资到账后核对，才确认接续成功。房租等扣款逐项设置并检查第一次执行。
5. 申请被拒或卡住，问原因属于材料、地址、账户审查还是其他资格；索取补件渠道和案件号。不要连续更改资料反复申请；已开账户受限转[账户受限清单](bank-account-restriction.md)。

可复制询问：“我有____证件，目前住在____，尚缺____。请给这款账户可接受的材料、总费用和实际办理方式；如果不能办理，请说明缺哪项或哪类账户可另行评估。”

## 从第一张信用产品开始

先看自己是否需要信用产品、能否按时支付全额账单。普通存款账户、借记卡与信用账户不同。不要为了“建信用”借一笔用不上的钱。

1. 通过发卡机构官方渠道比较年费、利率、押金、还款和境外服务；押金担保信用卡（secured credit card）也要问是否、向哪些信用报告机构报送。押金不是以后每期账单的替代付款。
2. 按真实收入、身份和地址申请。没有记录或未获批时，先读正式答复，问能否补件或使用另一种适合的产品，不用付费“包装身份”。
3. 获批后只安排可负担的支出，记录出账与到期日期，核对自动还款账户及余额；首次还款后看是否实际入账，不能只看“已设自动扣款”。
4. 按官方入口查看自己的信用报告，检查账户和身份是否准确；有错误走报告机构／报送机构正式争议程序，身份盗用另用[网络安全清单](cyber-incident.md)。不承诺几个月达到某分数。

[美国消费者网站的信用说明](https://consumer.gov/credit/improving-your-credit)建议按期付款、控制债务并核对报告，也说明真实的负面记录不能由“信用修复”公司任意删去。报告查询从其官方链接进入，避免把付费监控订阅当作必须购买的服务。

## 回中国之前和抵达之后

在旧手机和号码仍可用时，向银行更新真实联系资料，确认境外认证、补卡寄送、到期续卡、纸质通知和客服时间。用[设备号码迁移](device-number-transition.md)验证新登录途径；不把验证码交给代收邮件的亲友。

列出每个账户的固定扣款、信用账单和预期入账，保留必要余额及通知渠道。抵达后按正常使用方式确认登录和下一期账单；无法登录时直接找银行恢复，不让亲友冒充本人操作。若银行不再服务实际居住情形，要求书面说明余额、未结账单、自动扣款和最终文件怎样转出，按[关户处理](bank-account-restriction.md)执行。

**完成标准：** 开户以实际可收付、卡与通知可用为准；信用维护以账单正确、还款实际入账为准；离境维护以两地都能合法联系机构、收到通知并处理付款为准。每阶段未完成项有具体负责人和下次跟进日期。
