# 跨境办事失败排查：文件被退、本人不到场、汇款失败、账户进不去

> **内容性质：管理建议** 勾选项用于整理任务，不代表每项都是法律义务；期限、资格与合同要求按所在地和实际文件确认。

**人在美国，要让国内亲友代办：** 先看[本人不能到场](#本人不能到场)，先取得具体业务的代理要求再安排签署。**美国出具的文件要交中国机构：** 看[公证／认证分流与新泽西实例](#对方说需要公证认证)。已经退件的，先记录下面的信息，不急着再付一次认证费。

汇款失败或无法登录账户另用本页相应分支。基础设施见[第18章](../book/18-中美双栖生活基础设施.md)，公证／附加证明书／授权见[第19章](../book/19-文件公证Apostille与跨境授权.md)。

## 先把“失败”写成一个可验证的问题

不要只记“银行不让汇”“文件不认”。记录：
- 哪个机构、哪个具体业务；
- 提交日期和受理渠道；
- 被拒绝／退件的原文；
- 缺什么材料或哪一字段不一致；
- 案件／参考编号；
- 下一次补件或申诉期限；
- 对方给出的官方规则链接或书面要求。

## 文件因姓名或身份信息不一致被退

- [ ] 列出每份文件上的完整姓名、拼音／英文顺序、生日、证件号类型和签发机关。
- [ ] 向**接收机构**问清它接受什么桥接材料：结婚／更名文件、声明、翻译、公证、旧新证件、同一人证明等。
- [ ] 不要自己创造“通用同一人证明”并假设所有机构都会接受。
- [ ] 姓名差异的一般准备见[第19章第15节](../book/19-文件公证Apostille与跨境授权.md#15-姓名差异提前建立对照)。

**不要只把一张退件截图转给翻译或中介。** 把有差异的文件按“文件名称—签发机关—原文写法—需要关联到的身份”排成对照表，先问接收方要求更正原件，还是接受指定的关联材料。若是原件记载错误，找原签发机关申请更正；若是历史姓名变化，问接收方接受什么证据串联，不能在扫描件上自行改字。

可复制问法：“〔文件A〕写为〔原文〕，〔文件B〕写为〔原文〕，用于办理〔业务〕。请确认是哪一项不符、是否需要原签发机关更正，或可提交哪些姓名关联材料；翻译是否需保留原写法并附说明？”填写真实信息的对照表只通过正式受理渠道发送。

## 对方说“需要公证／认证”

**先把机构的一句话变成材料清单。** 找实际受理部门的办事指南、业务专线或正式咨询入口，而不是只向公证员问“能不能盖章”。把对方使用的原词、文件名和用途抄下来，再问下面这些区别。

| 接收方实际要的东西 | 先联系谁 | 拿到什么再继续 |
|---|---|---|
| 出生／婚姻等官方记录的认证副本 | 原登记或签发机关 | 符合用途的副本种类、申请资格和签发要求；不是自己复印后盖章 |
| 委托书上的签名公证 | 接收机构确认文字后，再问签署地公证员／主管机关 | 要采用的公证形式、到场或远程条件、证件及签署要求 |
| 附加证明书 | 文件来源地的指定主管机关 | 它能认证哪一签字／印章、前置材料、送件与退回方式 |
| 中文／英文翻译 | 最终接收机构，再找符合其要求的译者 | 是否翻全件与附页、译者声明／资质、装订和签章要求 |
| 姓名或事实本身不一致 | 原签发机关和最终接收机构 | 更正或关联材料要求；再加一道认证不能改正内容 |

向国内窗口可以这样问：“我在美国，拟提交〔签发州／机关、文件名称〕用于〔具体业务〕。请给文件版本、公证／附加证明书、翻译和原件要求，是否接受电子件预查，原件是否留存；如果贵处只受理部分手续，请告知下一受理部门。”预查不是正式批准，记录答复部门、日期和仍需正式审查的内容。

**先选认证路线，再付费寄件。** [美国国务院的申请准备说明](https://travel.state.gov/content/travel/en/replace-certify-docs/authenticate-your-document/apostille-requirements.html)区分联邦文件与州文件；州文件从签发州的主管机关办理，不因持有人现在住在另一州就改变文件来源。私人委托书另按实际公证所在地及接收要求确认。涉及公约适用范围的中国收件，[外交部现行简介](https://cs.mfa.gov.cn/zggmcgx/lsrz/jj/202607/t20260713_11981309.html)说明适用公文书加附加证明书后无需再办中国驻外使领馆领事认证；这不免除翻译、授权范围或接收方的其他要求。

**限定实例：新泽西州签发的婚姻证明，拟交中国机构。** 以下假设接收方已要求认证副本及附加证明书；其他州、联邦文件或私人授权书不能套用这条记录申领路线。

1. 从[NJ卫生部门：申请生命事件记录](https://www.nj.gov/health/vital/order-vital/)申领认证副本（certified copy），在申请中说明用于附加证明书。官网要求申请表、身份证明、费用及申请人与记录当事人的关系证明；按个人情况核对材料。不要选仅供家谱用途的普通证明（certification）。
2. 收到后核对姓名、日期和文件版本，再从[NJ财政部门附加证明书说明](https://www.nj.gov/treasury/revenue/apostilles.shtml)进入办理。该州说明不受理其他州的生命事件记录；不能把外州证明寄到NJ让其认证。
3. 打开官网链接的[在线申请入口](https://www.njportal.com/dor/apostille)，准备联系方式、每份文件描述、使用国家、处理方式、退件方式及付款资料。**在线支付后还要送原始材料和订单确认页**，不是付款即办完。普通与加急的送件方式和地址不同，按本次选项的说明核对。
4. 预算分开记“记录副本费＋附加证明书费＋支付服务费＋翻译费＋两程邮费”。2026-10-21读取的NJ入口列非收养用途普通服务每份25美元，另收信用卡2.50美元或电子支票1美元服务费；下单时重新核对。处理时长从收件入系统等条件计算，不把网上付款日当作承诺完成日。
5. 收回整套文件后核对底层文件、附加证明书和订单是否对应。NJ明确要求不要拆掉已附加的证明书。按中国接收方要求安排翻译和提交，再取得正式受理信息。

附加证明书认证的对象与文件内容、业务受理是不同问题；制度区别见[第19章](../book/19-文件公证Apostille与跨境授权.md)。上例不判断个人婚姻登记、户籍、财产或代理资格。

## 本人不能到场

- [ ] 先问该业务是否允许代理人、远程、邮寄或线上办理。
- [ ] 若允许代理，索取机构自己的授权委托书文字、身份文件和签字要求。
- [ ] 明确权限只覆盖需要办理的事项、期限和是否可转委托。
- [ ] 涉及银行、房产、公司、继承等高后果事项时，让当地律师／机构审核，不用网上宽泛模板替代。

**把“替我办一下”改成一项可受理的请求。** 先写清城市、机构、具体业务，以及需要亲友做的是递交、查询、领取，还是签署有法律后果的文件；这些动作不要合并为“全权处理”。

1. **国内接收方先答复能否代理。** 从当地政府官网找到具体业务办事指南；银行业务则从该银行官方渠道找到实际受理网点／部门。亲友可以先咨询，不能因有本人证件照片就代签。问是否有本人线上办理、邮寄或授权代理路线，是否必须原件及当场核验。
2. **索取格式与材料清单。** 要机构模板或认可的内容要求，列出本人、代理人、事项、范围、期限、签署／见证／公证、翻译及认证要求。不自行把账户密码、验证码或整套不相关证件放进委托书。
3. **文字先确认，签署后再按路线办理。** 可预查时先提交未签署草稿；涉及房产处分、银行资金、公司或继承，由适当的当地专业人士审阅实际权限与后果。问公证员是否必须在其面前签署，不先签好再要求补盖章。不要为省一次往返把授权扩大到所有财产。
4. **国内亲友拿一份实际窗口清单。** 告知去哪一部门、是否预约、带哪些原件、仅能办理什么、原件如何保管和退回。若对方改口说必须本人到场，请其明确哪一步不能代理、依据或办事指南，以及本人出行前还须准备什么。

可复制给接收方：“本人目前在美国，希望委托〔关系／拟代理人〕在〔城市〕办理〔具体动作〕，不包括〔不需要的权限〕。请确认是否受理、能否先审草稿、委托书格式、双方证件、公证认证及翻译要求、预约和原件留存方式。若不受理代理，请给本人远程或到场的办理路线。”

**如果两端答复不同：** 将国内接收方的原文交美国办理机构，说明需要证明的签名或事实；再把美国机构能够提供的具体文件形式反馈国内接收方。不要要求美国公证员证明其权限以外的事实，也不要让亲友到窗口解释一份双方都没确认的文件。不能对接时，先取得接收方可接受的替代方案，再决定是否必须本人回国。

**虚构情境：** 海外本人想让亲友领取一份国内档案材料。窗口允许代领，但给了专用委托书和证件清单。下一步是确认海外签署及原件形式，安排双方材料和领取预约；不是直接下载“全权委托书”去做附加证明书。若窗口明确只允许本人领取，增加认证也不会让代领变成可受理。

## 汇款／收款失败

- [ ] 先区分技术故障、银行合规暂缓、收款人信息不符、转账限额、制裁／反洗钱审查、资金用途文件或中国侧外汇／银行规则。
- [ ] 向发起行和接收行分别取得具体拒绝／暂缓原因。
- [ ] 核对收款人姓名、账号、银行识别码（SWIFT）／路由号码、币种与用途文字是否完全按收款行要求填写。
- [ ] 大额或异常用途准备资金来源、税务／交易背景等银行要求的真实材料。
- [ ] 不通过“拆小多笔”“换陌生人账户”等方式规避银行合规审核。

**情境：美国汇出方显示已完成，中国家人说没收到；或国内汇出已扣款，美国账户仍没有入账。** 先别再汇第二笔。汇出机构的“已发送”、收款行收到款项、收款人可使用余额是不同状态；请两边按同一笔交易的编号核查。

**第一步：汇款人整理原始回执，收款人提供银行认可的收款资料。** 不靠聊天记录重新拼账号。由收款人从本人银行官方应用、官网或开户网点取得本账户的境外汇入指引；问清账户是否接受本次币种和用途、姓名应怎样填写、账号和银行识别码、是否需中转行，以及可能的入账手续。美国银行的境内转账路由号码不自行当作国际汇入指令，具体以该账户指引为准。

| 私人记录 | 从哪里取、怎样用 |
|---|---|
| 汇出时间、金额和币种 | 原始回执与扣款记录；日期写清时区，不把两国日期差当成漏款 |
| 交易编号与预计可用日期 | 汇款机构回执；无日期时向原机构取得，不能用网上“通常几天”替代 |
| 实际提交的收款资料 | 订单详情，与收款行给的资料逐字比对；姓名、账号、币种、银行／分行不能只核一项 |
| 费用与预计实收金额 | 付款前报价和最终回执；区分额外支付的费用、从本金扣除的费用及标注为估算的项目 |
| 两边查到的状态 | 原文、部门、查询日期、各自工单及下次跟进日；截图遮去无关交易 |

例如[中国银行境外汇入说明](https://www.boc.cn/pbservice/pb4/200806/t20080626_762.html)列出户名、账号、开户行英文名称及路径信息，并提示中转费用可能造成实收减少。它是该行产品说明，不能据此给所有中国账户套同一代码、到账天数或自动入账保证。

**第二步：汇款人查出去的款，收款人查进来的款。** 从原订单的帮助／交易查询入口联系汇款机构，要求开启这笔款的追踪；收款人从自己的银行官方客服或开户网点联系跨境汇入业务人员。用同一份必要信息沟通，不把完整银行资料贴到论坛。

> 给汇出方：交易〔编号〕于〔当地日期时间〕汇出〔金额、币种〕，回执预计〔日期〕可用，收款人目前未收到。请确认现在是待审核、已发出、收到入账确认还是正在退回；请提供可供收款行查询的追踪编号或汇款确认文件、当前负责处理的机构、需要我补的材料及下次查询日期。若走银行电汇，请说明你们可提供哪种追踪信息，不只答复“发送成功”。
>
> 给收款方：本人等待〔汇款人／汇出机构〕的〔金额、币种〕汇款，汇出日期〔日期〕，追踪资料为〔编号／文件〕。请查是否收到、是否待补件、信息不匹配或已拒收；如需转交跨境汇入部门，请给受理编号及下一步。尚未收到时请说明查询结果，我会交汇出方继续追踪。

**按实际答复继续，不统一“再等几天”。**

| 查到的情况 | 谁做下一步 | 完成前应拿到什么 |
|---|---|---|
| 汇出方仍在核验 | 汇款人按原机构的安全渠道提交真实身份、资金来源或用途材料 | 缺项清单、补件收到确认及下一次查询日；上传成功不等于放行 |
| 汇出方说已发送，收款方查不到 | 汇款人把收款方查询结果交原机构，请其沿支付路径追踪；收款人配合提供认可的收款指引 | 可核查的状态／追踪答复，不由亲友自行猜某家中转行后反复打电话 |
| 姓名、账号或银行信息不匹配 | 收款行说明正确要求；汇款人问原机构能否更正、是否收费，或须撤回重汇 | 更正／撤回受理确认及最终结果；只在个人通讯录改名字不会修改已发交易 |
| 收款行已收到但要求补件 | 收款人问具体缺什么、在哪里提交、是否须本人到场、期限与不补件后果 | 收款行受理记录及款项实际可用状态；人在另一国时先问远程或代理条件 |
| 到了外币余额，原以为会收到人民币 | 收款人向银行确认入账币种、原订单是否包含兑换、如需兑换的手续和费用 | 实际可用余额与兑换确认；外币已入账不等于人民币可用，也不能直接判为汇丢 |
| 两边说正在退汇 | 汇款人向原机构索取退回原因、编号、金额币种和预计处理日 | 原付款方实际收到退回款，并解释费用／汇差；“已发起撤回”不等于已退回 |
| 实收少于回执预期 | 用相同币种对账，分别询问汇出费用、中转扣费、收款费用及兑换 | 逐项费用／汇率说明；有差额不直接推定盗扣，也不默认全部合理 |

如果发现不是本人授权的汇款，或收款指令疑似被替换，立即通过已核实的官方渠道报告并请求止付／追回，转[账户安全事件清单](cyber-incident.md)；不要把欺诈当普通到账慢，也不要为“解锁资金”向陌生账户再付款。

**美国汇出方向：取消与报错有适用范围。** [CFPB汇款权利说明](https://www.consumerfinance.gov/ask-cfpb/what-is-a-remittance-transfer-and-what-are-my-rights-en-1161/)介绍的保护，一般针对美国境内消费者通过符合条件的汇款服务商向境外发送超过15美元的款项；[规则定义](https://www.consumerfinance.gov/rules-policy/regulations/1005/30/)还区分账户类型及个人／家庭用途。其官方解释对一般消费者账户按账户所在地判断发送人所在地，预付账户另有分支；因此人暂时在中国，不等于从美国普通个人账户汇款就失去这项保护。仍须核对服务商、账户和用途条件，商业付款或中国汇往美国的款项不能直接套用。

对适用交易，CFPB说明付款后通常有30分钟免费取消窗口，但款项已被领取或存入收款人账户时除外。发现错误应立即联系原服务商；报错期限为其披露的资金可用日起180天，通常有90天调查期。**这些期限不是让收款人等90天才追款，也不是所有交易都能撤回的保证。** 按回执的取消／报错入口提交并保留接收记录；更早预约的汇款等特殊安排按实际规则核对，不把普通即时汇款窗口直接套用。

中国汇出方向，从原银行订单和柜面受理记录开启查询、更正或退汇，明确它要求的材料和实际期限；不照搬上述美国窗口。涉及中国外汇用途、结售汇或个人资格时，向受理银行提交真实情况确认，本节不新增通用额度结论，也不以亲友拆分或借名收款规避审核。

**虚构走查：** 某人在美国向国内家人汇款，回执预计周三可用，周四仍未入账。汇款人向原机构开追踪工单，家人带追踪资料问收款行；若收款行确认待补用途材料，就按其清单补件并确认入账。若仍查不到，原汇出机构继续追踪；在原款去向未明前，不因家人催促就重复发同一笔。另有紧急付款需求时，单独记录合法可用资金的付款安排，原工单继续保留。

**这笔款怎样才算办完：** 收款人确认正确币种的款项已实际可用，或汇款人确认退回款已到账；金额差异有费用／汇率解释，未解决争议有工单和下次跟进日期。仅有扣款截图、汇出成功通知或撤回申请，不算结案。与原机构沟通未解决的美国适用问题，可从[CFPB汇款问题入口](https://www.consumerfinance.gov/consumer-tools/sending-money/)转投诉；投诉不能替代正在进行的追款或临近的取消／报错期限。

## 中国手机号、银行或支付突然失效

- [ ] 先保证还有一条能与银行／运营商官方客服通信的路径。
- [ ] 区分手机卡／漫游、实名信息、证件过期、设备更换、风控、支付限额和账号冻结。
- [ ] 不要连续反复尝试触发更多锁定；记录每一步和客服工单。
- [ ] 需要现场处理时，尽早确认是否可授权、需要本人原证件还是可通过其他官方渠道办理。

验证码与换号的具体排查见[两地通信与账户接续](two-country-living.md#手机丢了也能联系和付款)。

## 跨境补件的完成标准

**寄出前按用途装一套可核对的材料。** 保存扫描件和私人清单：`案件编号／文件名称／版本或日期／份数／原件或副本／翻译对应件／退回要求`。向接收方确认地址、部门、收件人和案件识别信息，按其要求附说明页；无需提供的敏感资料不随件发送。原件唯一时先问有无可接受副本、如何补发及退回，不为扫描拆开认证装订。

把处理状态分开记：物流签收 → 机构登记入案 → 材料审查／补件 → 正式结果与原件退回。物流截图只能证明递送情况。机构迟迟未登记时，用运单、签收日、案件编号和文件清单询问收件部门，不立刻再寄一份原件。

| 新通知／退件原因 | 找谁处理 | 下次提交前保留的证据 |
|---|---|---|
| 副本或签发版本不对 | 原记录签发机关 | 接收方指定的副本要求、新申请编号 |
| 委托范围未覆盖要做的事 | 接收机构与审阅授权的专业人士 | 修改后的具体权限、重新签署与认证要求 |
| 翻译漏页或格式不符 | 译者，按接收方要求修改 | 原文页与译文对应清单、接收要求 |
| 附加证明书不是对应文件／签字 | 签发认证机关 | 原订单、整套扫描件、要求更正的具体位置 |
| 只说“不符合要求” | 原受理部门 | 哪份材料、哪一项、可接受替代、补件期限及渠道 |
| 时间赶不上补件期限 | 主管受理部门；涉法律程序同时求助专业人士 | 可否延期或先交部分材料的明确答复；申请延期不等于已获批准 |

可复制追问：“案件〔编号〕材料于〔日期〕由〔渠道〕送达。请确认是否已登记入案，缺哪份材料的哪一项，补件是否保留原案件，期限与送件渠道是什么？如需重做，请给可接受的具体形式。”

**完成标准：** 收到正式批准／签发／领取或其他终结结果，并确认原件去向；若仍待补件，保留下一步、负责人和期限，不能写为办结。与银行汇款相关的到账确认按该业务另行处理。
