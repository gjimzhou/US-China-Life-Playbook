# 跨境办事失败排查：文件被退、本人不到场、汇款失败、账户进不去

用于“我已经知道要办什么，但事情卡住了”的中美跨境场景。基础设施见[第18章](../book/18-中美双栖生活基础设施.md)，公证／附加证明书／授权见[第19章](../book/19-文件公证Apostille与跨境授权.md)。

## 先把“失败”写成一个可验证的问题

不要只记“银行不让汇”“文件不认”。记录：
- 哪个机构、哪个具体业务；
- 提交日期和受理渠道；
- 被拒绝／退件的原文；
- 缺什么材料或哪一字段不一致；
- case / reference number；
- 下一次补件或申诉期限；
- 对方给出的官方规则链接或书面要求。

## 文件因姓名或身份信息不一致被退

- [ ] 列出每份文件上的 exact name、拼音／英文顺序、生日、证件号类型和签发机关。
- [ ] 向**接收机构**问清它接受什么桥接材料：结婚／更名文件、声明、翻译、公证、旧新证件、同一人证明等。
- [ ] 不要自己创造“通用同一人证明”并假设所有机构都会接受。
- [ ] 姓名差异的一般准备见[第19章第15节](../book/19-文件公证Apostille与跨境授权.md#15-姓名差异提前建立对照)。

## 对方说“需要公证／认证”

继续追问四件事：
1. 哪一份原始文件？
2. 要 notarization、certified copy、apostille、consular service、translation 还是其他形式？
3. 谁必须签字、在哪里签？
4. 最终接收的是原件、纸质副本还是电子件？

“需要公证”经常不足以决定美国侧到底该找 notary、county/state authentication、Secretary of State、federal authentication 还是根本不需要这些步骤。

## 本人不能到场

- [ ] 先问该业务是否允许代理人、远程、邮寄或线上办理。
- [ ] 若允许代理，索取机构自己的 power-of-attorney / authorization 文字、身份文件和签字要求。
- [ ] 明确权限只覆盖需要办理的事项、期限和是否可转委托。
- [ ] 涉及银行、房产、公司、继承等高后果事项时，让当地律师／机构审核，不用网上宽泛模板替代。

## 汇款／收款失败

- [ ] 先区分 technical failure、bank compliance hold、recipient information mismatch、transfer limit、sanctions / AML review、资金用途文件或中国侧外汇／银行规则。
- [ ] 向发起行和接收行分别取得具体 rejection / hold reason。
- [ ] 核对 beneficiary name、account number、SWIFT / routing、币种与用途文字是否完全按收款行要求填写。
- [ ] 大额或异常用途准备资金来源、税务／交易背景等银行要求的真实材料。
- [ ] 不通过“拆小多笔”“换陌生人账户”等方式规避银行合规审核。

## 中国手机号、银行或支付突然失效

- [ ] 先保证还有一条能与银行／运营商官方客服通信的路径。
- [ ] 区分 SIM / roaming、实名信息、证件过期、设备更换、风控、支付限额和账号冻结。
- [ ] 不要连续反复尝试触发更多锁定；记录每一步和客服工单。
- [ ] 需要现场处理时，尽早确认是否可授权、需要本人原证件还是可通过其他官方渠道办理。

## 跨境补件的完成标准

不是“材料寄出”，而是：
- tracking 显示送达；
- 接收机构确认进入案件；
- 缺件状态清除；
- 获得正式批准／签发／到账；
- 或明确收到下一步书面要求。

## 常用官方入口

- 美国州级 apostille / authentication：从各州 Secretary of State 官方网站进入；
- 美国联邦文件认证：[U.S. Department of State — Authenticate Your Document](https://travel.state.gov/en/replace-certify-documents/authenticate-your-document.html)；
- Apostille Convention：[HCCH Apostille Section](https://www.hcch.net/en/instruments/conventions/specialised-sections/apostille)；
- 中国政务：[国家政务服务平台](https://gjzwfw.www.gov.cn/)；
- 中国领事服务与附加证明书：[中国领事服务网](https://cs.mfa.gov.cn/)。
