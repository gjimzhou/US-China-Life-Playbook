# 跨境办事失败排查：文件被退、本人不到场、汇款失败、账户进不去

> **内容性质：行动建议与个案核对问题。** 勾选项用于整理任务，不代表每项都是法律义务；期限、资格与合同要求按所在地和实际文件确认。

用于“我已经知道要办什么，但事情卡住了”的中美跨境场景。基础设施见[第18章](../book/18-中美双栖生活基础设施.md)，公证／附加证明书／授权见[第19章](../book/19-文件公证Apostille与跨境授权.md)。

## 先把“失败”写成一个可验证的问题

不要只记“银行不让汇”“文件不认”。记录：
- 哪个机构、哪个具体业务；
- 提交日期和受理渠道；
- 被拒绝／退件的原文；
- 缺什么材料或哪一字段不一致；
- 案件／参考编号；
- 下一次补件或申诉期限；
- 对方给出的官方规则链接或书面要求。

## 文件因姓名或身份信息不一致被退

- [ ] 列出每份文件上的完整姓名、拼音／英文顺序、生日、证件号类型和签发机关。
- [ ] 向**接收机构**问清它接受什么桥接材料：结婚／更名文件、声明、翻译、公证、旧新证件、同一人证明等。
- [ ] 不要自己创造“通用同一人证明”并假设所有机构都会接受。
- [ ] 姓名差异的一般准备见[第19章第15节](../book/19-文件公证Apostille与跨境授权.md#15-姓名差异提前建立对照)。

## 对方说“需要公证／认证”

继续追问四件事：
1. 哪一份原始文件？
2. 要公证、核证副本、附加证明书、领事服务、翻译还是其他形式？
3. 谁必须签字、在哪里签？
4. 最终接收的是原件、纸质副本还是电子件？

“需要公证”经常不足以决定美国侧到底该找公证员、县／州认证、州务卿办公室、联邦认证还是根本不需要这些步骤。

附加证明书通常证明签名、签署人身份及印章等来源真实性，不证明文书内容正确，也不自动赋予代理权限。先核对接收方需要什么，再选择认证路径。

**权威解释：** [海牙国际私法会议：附加证明书基础说明](https://assets.hcch.net/docs/6dd54368-bebd-4b10-a078-0a92e5bca40a.pdf)。

## 本人不能到场

- [ ] 先问该业务是否允许代理人、远程、邮寄或线上办理。
- [ ] 若允许代理，索取机构自己的授权委托书文字、身份文件和签字要求。
- [ ] 明确权限只覆盖需要办理的事项、期限和是否可转委托。
- [ ] 涉及银行、房产、公司、继承等高后果事项时，让当地律师／机构审核，不用网上宽泛模板替代。

## 汇款／收款失败

- [ ] 先区分技术故障、银行合规暂缓、收款人信息不符、转账限额、制裁／反洗钱审查、资金用途文件或中国侧外汇／银行规则。
- [ ] 向发起行和接收行分别取得具体拒绝／暂缓原因。
- [ ] 核对收款人姓名、账号、银行识别码（SWIFT）／路由号码、币种与用途文字是否完全按收款行要求填写。
- [ ] 大额或异常用途准备资金来源、税务／交易背景等银行要求的真实材料。
- [ ] 不通过“拆小多笔”“换陌生人账户”等方式规避银行合规审核。

## 中国手机号、银行或支付突然失效

- [ ] 先保证还有一条能与银行／运营商官方客服通信的路径。
- [ ] 区分手机卡／漫游、实名信息、证件过期、设备更换、风控、支付限额和账号冻结。
- [ ] 不要连续反复尝试触发更多锁定；记录每一步和客服工单。
- [ ] 需要现场处理时，尽早确认是否可授权、需要本人原证件还是可通过其他官方渠道办理。

## 跨境补件的完成标准

不是“材料寄出”，而是：
- 物流追踪显示送达；
- 接收机构确认进入案件；
- 缺件状态清除；
- 获得正式批准／签发／到账；
- 或明确收到下一步书面要求。

## 常用官方入口

- 美国州级附加证明书／认证：从文件签发地的指定主管机关进入，常见为州务卿办公室，具体以海牙国际私法会议主管机关目录及州官网为准；
- 美国联邦文件认证：[美国国务院：文件认证](https://travel.state.gov/en/replace-certify/authenticate-documents.html)；
- 《取消外国公文书认证要求的公约》：[海牙国际私法会议：附加证明书专区](https://www.hcch.net/en/instruments/conventions/specialised-sections/apostille)；
- 中国政务：[国家政务服务平台](https://gjzwfw.www.gov.cn/)；
- 中国领事服务与附加证明书：[中国领事服务网](https://cs.mfa.gov.cn/)。
