# 怀孕、妊娠丢失与生产：从发现怀孕到产后

这份清单处理几个很容易让人突然“不知道下一步”的场景：验孕阳性、孕期出现异常症状、怀疑流产、临产，以及生产后最初几周。美国医疗系统和保险流程见[第04章](../book/04-美国医疗系统怎么用.md)，新生儿参保和家庭安排见[第21章](../book/21-孩子教育Childcare与家庭规划.md)。

> 这不是产科诊断指南。怀孕期间和产后一年内出现严重或异常症状时，要明确告诉医疗人员“正在怀孕／过去一年内怀孕过”，并按症状紧急程度及时就医。

## 验孕阳性后，先建立产科入口

- [ ] 确认最后一次月经日期、既往妊娠史、当前药物／补充剂、主要慢性病和过敏。
- [ ] 联系 OB-GYN、midwife 或合适的产科入口，询问首次 prenatal appointment 应在何时、需要先做什么检查。
- [ ] 向保险核对具体 provider / hospital network、产科费用分担、化验／影像网络和 delivery facility。
- [ ] 不自行停用长期处方药；把怀孕信息尽快告知处方医生和产科。
- [ ] 开始整理 employer leave、short-term disability、FMLA／州假等可能相关事项，但不要假设所有假期自动带薪。

## 孕期出现异常症状时

CDC Hear Her 当前提醒：怀孕期间及生产后一年内都可能出现需要立即医疗评估的 maternal warning signs。严重头痛、昏厥、视力变化、发热、呼吸困难、胸痛、严重腹痛、明显出血／流液、胎动明显减少等都不应等到下一次普通产检再说。

**官方入口：** [CDC：Urgent Maternal Warning Signs](https://www.cdc.gov/hearher/maternal-warning-signs/index.html) · [CDC：Pregnant and Postpartum Women](https://www.cdc.gov/hearher/pregnant-postpartum/index.html)。

## 怀疑流产／early pregnancy loss

出血或腹痛并不一定代表流产，但需要医学判断。ACOG 当前患者资料说明，出现阴道出血／spotting、液体流出、组织排出或较重出血伴痉挛时应联系产科；确诊可能需要 ultrasound 和／或 serial hCG，而不是仅凭一次家庭验孕或一次症状判断。

- [ ] 联系 OB-GYN / urgent obstetric line，说明孕周、出血量、疼痛位置、是否晕厥／发热、既往 ectopic pregnancy 风险等。
- [ ] 不自行判断“已经流完”或“肯定没事”。
- [ ] 让医生说明 expectant、medication、procedure 等适用选项和后续确认方式。
- [ ] 问清何时必须去 ER、何时复诊、何时重复 ultrasound / lab。
- [ ] 如果这次妊娠结束，记得处理预约、保险账单、工作请假和情绪支持，而不是只处理身体部分。

**专业入口：** [ACOG：Early Pregnancy Loss](https://www.acog.org/womens-health/faqs/early-pregnancy-loss)。

## 临产或疑似破水

- [ ] 使用产科／delivery hospital 给出的 labor & delivery 电话，而不是临时搜索陌生医院。
- [ ] 询问 contractions、破水、出血、胎动变化等情况应该何时来院。
- [ ] 带身份证件、保险卡、药物清单和 hospital 要求的必要资料。
- [ ] 临时换医院或跨州生产时，network、records 与 prior authorization 可能需要重新核对，但紧急医疗不应因费用核对而延误。

## 生产后不要只关注婴儿

CDC 明确提醒，pregnancy-related complications 可在生产后一年内发生。产后继续保留 OB / postpartum 入口；遇到 Hear Her warning signs 立即求助。

- [ ] 安排 postpartum follow-up。
- [ ] 跟踪自己的出血、疼痛、伤口／切口、血压、发热、呼吸、情绪和睡眠异常。
- [ ] 如果出现自伤／伤害婴儿想法或其他危机，立即使用危机／急救服务。
- [ ] 新生儿参保、儿科、出生证明、Social Security 等行政事项按对应机构办理，不要假设医院全部自动完成。

## 新生儿保险和工作福利

出生通常触发 employer group plan / Marketplace 等 special enrollment 路径，但期限和生效规则不同。立即向 employer benefits / insurer / Marketplace 核对，保存提交与生效确认。

详见[第21章](../book/21-孩子教育Childcare与家庭规划.md)及[美国医疗系统](../book/04-美国医疗系统怎么用.md)。

## 心理与家庭支持

妊娠丢失、困难生产或产后情绪问题都可能带来显著心理负担。可从自己的 OB、PCP、therapist 或[非紧急心理健康服务清单](mental-health-care.md)进入；危机时使用 988／911 等适用入口。
