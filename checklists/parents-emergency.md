# 父母在中国住院：海外子女远程协助与应急资料

**父母已经住院：** 直接从[今天住院时如何分工](#今天住院时如何分工)开始，按现场、医疗沟通、缴费医保和病历分别办理，不必先填完空白表。

**提前准备：** 建议每位父母一份，在父母知情同意下填写[身份与联系](#身份与联系)及后续资料，并约定分享范围。详见[第20章父母养老与远程照护](../book/20-父母养老与远程照护.md)。

> 适用于海外家属协助中国住院事务。实际资料只填私人副本；流程中的分工建议不产生医疗或财务代理权限。

病情处理后，需要增加居家或机构照护时，继续用[照护变化清单](care-needs-change.md)找服务、安排首次到岗和缺勤替班；有转介或付款还不等于现场有人接手。

## 今天住院时如何分工

**情境：你在美国，父母在中国，刚收到“已经送医院”的消息。** 此时先解决“人在哪里、谁在场、医院下一步找谁”，再决定是否返程。尚未送医且存在紧急危险时，请当地在场者联系120；下面的资料整理不能延误急救。

1. **给现场人打电话，确认位置。** 要医院全名、院区、急诊／病区和已知的接诊信息，不只问“在哪家医院”。请对方确认患者现在由哪一组医护接手，并把医院官方联络方式发来。联系不上患者时，不凭转发消息中的收款码或私人号码付款。
2. **确定一个现场联络人和一个远程记录人。** 现场人负责向医院提交材料、问流程、接收通知；远程人整理资料、联系其他家属和查办事入口。约定下一次通话时间，同时记北京时间和美国当地时间，避免一方以为“明早”是自己的明早。
3. **向病区说明你在境外。** 请现场人问护士站：患者希望谁参加沟通，医院如何登记联系人、确认同意或代理权限；与负责医生沟通应怎样预约。患者不能表达时，直接问医院指定部门需要什么手续，不让家人自行推定签字权。
4. **只先发当前需要的资料。** 通过医院指定渠道提供当前用药、过敏、重要既往病史及相关报告。证件和完整病历只发给需要接收的人；没弄清药名时拍原包装和标签，不凭记忆填剂量。

**现场人可以直接问护士站：**“家属有一位在美国，患者希望由〔人〕参与沟通。请告诉我们应该登记谁的联系方式、需要什么同意或代理材料、何时可以和负责医生通话；现场临时离开时，谁能接收通知？”

| 当天要落实 | 谁执行 | 拿到什么才算落实 |
|---|---|---|
| 医院与患者位置 | 现场人 | 院区、病区和官方联络入口，已确认医护接手 |
| 医疗沟通 | 医院认可的联系人 | 沟通时间、联系方法、需补的同意／权限材料 |
| 证件和当前用药 | 能取得原资料的人 | 医院实际收到的材料清单，缺项另列 |
| 缴费与医保 | 现场人联系医院收费／医保窗口 | 患者对应缴费通知、官方渠道、医保待办与回执 |
| 当晚及次日照护 | 家属或经医院确认可入病区的照护人员 | 谁能在场、能做什么、离开时谁接手 |

**没有亲友能到场：** 先从医院官网找总机，请转急诊／所在病区，说明患者位置和自己在境外；问医院可提供哪些联系、陪护咨询或患者服务。需要聘请照护人员时，请病区确认准入、服务范围、交班和收费，再通过正式渠道签约；有人收费陪护不代表可以替患者作医疗决定。不要等买到机票才开始联系。

### 医生通话只记录这五类信息

| 要问的话 | 记录方式 |
|---|---|
| 目前已明确什么，哪些还在等检查？ | 把已确定与待明确分开，不把家属猜测写成诊断 |
| 下一步要做什么，谁需要同意，什么时候答复？ | 检查／治疗名称、医院要求的决定时间及联系人 |
| 有哪些变化需要立即通知医护？ | 按医疗团队原话记录，不自己补医学判断 |
| 后续结果何时出、谁解释、没消息找谁？ | 日期、科室或联系人、跟进方法 |
| 预计需要哪些院内／出院后的协助？ | 具体事情和所需人员，由团队确认 |

结束前复述：“我记下的是〔下一步〕，〔人〕在〔时间〕前处理〔事项〕，未出的结果由〔人〕跟进。哪里需要改？”家属内部指定一个人汇总问题，避免多人分别打电话却得到互不完整的信息。

### 押金、医保和病历分三个窗口处理

**缴费找收费窗口，医保找医院医保办公室／参保地经办机构，资料复制找病案室或病案科。** 不要求负责医生替家属解决账户登录、报销与复印问题。

- 收到缴费要求时，核对患者标识、医院／院区、用途、金额和官方付款入口。境外银行卡或应用不能支付时，请收费窗口说明医院支持的替代渠道；若由可信现场人垫付，约定金额并保存医院凭证，不把钱转给来源不明的“协调人员”。
- 跨省住院先按[医保办理顺序](#跨省住院--门诊时的医保检查)处理。钱已交不等于已经完成医保结算，备案提交也不等于医院已读到有效记录。
- 需要病历时，说明用途和具体材料：先拿临床团队当前能提供的摘要、已出报告与医嘱；完整住院病案何时归档、如何复制另问病案科。不要为了等全套盖章病历，耽误正在进行的医疗沟通。

**医院实例，仅适用于其当前办理要求：** [北京协和医院“就医须知”第9项](https://www.pumch.cn/medical_notice.html)列出住院病历代理复印所需的患者和代理人有效身份证件原件、代理关系法定证明材料及授权委托书。这个实例说明“我是子女”不能替代材料清单；其他医院先找官网的“病历复印／病案服务”，再问实际接收要求。

**病案科问法：**“患者在〔院区〕住院，我在境外，拟由〔人〕代办〔出院记录／检查报告／完整病案〕。请提供本院申请表和代办材料清单；是否接收电子申请或邮寄，哪些必须原件，何时可取，原始影像是否由另一科室提供？”把答复转给真正去窗口的人。医院不接受现有材料时，请其说明缺哪一项及可接受的替代方式，再决定是否办理跨境授权。

### 一条家属更新消息怎样写

以下为**虚构示例**，只演示信息组织，不是治疗建议，也不含真实患者资料：

> 北京时间10月17日19:00更新：已确认住在甲医院乙院区某病区。现场由A接应，远程由B整理资料。医院还在等待一项检查，暂不把家属猜测当诊断。A负责问明日沟通时间，并将正式缴费通知发给B核对；B今晚整理原用药包装照片。明日北京时间09:00再更新。是否返程尚未决定，A已确认能留到交班人到场。

消息应能让下一位家属接手，而不是只有“情况稳定／再观察”。新增消息写时间，保留未解决事项；医生确认变更后标注旧信息已失效。

### 出院前把在中国的后续接好

向医疗团队取得出院去向、最新药单、复诊安排、未出结果及需要及时求助的情况。现场人逐项确认：谁接回家，谁取得出院药，药是否实际领到，家中需要的协助是否有人执行。海外家属安排下一次远程联系，但不能用视频通话代替必须在场的照护。

取得费用明细、票据和医保结算信息，缺完整病案时记录申请人、领取／寄送方式和跟进日。**这次协助结束的标准**是下一处照护已经接手、药物与复诊有实际安排、待办有姓名和日期；不是海外子女落地或患者离开医院就算结束。

## 跨省住院 / 门诊时的医保检查

**先按下面顺序做，随后再勾选本节清单。** 先确认父母的参保城市与实际住院城市；医保是在中国哪一地参保的问题，不是海外子女持什么身份的问题。急救与治疗先由医院处理，家属并行办理结算手续。

| 顺序 | 到哪里、做什么 | 保存什么 |
|---|---|---|
| 1. 查已有备案 | 国家医保服务平台APP的“异地备案”专区，先查“备案记录”；留意是否在地方渠道已有记录 | 参保地、就医地、类别、生效状态与有效时间 |
| 2. 需要新办或更正时 | 按专区中的“异地就医备案操作指南”进入申请；按本人实际情况选类别、填就医地并提交要求的材料 | 申请编号、缺件／审核提示；不能只保存提交成功页面 |
| 3. 让医院再确认 | 现场人带有效备案信息到医院医保窗口，问本次住院是否能读到记录并按跨省直接结算办理 | 窗口答复、尚缺资料、失败提示与负责联系方 |
| 4. 结算前再看一遍 | 核对结算单上是否有医保结算及个人支付金额；不清楚的项目当场问窗口 | 结算单、发票、费用明细及未解决问题 |

栏目来自[国家医保局线上备案操作指南入口](https://www.nhsa.gov.cn/art/2023/10/20/art_114_11408.html)，其附件可查看申请和记录查询示例。页面布局变化时按栏目名称查找，不按旧截图位置盲点。代办使用平台允许的帮办功能及材料；需要本人核验而无法完成时，请参保地经办机构说明线下／授权替代流程，不借用他人身份登录。

**已经住院还没备案：** 联系医院医保窗口和参保地经办机构，明确说“尚未出院结算，拟补办备案”。[国家医保局2022年通知](https://www.nhsa.gov.cn/art/2022/7/26/art_104_8629.html)列明出院结算前补办备案和自费结算后按参保地规定申请手工报销的路径；[2026年说明](https://www.nhsa.gov.cn/art/2026/5/27/art_14_20753.html)继续说明支持出院前补办。不能据此保证每笔费用都可报销。

**平台登不上、审核未过或医院结算失败：** 在[国家医保服务平台](https://fuwu.nhsa.gov.cn/)查询参保地医保经办机构联系方式，请现场人同步问医院医保窗口。记录错误原文、发生时间、办理渠道和本次住院信息；分别询问是参保待遇、备案状态、医院联网还是费用项目的问题。境外无法使用短号码／应用时，让现场人协助核实官方长号码或到窗口，不反复交同一申请。

> **给参保地的问法：**“患者参保地是〔城市〕，正在〔省、市、医院〕住院，尚未／已经自费结算。备案显示〔原文〕，医院提示〔原文〕。请说明应补哪项材料、由谁处理，出院前可走什么途径；若需手工报销，请给材料清单、提交方式、代理要求和实际期限。”

已经自费结算的，先向医院索取正式票据、费用明细、出院记录及结算凭证，再按参保地清单补材料；是否撤销原结算重结或改走手工报销，由两边机构确认，不凭家属自行推测。

- [ ] 接近65岁时已记录联邦医疗保险（Medicare）首次参保期，以及是否因本人或配偶当前就业提供的保障而可延后B部分参保。
