# 第一次买车：从预算到提车与登记

> **内容性质：美国购车筹备与核对建议。** 新车、经销商二手车、私人交易及租赁规则不同。本页以购买自用车为主；州税、登记、检验和消费者权利向实际州主管机关核对，不设全国统一费用或退车期。

## 先确认买来做什么

列通勤距离、乘员、停车、是否需要充电、保险与维护预算。先比较公共交通、租车或继续使用现有车辆能否满足需求。预算分为购车总价、融资成本、保险、税费登记、停车、能源和维修，不只看月供。

向保险公司取得候选车型的报价；有具体车辆后再按车辆识别号码（VIN）核对。住处不能安装充电设备时，先确认实际可用的充电方式，不凭广告续航决定。

## 找车与询价

- [ ] 核对卖方身份、车辆所在地、VIN和实际里程；不要因催促先向不明收款方转订金。
- [ ] 向不同卖方索取同一范围的书面落地总价（out-the-door price），拆开车辆价格、税费、登记、经销商费用和附加产品。
- [ ] 问清报价有效期、优惠资格和是否绑定融资、置换或其他条件。
- [ ] 下订前写清车辆、金额、是否可退、取消及迟迟不能交付时的处理。

**询价话术：** 请按这辆车的VIN提供含所有费用的书面总价，列明附加产品，并说明哪些优惠要求使用你们的贷款或置换旧车。

> Please send a written out-the-door quote for this VIN, itemizing all fees and add-ons and any discounts that require dealer financing or a trade-in.

## 看车与独立检查

预约试驾前问驾驶证、保险、路线和随行要求。检查实际乘坐、视线、停车、儿童座椅空间及日常使用需求；驾驶中不操作手机记录问题。

二手车的历史报告不能替代独立技师购前检查。先问是否允许检查、谁支付、能否取得书面结果；拒绝检查时可选择放弃。报告、检查和卖方承诺相互核对，未解释的事故、维修或产权问题先查清。[FTC二手车购买指南](https://consumer.ftc.gov/articles/buying-used-car-dealer)说明独立检查的重要性及经销商《买方指南》（Buyers Guide）的用途；该指南要看车辆按现状出售还是提供哪些保修，不把它当作私人交易的统一文件。

核对VIN在车身、合同和产权文件中一致，查看召回信息及维修证明；[NHTSA召回查询](https://www.nhtsa.gov/recalls)用于继续查询，未显示召回不代表整车没有问题。私人交易须另向州机动车部门核对卖方产权、留置权解除、过户材料及付款交接方式。

## 融资、置换与合同分别看

| 项目 | 签署前取得的答案 |
|---|---|
| 贷款 | 年利率（APR）、贷款金额、期限、总还款、首期到期日及相关费用 |
| 附加产品 | 是否自愿、价格、保障范围、取消及退款条件；不理解先不签 |
| 置换旧车 | 置换价格、旧贷款余额、差额怎样处理、谁清偿旧贷、何时确认 |
| 融资状态 | 已最终批准还是仍有条件，未获批准如何处理，不能只听“先开回去” |
| 承诺维修／配件 | 具体内容、谁做、完成日期、是否另收费，写进交付文件 |

用相同车价、首付和期限比较融资，避免低月供掩盖更长还款。买车和融资合同分别逐项核对，取得完整副本，不签空白或金额不明的文件。不要默认签后有三天反悔权；具体退车政策和适用法律在签前核对。付款争议见[消费者主章](../book/16-银行信用卡消费者纠纷与诈骗.md)。

## 提车当天与后续登记

- [ ] 先确认保险实际生效，再按州规则确认合法上路所需登记、车牌或临时许可；不凭经销商一句保证代替文件。
- [ ] 核对车辆、VIN、里程、外观、承诺维修、钥匙、配件和合同一致，有缺项当场记录。
- [ ] 知道基本灯光、除雾、加油／充电和求助方式；不熟悉功能时先在安全停放状态学习。
- [ ] 收齐销售、贷款、保修和登记相关文件，明确谁提交、何时收到正式文件、逾期找谁。
- [ ] 检查第一期贷款通知与保险文件；置换有旧贷款时确认实际结清，不只看车辆已交出。

从[USA.gov州机动车服务入口](https://www.usa.gov/state-motor-vehicle-services)进入实际州机构，查税费、产权、登记、检验及截止日期；跨州购买尤其要确认在哪个州完成哪些步骤。

完成标准：车辆与约定一致，可合法且有保险地使用，产权／贷款／登记有文件或明确跟进，未完成维修有书面责任。后续保养和事故处理见[车辆主章](../book/08-车祸停车维修与责任.md)。最后编辑：2026-10-16；限定核对FTC二手车检查与买方指南，未审定各州手续或具体合同。
