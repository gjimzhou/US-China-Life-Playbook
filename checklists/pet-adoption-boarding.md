# 接宠物回家与离境寄养：从选择到接回

> **内容性质：照护安排建议。** 适用于准备接猫狗等伴侣动物回家，以及主人往返中国、动物暂留美国的家庭。动物健康、行为、用药和运输适宜性由兽医判断；收养合同、住房和寄养要求按当地机构核对。

## 先决定谁能长期照护

把未来已知的离境时间、住处限制、每日照护时间和能负担的常规／突发费用写下来。与同住者逐个确认意愿；一方只愿短时帮忙，就不要把对方列成长期照护者。住所能否接纳具体动物，向房东／物业按租约确认；不存在可持续安排时，可以推迟接养。

寻找渠道从所在地动物管理部门、正式收容机构或可核实的救助组织开始。例如[纽约市动物福利部门](https://www.nyc.gov/site/animalwelfare/resources/adoptions-and-foster-opportunities.page)列出本地领养和临时照护入口；纽约示例不代表其他地区资格、费用或许可。

## 首次接回家的办理顺序

1. **先问机构，再见动物。** 索取申请条件、面谈／探访方式、收费包含什么、需要哪些家庭或住房材料、能否与现有宠物按机构安排见面。对方只有聊天账号、拒绝提供实际机构与动物资料时不付订金。
2. **了解这只动物。** 向照护者问已知病史、疫苗与用药、饮食、行为、独处情况、与儿童／其他动物相处，以及尚不清楚的部分。新环境表现可能不同，不把一句“温顺”当作保证。
3. **签约前谈失败安排。** 看所有权、试养／临时寄养与正式领养的区别；问不适应、健康问题、退回或转交时联系谁、费用如何处理。替机构临时照护不等于取得动物所有权。
4. **预约新兽医并准备住所。** 给诊所说明动物种类、年龄和现有记录，问首次检查时间及紧急联系；按其建议准备运送工具、药物和照护。安排安全休息区、食水和卫生用品，避免接回当天无人照护。
5. **交接当天核对。** 对上动物身份与芯片号（如有）、签署文件、医疗记录、药物标签、食物和既有习惯；请原照护者实际演示需要的日常操作。不会给药或发现异常时向兽医确认，不自行改变剂量。
6. **到家后逐项接续。** 按适用要求办理芯片联系人、地方登记及后续医疗；记录谁已经收到更新。首次检查时请兽医核对记录缺项、后续计划及出现哪些变化要联系，不让家人自己猜。

收尾不是“动物已带走”，而是照护人和备用人都能执行、记录已转到新兽医、合同未决事项有人跟进。若动物不能适应或家中无法安全照护，先联系原机构及兽医商量替代；不要擅自转送、弃置或隐瞒重要病史。

## 离境寄养先做一次实际交接

第一步把离境与最晚可能返程日期、动物的照护任务交给候选寄养机构或看护者，确认有能力及实际名额。不能只问“能住几天”。

| 需要询问 | 希望得到的具体答复 |
|---|---|
| 健康与行为接收 | 所需记录、疫苗或检查、特殊行为与用药能否接收；由谁判断 |
| 夜间与应急 | 夜里谁在场、多久巡查、用哪家急诊兽医、如何转运和通知 |
| 全部费用 | 住宿、给药、特殊饮食、节假日、延长、取消及晚接费用，定金和退款条件 |
| 主人在中国 | 可联系时段、收不到电话时备用人、谁有权作哪些决定、怎样直接向兽医付款 |
| 接回安排 | 开放时间、延误时能否续住、能否由指定人代接及其证件要求 |

按动物需要与兽医意见安排短时试照看或试住；结束时询问实际吃喝、排泄、活动、应激与给药情况，判断是否要调整安排。适用资质直接向当地主管机关查，平台评分不代替许可。

## 出发前把用品、权限和两地联系人交清

准备带标签的用品与按原处方包装的药物，附兽医说明、喂食要求、必要健康记录、主人与本地备用人联系方式。请对方逐项确认收到、能做和不能做的事，必要操作由专业人员教会。钥匙或门禁交接留记录，家中看护只给必要访问权限。

向兽医和寄养方分别问自己的授权表、费用预授权和联系不到主人时的程序；“宠物保险联系人”不等于可代作医疗决定的人。涉及重大治疗，按兽医及有效授权处理，不用一条群聊消息替代正式手续。

人在中国时约定更新频率与具体记录，但不把照片替代照护。看护者临时退出，先让已同意的本地备用人确认动物当前安全，再联系能够实际接收的替代方；从旧方取得用品、已给药时间和异常记录后交给新方。宠物出现健康异常，联系兽医，不能等跨时区群聊投票。

## 返程延误与接回当天

航班变化立即向寄养方确认能否延长、增费与最晚接回时间；满房时由已获认可的本地人接到安全替代处，不默认门店会无限续住。

接回核对动物、用品、用药与剩余数量、照护日志和最终费用；有伤病或明显行为变化，先向照护者索取发生经过并联系兽医。清偿无争议费用，争议留书面记录；家中看护结束后回收钥匙和不再需要的权限。

跨境带动物另看[宠物往返规则与文件](../book/17-宠物Operating-System.md#17-出发前就检查回程)，不把寄养接收当成航司或口岸同意。2026-10-23：核对纽约市领养导航；本页未给临床建议、疫苗时间表或全国寄养规则。
