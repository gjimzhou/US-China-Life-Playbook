# 初次独立生活：入住、吃饭、家务与日常办事

> **内容性质：生活安排建议。** 适用于美国第一次自己住、与室友合住或搬到新城市。目标是能住、能吃、能出门、能付款和求助；不要求一次买齐用品，也不按住房大小或收入设标准。

签租约、押金和退租看[租房流程](rental-lifecycle.md)；搬运与地址更新看[搬家清单](move-checklist.md)。本页从“拿到住处之后怎样过日子”开始。

## 入住前先弄清谁负责什么

向房东、物业或宿舍管理方确认交钥匙、门禁、入住检查、水电气网络、垃圾、停车、洗衣、快递和报修的安排。租金里是否包含服务，以租约和书面答复为准，不能凭上一位住户的习惯判断。

| 事项 | 第一动作 | 确认完成 |
|---|---|---|
| 水、电、燃气 | 问物业哪些由住户开户、适用供应商、开始日期和是否需现场开通 | 确认服务实际可用、户名及计费起始日正确 |
| 网络与手机 | 核对地址覆盖、安装／设备、自购或租用、总月费与取消条件 | 实测连接，知道故障入口；设备归还要求可查 |
| 付款与邮件 | 核对正式收款入口、付款方式、邮箱和包裹领取规则 | 能收到通知，付款有凭证 |
| 交通 | 实际走一遍通勤／买菜路线，查当地运营方的班次、票价和末班时间 | 日常能往返，有迟到或服务中断的替代方案 |
| 安全与维修 | 记录物业普通及紧急报修渠道，按官方说明确认报警器和出口 | 知道危险时怎样离开与求助，普通故障有人受理 |

开通前问开户、押金、安装、设备及促销结束后的费用。陌生来电要求立刻换供应商或转账时，自己找到官方联系方式核实。房屋损坏按入住检查流程留记录，不为拍照进入危险区域。安全说明见[第01章](../book/01-不要意外死亡.md)和[住房主章](../book/09-住房物业与Contractor.md)。

## 第一晚只准备实际必需品

- [ ] 钥匙、门禁、手机充电和照明可用；钥匙锁在屋里时知道找谁。
- [ ] 有可睡的地方、床上用品、换洗衣物、洗漱用品、厕纸和必要药物。
- [ ] 有饮水、能吃的一餐、简单餐具及垃圾袋；没有厨房时先安排可持续的用餐方式。
- [ ] 有安全回家与第二天出门的方法；重要联系人不只保存在一个可能没电的设备里。
- [ ] 安排大型物品配送前量门、电梯和房间，不仅量商品尺寸。

按“今天要用、这一周会用、以后再决定”分三组采购。锅、桌椅和工具可以分次补，不把别人家的配置当成自己的购物清单。借物先约定归还与损坏处理。

## 买菜与做饭从几顿会做的开始

先选择两三种能重复完成的简单餐食，检查住处有哪些可用设备，再按实际份数写采购单。把主食、蛋白质来源、蔬果和自己需要的调味品分别考虑；外卖、食堂、方便食品与自己做饭可以组合，费用和身体需要自行调整。

| 环节 | 实际做法 |
|---|---|
| 去买之前 | 看已有食材、储存空间、接下来几天是否在家；避免重复购买大包装 |
| 购买时 | 比较同单位价格及真正能用完的数量；确认配料、过敏需求、储存说明和退换条件 |
| 回家后 | 先处理需要冷藏冷冻的东西；把开封／制作时间记在容器上，分出先用部分 |
| 开始做饭 | 先读完步骤，准备工具和食材；不熟悉的电器先看说明，不边开火边出门办事 |
| 吃完之后 | 处理剩余食物、清洁操作面和餐具；下次采购前检查库存 |

食品安全另按[FoodSafety.gov四步骤](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety)：清洁、分开生熟、达到安全烹调温度、及时冷藏。不同食物的温度和保存时间查该页及对应官方表格，不以气味或颜色代替安全判断。本页不提供个别疾病的饮食方案。

## 洗衣、清洁和垃圾安排到实际时间

| 事情 | 第一次先确认 | 每次怎样收尾 |
|---|---|---|
| 洗衣 | 衣物标签、共用洗衣机付款和预约、洗剂用量、烘干适用性 | 及时取走、晾干或收好；按设备说明清理用户应清理的部分 |
| 厨房 | 哪些工具和清洁产品适用于实际台面与设备 | 餐具、食物残渣和垃圾处理好，不让下一次做饭先处理上次残局 |
| 浴室与地面 | 产品标签、通风、表面适用性及工具分开使用 | 用品安全存放，发现漏水或损坏按流程报修 |
| 垃圾与回收 | 向物业或当地政府查收运日、分类、容器和大件预约 | 按指定地点放置，收回容器；电池与危险废物另查当地入口 |
| 耗材与维护 | 纸品、洗剂、灯泡等何时补，哪些维修归物业 | 先核对实际型号与责任，不自行拆燃气、电路或其他危险设施 |

清洁产品只按各自标签使用，不自行混配。不会操作、设备异常或存在安全疑虑时先停下，联系物业或有资格的服务人员。需要付费请人时看[找服务流程](service-booking.md)。

不强求每天做同样多：把餐具、垃圾和急需衣物列为当下必需，深度清洁留到有时间时。设备不能用时安排洗衣店、简单餐食等临时替代，同时跟进维修。

## 合住先讲清日常边界

入住前一起谈清租金、水电网、公共用品怎样分，访客和留宿、安静时间、宠物、公共空间、食物归属以及搬走如何交接。室友之间的约定不能自动改变每个人对房东或供应商的责任。

不要只约定“大家保持干净”。写成看得见的动作，例如“做饭后处理自己的餐具；垃圾满了由当周负责的人带出去”。任务按实际时间、能力和意愿安排，忙碌或生病时可以重新商量。

## 把账单与求助入口接起来

- [ ] 列房租、公共服务、手机网络、交通、餐食和其他实际支出，按工资到账日安排付款。
- [ ] 自动付款开通后仍看第一张账单和首次扣款；记录金额、到期日、取消与设备归还要求。
- [ ] 保存物业、常用交通、药房和就医入口；普通医疗预约见[美国医疗主章](../book/04-美国医疗系统怎么用.md)，紧急情况直接走当地应急入口。
- [ ] 找一位愿意联系的人，商量生病、被锁在门外或晚归交通中断时能帮什么；不要默认邻居或同事必须接手。

钱暂时不够时，先看[账单支付困难](bill-payment-difficulty.md)的联系和协商入口，不用忽略通知来拖延。真正的安全准备可继续使用[前30天清单](first-30-days.md)，不需要同一天全部完成。

## 报修时把问题说具体

说明房间／设备、什么时候开始、现在还能否使用、已做过哪些安全的检查，并问预计安排、进入住所方式和谁通知你。照片有帮助时通过正式渠道提供，不拍入证件或其他隐私。危险情况不要按普通报修排队等待。

**普通报修示例：** 厨房水槽从昨天起排水很慢，目前没有外溢。我没有拆管道。请确认怎样安排检查、预计时间，以及是否需要我在场。

> The kitchen sink has been draining slowly since yesterday. There is no overflow, and I have not taken the pipes apart. Could you confirm the inspection arrangements, expected timing, and whether I need to be home?

修好后试用并确认结果；仍有问题用[办事记录](service-follow-up.md)继续跟进。需要抵扣租金、提前解约等法律判断时，先查当地规则或寻求租客法律帮助，不凭本页生活建议自行操作。

完成标准：基本服务可用，能完成几顿饭与一次洗衣，知道付款和报修入口，合住责任已谈清，出现临时问题有替代办法。最后编辑：2026-10-15。食品安全来源核对只限所链接官方四步骤；具体租赁、服务费用和地方分类规则须按地点核对。
