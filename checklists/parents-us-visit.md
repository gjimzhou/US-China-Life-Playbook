# 父母赴美探亲：从准备到返程

> **内容性质：办事与照护安排建议**
> 适用于父母临时赴美探亲，重点是子女与父母怎样共同准备。已是美国公民、永久居民或计划长期迁居的父母，应另按本人身份核对；本页不替个人判断签证资格、承保结果或治疗方案。空白资料只在受保护的私人副本填写。

## 先商量这趟怎样过

先让父母说希望住多久、做什么、愿意接受哪些帮助，再安排预算和行程。把探亲、就医与照看孙辈的实际计划说清楚；不要把父母来访当成已经落实的长期照护人手。

| 一起确定 | 私人填写 |
|---|---|
| 预计抵离日期、可调整范围 |  |
| 住所、楼梯／洗浴是否方便、接送人及备用人 |  |
| 机票、保险、日常开支及未承保医疗费用由谁承担 |  |
| 父母想独自完成的事、需要协助的事 |  |
| 国内住所、宠物及需照护家人由谁接手 |  |

- [ ] 子女工作时，父母有可接受的出行、吃饭和休息安排。
- [ ] 约定双方都能提出缩短行程或调整相处方式，不把返程视为关系失败。

## 订不可退款项目之前

B-2访问签证允许探亲等临时访问，不能据此从事就业或永久居住。申请材料、面谈与申请步骤从受理使领馆核对；邀请信不是决定是否获签的保证，也不是国务院列出的访客签证必需材料。没有获签前，不宜先购买机票或作最终旅行安排。规则见[美国国务院：访客签证](https://travel.state.gov/content/travel/en/us-visas/tourism-visit/visitor.html)。

- [ ] 按每位父母本人身份检查护照、签证、过境要求和旅行目的，保存官方办理入口。
- [ ] 准备能如实说明的住所、联系人、费用安排和返程计划；不要背与实际情况不符的“标准答案”。
- [ ] 如果实际安排涉及长期固定照看孩子或其他可能被认定为工作的活动，出发前向合格移民律师说明具体安排，不能仅凭“家人之间、不付钱”自行认定。
- [ ] 持中国护照及十年有效B-1、B-2或B-1/B-2签证的中国公民，另核对电子签证更新系统（EVUS）登记；换护照或换相应签证后也重新核对。适用规则见上述国务院页面的中国公民部分；[EVUS官方办理入口](https://www.evus.gov/)。

## 医疗与用药先接得上

逐药填写、联系接诊者及药不够时的具体问法，使用[两地医疗接续流程](two-country-living.md#医疗交接跟着人走)，再按本页核对父母探亲身份与保险。

- [ ] 出发前向原治疗团队说明航程、停留时间、近期病情和在美活动，确认需要提前处理的复诊、检查及旅行安排。
- [ ] 请医生或药师核对跨时区服药、储存温度和途中备用方案；家属不要自行改剂量或把两边处方叠加。
- [ ] 用药资料包含通用名、剂量、用法、过敏史及开药医生联系方式，并准备必要的英文说明；保留原有标签包装，把途中需要的药放在随身行李。
- [ ] 逐药核对美国及过境地要求，确认数量、证明及是否属于受管制药物。处方或“自用”不自动等于进口许可，中药、补充剂也要按实际成分查。
- [ ] 若药物不能合法带足全程，出发前确认当地接诊、评估和续配路径；不要等药只剩最后几天才找医生。

[美国疾控中心（CDC）：携药旅行准备](https://wwwnc.cdc.gov/travel/page/travel-abroad-with-medicine)支持包装、用药记录和咨询安排；[美国食品药品监督管理局（FDA）：个人携带／寄送药物](https://www.fda.gov/industry/import-basics/personal-importation)区分旅客身份和药物类别。其外国访客说明不能直接套用于美国公民或永久居民；受管制药物还涉及美国缉毒局（DEA）要求。病历整理见[医疗交接主章](../book/06-医疗记录药物与跨境Continuity.md)。

## 保险拿条款逐项问

旅行取消保障与旅行医疗保障用途不同；既往疾病、除外责任和事先授权可能影响赔付。先读实际保单，再问具体情形，不能只凭产品名称或“保额很高”判断。参见[美国保险监督官协会（NAIC）：旅行保险种类与购买前问题](https://content.naic.org/article/consumer-insight-taking-trip-information-about-travel-insurance-you-should-know-you-hit-road)。

**先拿到能对应这次投保的文件。** 在销售页面找到完整保单样本、保障表和除外责任；下载后记产品全名、版本及报价条件。只有宣传页时，请销售方提供上述文件，再比较。问清谁承保、谁负责协助、谁处理理赔，分别保存其正式联系方式；销售人员的微信不能代替报案入口。

**把父母的真实需求拆成问题。** 经父母同意，通过保险方指定的私密渠道说明年龄、居住地、旅行日期及健康情况。不要只问“有高血压能不能买”，要分别问投保资格、原疾病相关治疗、常规续药和新发生的伤病。以下是询问清单，不表示每张保单提供这些保障：

| 要问清楚 | 留存的答复 |
|---|---|
| 年龄、居住地与投保时间是否符合资格；美国是否在保障地区内 | 对应资格条款及生效时间 |
| 原有疾病如何定义；常规复诊、续药与急性发作分别怎样处理 | 对应定义、排除及限制条款 |
| 自付额、共同保险、单项限额及总限额怎样计算 | 一次门诊／住院的计算示例 |
| 哪里可就诊、是否需先联系、由谁垫付 | 协助电话、网络查询和授权程序 |
| 提前返程、延长行程、医疗转运分别如何处理 | 适用条件、办理及申报期限 |

**可以直接发给保险方：**

> 中文：父母居住在〔国家〕，年龄〔岁〕，计划于〔日期〕至〔日期〕在美国探亲。针对〔产品及版本〕，请分别指出原疾病常规复诊、处方续配、原疾病突然恶化和新发生伤病的适用条款、除外责任、分项限额及事先通知要求。请说明应联系哪家协助／理赔机构，是否需要先垫付，以及哪些材料必须在回中国前取得。
>
> 英文：My parent lives in [country], is [age], and plans to visit the US from [date] to [date]. For [product and version], please identify the policy terms, exclusions, sublimits and notification requirements for routine care, prescription refills, a sudden worsening of an existing condition, and a new illness or injury. Who handles assistance and claims, must we pay upfront, and which documents should we obtain before returning to China?

**虚构费用例子，只演示读条款的方法：** 假设一笔1,000美元费用全部属于某假想保单认可费用，该次尚未扣除的自付额为250美元，扣除后保险支付80%，且无其他限制，则保险支付600美元，本人支付400美元。真实账单若有不承保项目、认可费用差额、不同自付额累计方式或分项上限，结果会变；让保险方用同样的金额按拟买保单写一次计算。这里不是市场报价或典型赔付承诺。

如果答复只有“突发疾病都保”，继续要条款页码与定义；无法说明的项目写为“保障未确认”，不要在家庭预算里按可赔处理。保费之外，把日常药物、已知不保服务、临时垫付及改签分别列出，先商量能负担的范围；必要时缩短行程或调整安排，无须为了探亲购买昂贵活动套餐。

- [ ] 保存保单全文、投保信息和书面答复，记录无法承保但可能发生的开支。
- [ ] 选定非紧急就诊入口，并向诊所确认是否接收新患者、语言协助和付款安排；“保险网络内”不能替代实际预约。

## 随身资料与抵达后的三件事

准备一张父母自己能找到的联系卡：美国住址、两位联系人、保险协助入口和重要过敏信息。证件副本另存，不把密码、完整银行资料放在卡上。需要家属参与医疗沟通时，按父母意愿向机构确认同意及授权手续。

1. **确认顺利到住所。** 测试电话、网络、门锁和付款；走一遍附近路线，明确走失或联系不上时在哪里会合。
2. **查本次停留记录。** 从[美国海关与边境保护局（CBP）：I-94查询入口](https://i94.cbp.dhs.gov/)核对本人入境类别和获准停留截止日期，保存记录；发现错误及时按官方渠道联系更正。
3. **重新安排返程提醒。** 以本次获准停留日期安排提前处理的时间，不能拿十年签证有效期或机票日期代替。

签证不保证入境，也不决定每次可以停留多久；不要预设每次都是六个月。规则见[国务院：签证到期日与获准停留期限](https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/visa-expiration-date.html)。

**把“查记录”做完：** 在父母同意下，从上面的CBP官方入口查询本次入境记录，按页面要求填写本次旅行证件信息；逐人核对姓名、证件、本次入境日期、入境类别和获准停留截止日期。保存整份记录，再把截止日期和保险结束日期、药物用完日期、返程日期并排写入私人日历。不要拿行程历史列表或另一位家人的记录代替本人本次记录。

| 遇到的情况 | 下一步与完成证据 |
|---|---|
| 页面打不开 | 记网址与报错，稍后换网络或浏览器重试；父母手中的入境材料先保存，不猜截止日期 |
| 查不到本次记录 | 对照实际使用的证件逐项复查输入；仍查不到时，从CBP官方帮助入口提交问题，记录查询时间、入境口岸与日期，并按受理方要求提供材料 |
| 姓名、类别或期限疑似错误 | 联系CBP请求核查；附现有记录，说明哪一项与实际材料不一致，询问材料清单、是否需本人到场和后续查询方式 |
| 记录日期早于机票日期 | 及时安排符合获准期限的返程，或寻求合格移民法律帮助评估合法途径；不能自行认定记录写错，也不能等回复就默认可以多留 |

CBP签发记录的错误可向其延后检查办公室（Deferred Inspection）寻求更正；[CBP电子I-94规则说明第31页](https://public-inspection.federalregister.gov/2016-30459.pdf#page=31)解释该职责。实际联系从[CBP帮助入口](https://www.help.cbp.gov/)及[办公室目录](https://www.cbp.gov/about/contact/ports/deferred-inspection-sites)查，先问受理方式，不直接跑机场。各办公室当前材料、预约与办理时间须另外确认。**更正与延期是不同事项**：请求核查不会自动赋予更长停留期。收到更正通知后，重新取得记录并核对，不以“邮件已发送”作为办完。

可复制询问：“本人于〔日期〕经〔口岸〕入境，I-94显示〔原文／查无结果〕，与〔具体材料〕不一致。请告知受理部门、所需材料及安全提交方式，是否需要本人到场；后续如何确认记录已更正？”只在核实过的官方渠道提交证件资料。

## 生病或行程改变时

**在美国出现紧急危险或急症时，先拨911或寻求急救，不为查询保单、等待子女下班而延误。** 急诊就医权利不代表免费或保险必赔；[美国医疗保险和医疗补助服务中心（CMS）：急诊权利说明](https://www.cms.gov/priorities/your-patient-rights/emergency-room-rights)解释适用医院的筛查与稳定治疗义务。后续账单与拒赔见[美国医疗系统主章](../book/04-美国医疗系统怎么用.md)。

- [ ] 就医后取得用药和复诊说明，保存病历、费用明细及付款凭证；按保单通知与申报要求跟进。
- [ ] 想延长停留时，在现有获准期限届满前尽早核对延期途径和个人条件；不能把提交申请理解为已获批准，也不能只改返程票。入口见上述国务院停留期限说明。
- [ ] 同时重新确认保险能否续保、药物供应及国内责任接手，任一项不能接续时调整行程。

**非紧急就医前，分别打两通电话。** 先向保单指定协助机构说明症状与所在邮编，请其说明可用就诊入口、通知／授权要求及付款流程，记下经办人与参考编号。然后向诊所确认是否接收这位访客、能否安排翻译、当天服务及预付要求；报出保单上的实际计划和管理机构，而不只说“有旅行保险”。临床紧急程度交医疗人员判断。

**就医后，当天建一个私人文件夹。** 放就诊日期、机构名称、医疗摘要、分项账单、付款凭证和保险往来。按保单索取理赔表、通知与提交期限、材料格式和接收地址；提交后取得理赔编号或收件确认，另记下一次跟进日。医院提交账单与本人提交保险申请是两件事，向双方分别确认谁在做什么。

| 受阻情形 | 找谁、问什么 |
|---|---|
| 诊所说不接受这张保险 | 问能否自费接诊及书面估价；同时问保险方是否有其他可接诊机构、该处就医是否可报及需什么材料 |
| 收到缺件通知 | 对照缺件清单，向对应医院病历部门或收费部门索取；让理赔方确认收到补件及下一步，不重复寄一整包不相关资料 |
| 保险拒赔 | 要书面理由、对应条款和复核／申诉方式及期限；保留送达记录，不把销售人员口头“再等等”当作暂停期限 |
| 医院催款、保险尚未处理 | 联系医院账务部门说明理赔状态，询问账单复核或可用付款安排；取得实际答复，不假定理赔中就会停止催款 |
| 已回中国但仍有账单 | 用离境前保存的正式入口联系两方，确认境外联系方式、收款／退款方式和仍需本人签署的文件 |

**虚构情境：** 父亲已买保险，门诊仍要求先付款。先确认该次服务与费用，再向保险方问清垫付和材料要求；若已就诊付款，带走分项账单和付款凭证，按实际保单申请。付款收据不等于报销批准，医院说“我们可以看”也不等于保险说“这次可以赔”。

## 返程不是只送到机场

- [ ] 核对返程及过境文件、航班协助、接机人和途中用药。
- [ ] 如在美接受过诊疗，带回出院／门诊摘要、检查结果和最新用药表；约定由谁联系国内医生继续跟进。
- [ ] 保存实际离境记录，整理未结医疗账单、理赔编号与下一次跟进日期；回国后仍能收取通知。
- [ ] 撤去不再需要的临时访问权限和服务，同时保留尚未结案事项的联系渠道。

离境前由父母和协助人一起查看每一笔未结事项：`就诊日期／医院／账单编号／理赔编号／已付金额／缺件／下一步／负责人／跟进日`。提前测试回国后仍能使用的邮箱或联系渠道；若让子女继续沟通，按机构要求落实父母同意及授权。不要为了保留验证码把账户密码发给所有亲属。

**本次准备完成的标准：** 每位父母的文件、用药、费用和接送有人落实；抵达后核对了本次停留期限；未结事项能在返程后继续处理。反复往返另用[两地生活清单](two-country-living.md)，临时探亲不能替代长期迁居安排。
