# 重大诊断、住院与出院后的照护安排

> **内容性质：指南解读** 清单帮助联系医疗团队和核对安排，不用于自行诊断、换药或决定治疗；一般分工建议不等于医疗规范。

确诊重病、接受手术，或因中风、严重感染、骨折、慢性病恶化住院时，可以用这份清单记录医生的安排。出院前尤其要问清：回家后谁照护、药怎么用、有问题联系谁。

## 住院期间先确定一个信息协调人

- [ ] 记录主治医生／主管团队、主要专科、个案管理人员／社工、护士站和出院协调入口。
- [ ] 家庭内部确定一个主协调人，统一记录问题和任务，但不把协调角色误认为医疗代理权。
- [ ] 每次重大决定问：当前初步诊断是什么？已经排除什么？今天改变了什么？下一步决定点是什么？
- [ ] 记录尚未解决的问题，而不是只记“情况稳定”。

## 重大诊断后先拿到“下一步地图”

至少问清：
- 正式诊断／分期／严重程度；
- 还需要哪些确诊检查；
- 治疗方案与时间窗口；
- 哪个医生负责总协调；
- 哪些症状需要立即联系；
- 下次预约／检查／医疗操作；
- 哪些事情可以等第二诊疗意见，哪些不能拖。

不要只依赖口头解释。请求出院小结、病理／影像报告、药物清单和可带走的记录。

## 出院前逐项确认

联邦医疗保险（Medicare）／医疗保险和医疗补助服务中心（CMS）的出院计划清单强调患者和照护者在离开医院、护理机构或其他照护机构前，应拿到后续照护所需信息。

- [ ] 回家后谁实际照护？
- [ ] 能否安全上楼、洗澡、上厕所、吃饭和取药？
- [ ] 伤口／引流管／导尿管／氧疗／行动辅助设备怎样使用？
- [ ] 每种药：开始、停止、改变剂量的原因是什么？
- [ ] 哪些旧药现在明确不要再吃？
- [ ] 居家医疗服务、物理治疗／作业治疗（PT/OT）、耐用医疗设备（DME）是否已经真正安排，而不是“有人会联系”？
- [ ] 复诊预约是否已有日期或明确预约责任人？
- [ ] 哪些症状打医生，哪些去非危重急诊诊所／医院急诊，哪些直接 911？
- [ ] 谁能在夜间和周末回答问题？

**官方工具：** [Medicare：出院准备清单](https://www.medicare.gov/publications/11376-your-discharge-planning-checklist.pdf) · [医疗保险和医疗补助服务中心（CMS）：患者参与照护](https://www.cms.gov/medicare/provider-enrollment-and-certification/qapi/consumer-engagement)。

**如果认为出院太早或回家不安全：** 当场向主管医生、出院协调人员说明具体困难，索取书面出院计划与适用申诉通知，不只口头要求“再住几天”。

使用联邦医疗保险（Medicare）时，住院出院和专业护理／居家医疗等服务结束可能适用不同快速申诉程序与期限。医院情形应按《联邦医疗保险权利重要通知》（Important Message from Medicare）办理，官方说明通常要求不迟于计划出院当天提出；其他适用照护机构的期限通常为终止日前一天中午。以本人实际通知及适用程序为准，错过期限可能改变费用责任。商业保险不能直接套用此程序。

**及时操作：** [联邦医疗保险：快速申诉、通知及期限](https://www.medicare.gov/providers-services/claims-appeals-complaints/appeals/fast-appeals)。病情突然恶化应立即告知医疗人员，不等待申诉结果。

**出院后服务没来、结果没人接手时**

离院前把尚未完成的事项写成“事项—接收机构—联系人—约定时间”：例如设备由谁送、第一次上门由谁确认、待出的病理结果由哪位医生解释。让出院团队核对接收方是否已接受转介，并给一个联系不到时的备用入口。这是家庭交接记录，可配合上面的官方出院清单使用。

- 设备或上门服务未按约到达：先向供应方查订单／转介编号与缺件，再把具体缺口反馈给出院协调人，要求确认替代安排。若实际照护者无法承担任务，要明确说出哪项做不了，不能仅答复“家里有人”。
- 检验结果已出但无人解释：联系原检查／出院团队，确认由谁审阅、何时回电、结果是否送到复诊医生；复诊医生没有收到时，按其指定方式补传并确认收件。家庭不自行解释异常或改药。
- 约定时间已过又联系不上：使用出院文件列明的值班入口；出现医嘱要求紧急处理的症状时按该指示或急救流程行动，不等待行政回电。

境外家属可以跟进联系和文件，现场照护者负责确认设备可用、人员到岗与操作理解。接手人或照护强度有变化，继续用[照护需求变化清单](care-needs-change.md)安排替班。结案保留实际服务日期、结果解释与后续计划；只有转介编号还不算服务已开始。

**准备出院后回中国，或从中国赴美继续治疗**

先把拟出发日期、航段／转机、途中照护者及目的地医疗安排交给治疗团队。拿到出院文件不代表适合长途飞行；请团队说明是否需要延后、医疗证明、途中设备与照护安排，再向实际承运航司核对受理要求。不要依据某种手术的网络经验自行定起飞日期。

[CDC慢病旅客准备清单](https://www.cdc.gov/yellow-book/hcp/travelers-with-additional-considerations/travelers-with-chronic-illnesses.html)要求结合病情、目的地和运输方式准备，并提前联系航司；医疗证明不保证航司最终接受运输。[CDC航空旅行说明](https://www.cdc.gov/yellow-book/hcp/travel-air-sea/air-travel.html)特别提醒需氧旅客分别安排出发地、转机和到达地的地面供氧。是否需氧及怎样使用由医疗团队决定，设备接受条件由实际航司确认。

出发前用下面四项取得两端答复，不只让家属口头说“回去再看”：

| 要接续的事 | 原治疗地问谁、要什么 | 目的地落实什么 |
|---|---|---|
| 下一次诊疗 | 主管团队给复诊／治疗计划及可等待范围 | 接诊机构确认收到所需材料、实际预约与缺件；问诊费、押金及保险／付款入口 |
| 病历与未出结果 | 病案部门提供摘要、报告及所需影像；原团队明确谁追踪待出结果和解释 | 接收医生／机构说明格式、语言及接收渠道；确认收件，不能仅凭“已发送” |
| 用药与设备 | 医生／药师核对药物通用名、规格、用法和接续需要；设备方提供操作资料 | 接诊医生与药房确认当地获取途径及是否需重新就诊开方；设备供应方确认交付、费用和教学 |
| 途中与落地照护 | 实际照护者向团队复述照护任务和异常处理；航司确认所需材料及提交时间 | 接应人确认到达、交通、可入住处和当天能做的照护；夜间求助用所在地入口 |

药物入境与携带要求另按[跨境用药主章](../book/06-医疗记录药物与跨境Continuity.md)核对，不能凭外国处方推定当地药房必定配药。待出检查结果写明“哪天向哪一队追、谁解释、如何转给新医生”；跨时区时同时记两地时间。

**接诊未落实、设备缺货或航司不接受现有材料：** 把具体缺口反馈给原治疗团队／出院协调人及相关服务方，问临时在当地继续照护、补件或延期的安排和费用。家属不能自行减少照护来赶飞机，也不把出院申诉当作自动延长住宿的办法。临床情况变化优先按医嘱和当地急救流程处理。

完成证据是两端有明确接手人、复诊及供药／设备安排可执行、未出结果有人追踪；抵达后再确认服务实际开始。此处没有替本人判断旅行适宜性或境外保险资格。

## 药物核对不要只看新打印单

把出院药物清单和入院前真实用药逐项对照，特别找：
- 重复用药；
- 同一种药不同规格；
- 医嘱写明“暂停使用”，但家里仍有旧药瓶；
- 抗凝药、胰岛素、阿片类药物、类固醇等高风险药；
- 按需使用（PRN）药的最大频率；
- 哪位医生负责下一次续配。

不确定时联系出院团队／药师／处方医生，不靠家人自己猜。对伤口、设备和给药操作，可以请工作人员演示，再由实际照护者复述或演示一次，确认理解一致。

## 保险和账单同步建档

- [ ] 保存入院／出院日期、住院或观察身份、理赔／授权编号。
- [ ] 记录救护车、医院、医生、放射科、病理科、耐用医疗设备（DME）、居家医疗服务等可能分开发账的主体。
- [ ] 有保险时，把账单与保险理赔说明（EOB）、理赔状态和已付款逐项核对。保险尚未处理完时，主动联系账单部门和保险方，记录付款期限并请求核查或暂缓催收的书面确认；不要默认等待理赔会暂停期限。自费或未走保险的账单可能没有 EOB，应直接核对明细、估价及适用争议程序。

**账单核对入口：** [美国消费者金融保护局：医疗账单核查与求助](https://www.consumerfinance.gov/ask-cfpb/what-should-i-do-if-i-cant-pay-a-medical-bill-en-2125/)。

- [ ] 需要康复／专业护理机构（SNF）／居家医疗服务时，提前问保险保障条件和保险网络。

## 工作和家庭运营

重大诊断往往同时影响：
- 病假／家庭与医疗假／伤残保障；
- 儿童照护；
- 宠物照护；
- 交通；
- 家庭账单；
- 旅行计划；
- 移民／跨境事务预约。

把这些放进一张临时分工与办事安排，而不是要求病人本人独自处理。可结合[第34章](../book/34-重大打击后的Temporary-Operating-Mode.md)和[第30章](../book/30-Household-Emergency-Runbook.md)。

## 出院后的第一个复盘点

在最初复诊前确认：
- 所有处方真的拿到了；
- 设备到了且会用；
- 上门服务真正开始；
- 化验／影像／病理结果有人负责审阅；
- 复诊预约已排；
- 症状没有恶化；
- 照护者理解操作、愿意承担且具备实际照护能力；不足时已向团队求助。
