# 同居合住与重组家庭：两地费用、权限和交接

> **内容性质：家庭协商与专业咨询准备。** 用于伴侣同居、室友合住，以及带孩子进入新家庭并往返两国的安排。日常约定、租约、产权、亲子关系与法院命令分别确认；不把夫妻制度套给未婚伴侣或室友。存在暴力、威胁或控制时先用[关系安全清单](separation-family-safety.md)，不要求当面共同协商。

## 合住前先列实际责任

第一步不是合并账户，而是把住房合同、公共账单、大件物品、宠物与预计离境时间放在一起谈。每人保留个人资金和通信渠道；具体法律后果由所在地专业人士核对。

| 写在私人约定里的问题 | 怎样写得可执行 |
|---|---|
| 谁签房屋和服务合同 | 列合同上的姓名、付款日、各自份额、钱付给谁；室友约定能否改变对外责任要问合同对方 |
| 一方回中国数月 | 哪些固定费继续分担，哪些按实际使用，谁在美国收件报修，发生额外费用怎样批准 |
| 押金、家具与共同购物 | 保存各自付款和物品清单，约定搬走时取回、买断或出售的办法；不只写“到时再算” |
| 家务、访客与隐私 | 写明确频率、可接受时间及提前通知方式；共享设备不默认共享账号和定位 |
| 宠物与照护 | 谁日常负责、出行时谁接手、医疗费用怎样商量；分开时需按合同和适用规则处理 |
| 一方退出或欠款 | 怎样通知、如何向房东申请调整、何时核对账单和钥匙，分歧找哪类专业帮助 |

## 从约定到实际生效

1. 每人先独立列自己的限制和不能承担的事项，再讨论共同版本；有不理解或压力过大的条款先暂停。
2. 联系房东／物业，确认居住人、租客、转租或增加住户的正式要求；向水电网机构确认账户与付款安排。拿到同意和修订文本之前，不把内部约定当作合同已变更。
3. 涉及房产、较大共同投资、债务、医疗或财务代理时，分别向有资格的律师说明关系、地点与目标，问需要何种文件、各自是否应独立咨询。通用模板不替代文件审查。
4. 实际试行一轮账单分摊和家务安排，检查是否到账、是否有人被迫垫付、外部联系人是否能受理；修正不现实的分工。
5. 一方离境前交接收件、维修、付款与应急事务。只提供必要资料和获认可权限；不共享银行登录或让同住者冒充本人。

共同生活不等于机构自动允许对方看病历或管理账户；具体权限从[失能与授权](../book/10-Estate-Planning与失能.md)和[成年子女权限](adult-child-transition.md)按实际关系分开询问。**完成标准：** 家庭内部责任说清，对外合同实际接受，首轮付款与交接可核对。

## 重组家庭先确认谁能为孩子办理什么

把每个孩子单独列一页：法定父母／监护人、现有法院命令或协议、主要居住地、学校和医疗联系人、旅行证件、接送者。只向实际需要的人提供必要信息。新伴侣愿意照护与其是否有权签字是两件事。

1. **先梳理已有文件。** 有离婚、监护、探视或搬迁安排时，把完整文件交给处理相应地区事务的律师，说明拟往返国家、日期和住址变化；问是否需要另一方同意、法院处理或其他手续。存在分歧时先暂停不可撤销的旅行安排，不用机票逼对方同意。
2. **学校与医疗分别登记。** 有权办理的人联系学校办公室和医疗机构，确认新伴侣可接送、收哪些通知、可否陪诊及需要什么授权。分别取得接受确认；家长群里的介绍不替代正式登记。
3. **排实际接送表。** 写谁送到哪里、谁当面接收、临时晚到找谁、是否可由备用人接走。两地家人按当地日期／时区核对，避免儿童被留在无人接手的位置。
4. **跨境出行再单独核对。** 联系目的地使领馆与实际承运人，按孩子证件、同行者与监护情况问材料。国务院[未成年人旅行说明](https://travel.state.gov/en/international-travel/planning/personal-needs/minors.html)指出各地出入境与同意材料不同；不能用“美国出境不查某材料”推断目的地、法院或航司都不要求。
5. **抵达后确认接续。** 实际照护者收到必需病历、药物与学校安排；孩子有能联系原照护者的方式。临时改期或无法交还，先联系有权决定的相关方及法律顾问，不能自行改成长期留居。

## 冲突和变化怎样处理

费用分歧用已保存的账单和约定逐项核对，不让孩子传话或担任翻译。孩子不适应时先听具体原因，与其有权决定的照护者及必要的专业人员讨论；不要以花费或签证投入要求孩子接受安排。

一方退出同居，按房东／服务机构接受的方式处理退出、钥匙、物品和账单；保留安全的联系与文件渠道。重组家庭变化则重新确认孩子的照护、接送和权限，不能随成年人关系变化自动取消应履行的责任。

2026-10-23：定点读取国务院未成年人旅行材料边界。其余为协商和办理顺序，不判断共同财产、监护、赡养、移民或跨境命令效力；这些须按实际文件和地区核对。
