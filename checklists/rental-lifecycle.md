# 租房全流程：看房、签约、入住、争议、转租与退租

这份清单补齐“租房不是只有维修和搬家”的全过程。维修、承包商与住宅安全见[第09章](../book/09-住房物业与Contractor.md)，实际搬运见[搬家清单](move-checklist.md)。

> 租客权利、押金、notice period、维修义务、租金管制、转租、提前解约和 eviction 程序高度州／地方化。不要把其他州攻略中的天数或金额直接套用。

## 看房与申请前

- [ ] 确认实际房东／management company、单元号、月租、lease term、可入住日和申请费。
- [ ] 问清 parking、storage、pets、amenity、utilities、搬家费、broker fee 与其他 recurring / one-time charges。
- [ ] 看手机信号、噪音、窗户、热水、HVAC、电梯、垃圾／包裹、洗衣、虫害迹象和实际采光。
- [ ] 对口头承诺要求写进 lease、addendum 或正式书面沟通。
- [ ] 汇款押金前独立核验收款方与房源，警惕假房东和只接受不可追回付款方式的要求。

## 签约前逐条读

重点找：租金与 late fee、续租、rent increase notice、security deposit、utilities、维修报修、entry、guest、pet、sublease / assignment、early termination、move-in / move-out、insurance、parking、attorney-fee / dispute provisions。

- [ ] 不懂的条款先问，重大金额或异常条款可让当地 tenant lawyer 审查。
- [ ] 保存完整签署版 lease 和所有 addenda，不只保存电子签平台的链接。
- [ ] 确认付款 portal、maintenance portal 和 after-hours emergency number。

## 入住当天建立证据

- [ ] 对墙面、地板、窗、柜、家电、卫浴、已有污渍／损伤拍带日期的照片／视频。
- [ ] 按 building / landlord 流程提交 move-in condition report。
- [ ] 保存钥匙、fob、parking permit、meter reading 和押金／首月租金收据。
- [ ] 测试 smoke / CO alarms、门锁、热水和基本设备；有问题尽快书面报修。

## 租期中：所有重要问题留书面记录

- [ ] 报修写清日期、问题、是否影响安全／居住、照片和希望回复的方式。
- [ ] 紧急问题走紧急入口，普通问题不要只靠电话口头沟通。
- [ ] 房东／物业进屋、维修完成、临时安排和费用争议都保存确认。
- [ ] 怀疑权利被侵害或长期无法解决时，先读 lease，再查本州 tenant-rights agency / legal aid。

**全国入口：** [USA.gov：Tenant rights / landlord complaints](https://www.usa.gov/tenant-rights)。该页面会引导到州级 tenant rights、attorney general / housing agency 及 legal aid；具体法律仍看州和地方。

## 想转租、换室友或提前解约

- [ ] 先看 lease 对 sublease、assignment、roommate replacement、notice 和 landlord consent 的要求。
- [ ] 不要仅凭“物业口头说可以”就找下一位承租人；取得书面批准。
- [ ] 明确原租客是否仍承担租金、损坏或违约责任。
- [ ] 因军务、家庭暴力、住房不可居住或其他特殊法律理由寻求提前终止时，查适用州／联邦规则并获取专业帮助，不用普通 break-lease 条款覆盖特殊权利。
- [ ] 比较 buyout、lease transfer、sublease、继续付租直到重新出租等不同路径的真实书面条件。

## 收到 landlord notice、pay-or-quit、notice to cease 或法院文件

- [ ] 当天记录收到方式和日期，保存信封、邮件、门上 notice 与完整附件。
- [ ] 区分普通物业沟通、termination notice、demand 和真正 court papers。
- [ ] 不要因为正在和 management 协商就假设法律 deadline 自动停止。
- [ ] 迅速查本州法院 self-help / tenant legal aid，必要时找律师。
- [ ] 出庭／答辩／提交文件的期限以实际法院文件和当地规则为准。

## 退租前

- [ ] 按 lease 和当地规则给 notice，并保存对方收到证据。
- [ ] 预约 move-out / inspection（如适用），问清清洁、钥匙与电梯要求。
- [ ] 修复自己明确负责且合理可处理的问题，不擅自大修可能属于房东责任的项目。
- [ ] 完成搬出照片／视频，记录 meter、钥匙归还和 forwarding address。

## 押金和最终账单

- [ ] 保存 move-in 与 move-out 状态证据、lease、付款记录和维修沟通。
- [ ] 记录 statutory / lease deadline，但只使用本州当前规则。
- [ ] 收到扣款后逐项对照照片、正常磨损（ordinary wear and tear）与合同义务。
- [ ] 争议无法解决时，从州 consumer / tenant agency、legal aid 或 small-claims / housing court 入口升级。

## 完成标准

租房流程不是“箱子搬走”就结束。完成应至少包括：lease obligations 已结束、钥匙交回有凭证、utilities / insurance 已切换、押金／final balance 有结果、邮件地址已更新、未结争议有明确下一步。

最后编辑与来源核验：2026-09-21。全国投诉和州级入口参考 USA.gov tenant-rights 页面；具体权利、期限和程序按房屋所在地法律与租约核实。
