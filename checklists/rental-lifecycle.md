# 租房全流程：看房、签约、入住、争议、转租与退租

> **内容性质：管理建议** 勾选项用于整理任务，不代表每项都是法律义务；期限、资格与合同要求按所在地和实际文件确认。

这份清单补齐“租房不是只有维修和搬家”的全过程。维修、承包商与住宅安全见[第09章](../book/09-住房物业与Contractor.md)，实际搬运见[搬家清单](move-checklist.md)。

> 租客权利、押金、通知期限、维修义务、租金管制、转租、提前解约和驱逐程序高度州／地方化。不要把其他州攻略中的天数或金额直接套用。

## 看房与申请前

- [ ] 确认实际房东／物业管理公司、单元号、月租、租期、可入住日和申请费。
- [ ] 问清停车、储物空间、宠物、公共设施、水电等公共服务、搬家费、经纪费与其他定期／一次性费用。
- [ ] 看手机信号、噪音、窗户、热水、暖通空调系统（HVAC）、电梯、垃圾／包裹、洗衣、虫害迹象和实际采光。
- [ ] 对口头承诺要求写进租约、补充协议或正式书面沟通。
- [ ] 汇款押金前独立核验收款方与房源，警惕假房东和只接受不可追回付款方式的要求。

## 签约前逐条读

重点找：租金与滞纳金、续租、涨租通知、押金、水电等公共服务、维修报修、房东进入房屋的条件、访客、宠物、转租／租约转让、提前终止、入住／退租、保险、停车、律师费及争议处理条款。

- [ ] 不懂的条款先问，重大金额或异常条款可让当地租客权益律师审查。
- [ ] 保存完整签署版租约和所有补充协议，不只保存电子签平台的链接。
- [ ] 确认付款平台、报修平台和非营业时间紧急电话。

## 入住当天建立证据

- [ ] 对墙面、地板、窗、柜、家电、卫浴、已有污渍／损伤拍带日期的照片／视频。
- [ ] 按楼宇／房东流程提交入住状况记录。
- [ ] 保存钥匙、门禁卡、停车许可、水电表读数和押金／首月租金收据。
- [ ] 测试烟雾／一氧化碳报警器、门锁、热水和基本设备；有问题尽快书面报修。

## 租期中：所有重要问题留书面记录

- [ ] 报修写清日期、问题、是否影响安全／居住、照片和希望回复的方式。
- [ ] 紧急问题走紧急入口，普通问题不要只靠电话口头沟通。
- [ ] 房东／物业进屋、维修完成、临时安排和费用争议都保存确认。
- [ ] 怀疑权利被侵害或长期无法解决时，先读租约，再查本州租客权益机构／法律援助。

**全国入口：** [USA.gov：租客权益](https://www.usa.gov/tenant-rights)。该页面会引导到州级租客权利、州总检察长办公室／住房主管部门及法律援助；具体法律仍看州和地方。

## 想转租、换室友或提前解约

- [ ] 先看租约对转租、租约转让、更换室友、通知和房东同意的要求。
- [ ] 不要仅凭“物业口头说可以”就找下一位承租人；取得书面批准。
- [ ] 明确原租客是否仍承担租金、损坏或违约责任。
- [ ] 因军务、家庭暴力、住房不可居住或其他特殊法律理由寻求提前终止时，查适用州／联邦规则并获取专业帮助，不用普通提前解约条款覆盖特殊权利。
- [ ] 比较付费解约、租约转让、转租、继续付租直到重新出租等不同路径的真实书面条件。

## 收到房东通知、缴租或搬离通知、要求停止违约行为的通知或法院文件

- [ ] 当天记录收到方式和日期，保存信封、邮件、门上通知与完整附件。
- [ ] 区分普通物业沟通、终止租约通知、正式要求和真正法院文件。
- [ ] 不要因为正在和物业管理方协商就假设法律期限自动停止。
- [ ] 迅速查本州法院自助指南／租客法律援助，必要时找律师。
- [ ] 出庭／答辩／提交文件的期限以实际法院文件和当地规则为准。

## 退租前

- [ ] 按租约和当地规则给通知，并保存对方收到证据。
- [ ] 预约退租／验房（如适用），问清清洁、钥匙与电梯要求。
- [ ] 修复自己明确负责且合理可处理的问题，不擅自大修可能属于房东责任的项目。
- [ ] 完成搬出照片／视频，记录水电表、钥匙归还和后续收信地址。

## 押金和最终账单

- [ ] 保存入住与退租状态证据、租约、付款记录和维修沟通。
- [ ] 记录法定／租约期限，但只使用本州当前规则。
- [ ] 收到扣款后逐项对照照片、正常磨损与合同义务。
- [ ] 争议无法解决时，从州消费者保护／租客权益机构、法律援助或小额诉讼／住房法院入口升级。

## 完成标准

租房流程不是“箱子搬走”就结束。完成应至少包括：租约义务已结束、钥匙交回有凭证、水电等公共服务／保险已切换、押金／最终余额有结果、邮件地址已更新、未结争议有明确下一步。

最后编辑与来源核验：2026-09-22。全国投诉和州级入口参考美国政府服务网租客权利页面；具体权利、期限和程序按房屋所在地法律与租约核实。
