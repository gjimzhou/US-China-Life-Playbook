# 逐项引用规范（Claim-level Citation Guide）

本项目的目标不是“每章有若干链接”，而是让读者能够判断：**每个事实、数字、规则、论点和行动建议分别依据什么。**

## 1. 哪些内容必须有来源

以下内容原则上都要在相邻句子、段落或条目中给出来源：

- 可外部验证的事实、定义、数字、概率、时间、期限、电话号码与机构职责；
- 法律、监管、税务、保险、移民、医疗与政府办事规则；
- “应该 / 不应该 / 最好 / 优先 / 可以降低风险”等行动性建议；
- 对风险、收益、筛查价值、证据强弱或常见误区的判断；
- 表格中的事实性单元格、清单中的操作要求，以及正文中的反例；
- 对社会习惯、服务流程或专业实践的概括。

纯粹的导航文字（例如“详见第 03 章”）和对本项目自身结构的说明可以不另引外部来源。

## 2. 引用必须靠近主张

优先采用以下两种形式：

> 安全带可降低前排乘用车乘员的致命伤风险约 45%。[NHTSA](https://www.nhtsa.gov/vehicle-safety/seat-belts)

或：

> **依据：** [NHTSA：安全带](https://www.nhtsa.gov/vehicle-safety/seat-belts)；[NHTSA：儿童约束与安全带证据综述](https://www.nhtsa.gov/book/countermeasures-that-work/seat-belts-and-child-restraints)

一条规则中包含多个不同主张时，不要只在段末放一个无法判断对应关系的“来源”链接；应把引用放到支持的句子或小段旁。

## 3. “建议”也要交代依据

建议分三类处理：

1. **直接来自权威指南的建议**：直接引用该指南。
2. **从多个来源综合出的执行建议**：标明“编辑性综合 / 实务建议”，并列出支撑它的来源。
3. **只有本项目偏好、缺乏可靠外部依据的建议**：不得包装成普遍事实。应删除、缩窄，或明确标为“本项目工作流建议（证据等级 C）”。

证据等级 C 不等于“无需来源”。能找到与该做法相关的应急准备、专业实践、消费者保护或机构流程来源时，仍应引用。

## 4. 数字和动态规则

数字、门槛、年龄、金额、期限、表格版本、政策状态和电话号码必须：

- 优先引用第一手官方来源；
- 尽量在同一句或同一条内给出引用；
- 对会变化的内容写明“最后核验：YYYY-MM-DD”及核验范围；
- 不用旧页面的发布日期冒充当前规则的生效日期。

## 5. 论点与推理

“来源支持 A”和“本项目从 A 推出 B”必须区分。

例如：

> 多做筛查可能增加假阳性、过度诊断和后续侵入性检查。[NCI](https://www.cancer.gov/about-cancer/screening/hp-screening-overview-pdq)  
> 因此，本项目建议先问“结果是否会改变处理”，再决定是否购买额外筛查套餐。**这是基于上述证据的编辑性决策规则，不是 NCI 的逐字建议。**

这样既保留可执行性，也不把编辑推理伪装成官方结论。

## 6. 来源优先级

优先顺序：

1. 现行法律、法规、政府部门、监管机构、法院及官方办事入口；
2. 医学与其他专业机构正式指南、共识或标准；
3. 系统综述、荟萃分析、随机对照试验和高质量大型研究；
4. 可靠医院、消费者组织、保险机构与专业事务所的实务资料；
5. 新闻、论坛和个人经验只用于发现问题或说明争议，不独立支撑高后果结论。

## 7. 无法找到可靠来源时

不要为了“全覆盖”而塞入低质量链接。

优先顺序是：

1. 寻找更权威或更准确的来源；
2. 缩窄主张，使其与现有证据匹配；
3. 明确写成“编辑性建议 / 待核验”；
4. 如果仍会误导，删除该主张。

## 8. 每章完成标准

一章只有同时满足以下条件，才可标为“逐项引用完成”：

- 所有事实性段落均有相邻来源；
- 每个数字、期限、金额、年龄、电话号码都有直接来源；
- 所有行动建议有指南依据，或被明确标为编辑性综合；
- 清单中的每项都能回指正文依据；
- 章末“核验范围”明确哪些内容已核验、哪些仍依赖个案或地方规则；
- 没有用一个章末链接列表替代 claim-level citation。
