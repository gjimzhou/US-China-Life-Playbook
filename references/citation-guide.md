# 实用参考链接规范（Reader-facing Reference Guide）

本项目不是学术论文。引用的首要目的不是证明“作者查过资料”，而是让读者读到一条规则后，**能立即点出去继续理解、计算、办理或核实。**

因此，本项目优先使用 **reader-facing source links**，而不是密集的论文式脚注。

## 1. 每条内容最好给读者下一步入口

对税务、保险、移民、医疗、政府办事、买房、消费者权益等条目，优先提供下列一种或多种链接：

- **官方原文**：IRS、USCIS、州税务局、CMS、CDC、法院、监管机构等直接说明规则的页面；
- **详细解释**：官方 FAQ、官方指南、可靠专业机构或高质量消费者指南；
- **办理入口**：提交表格、预约、查询、申诉、冻结信用、申请文件等可以直接操作的页面；
- **工具 / 计算器**：官方 estimator、lookup、search、eligibility checker 等；
- **表格 / instructions**：当读者确实需要看具体表格、定义、门槛或例外时直接链接。

学术论文、系统综述和原始研究主要用于医学证据、风险大小或存在真实学术争议的结论；**普通生活规则不应为了“像论文”而堆论文。**

## 2. 推荐呈现方式

优先写成能一眼看懂用途的链接：

> **继续看：** [IRS 官方：2026 Publication 505 — Tax Withholding and Estimated Tax](https://www.irs.gov/publications/p505) · [IRS 工具：Tax Withholding Estimator](https://apps.irs.gov/app/tax-withholding-estimator)

或：

> **办事入口：** [FinCEN：在线提交 FBAR](https://bsaefiling.fincen.treas.gov/NoRegFBARFiler.html)  
> **规则说明：** [FinCEN：谁需要申报 FBAR](https://www.fincen.gov/report-foreign-bank-and-financial-accounts)

链接文字要告诉读者“点进去能干什么”，不要只写“来源 1 / 来源 2”。

## 3. 一条规则里可以有三层链接

对于高价值条目，最好同时覆盖：

1. **一句话解释**：正文已经告诉读者核心结论；
2. **官方原文 / FAQ**：读者需要确认定义、期限、例外时点进去；
3. **实际操作入口**：真正去算、查、申请、付款、申诉或预约。

例如税务预扣条目可以同时给：
- Publication 505：完整规则；
- IRS withholding 页面：通俗解释；
- Tax Withholding Estimator：直接计算。

## 4. “事实依据”和“继续阅读”不必写成学术脚注

本项目允许一条链接同时承担“支持主张”和“帮助读者继续操作”的功能。

只要链接确实支持相邻内容，就不必写成论文式编号引用。优先使用：

- **继续看**
- **官方原文**
- **官方解释**
- **办理入口**
- **计算工具**
- **州 / 地方规则**
- **医疗指南**
- **消费者指南**

这些标签比“参考文献 [17]”更适合本项目。

## 5. 来源选择：实用性与权威性一起考虑

默认优先顺序：

1. **官方且好用的页面**：政府 FAQ、专题页、在线工具、办事入口；
2. **官方原始规则 / instructions**：适合需要精确核对的人；
3. **高质量专业解释**：官方页面太技术化时，用可靠专业机构帮助理解，同时保留官方链接；
4. **学术证据**：医学、风险、统计结论或研究争议需要时再用；
5. **论坛 / 社交媒体**：只用于发现真实问题和生活经验，不作为高后果规则的唯一依据。

“官方”不自动等于“最适合读者”。如果官方只有几十页 PDF，可以同时给一个可靠的详细解释页面。

## 6. 动态规则仍然必须标明日期

税率、门槛、年龄、金额、期限、表格版本、移民政策、保险规则等会变化的内容仍要：

- 指向当前官方页面；
- 必要时注明“最后核验：YYYY-MM-DD”；
- 不把旧年度 instructions 当成当前年度定稿；
- 如果只有旧资料可用，正文明确说明。

## 7. 社交、家庭运营等软性建议怎么引用

这类内容不需要硬凑论文。

处理方式：

- 能找到权威礼仪、机构或专业服务指南时，链接给读者延伸阅读；
- 主要来自生活经验的，明确写成“实务建议 / 一种可行做法”，避免写成美国社会统一规则；
- 对地区、阶层、年龄、族群差异大的内容，优先给多个视角或说明适用边界，而不是假装存在唯一官方答案。

## 8. 每章完成标准

一章标为“参考链接完成”时，应做到：

- 几乎每个事实 / 规则 / 建议条目都有一个有用的外部入口；
- 高后果条目优先有官方原文；
- 能直接办理或计算的地方尽量给直接入口；
- 链接显示文字说明用途，而不是裸网址或“来源”；
- 学术文献只在真正需要证据链时出现；
- 章末不再用一串链接替代正文中的就近入口；
- 所有链接都服务于读者下一步，而不是为了提高“引用数量”。
