## 实用参考链接改造进度

目标见[实用参考链接规范](citation-guide.md)：不是把全书改成论文，而是让读者在每个重要条目旁能直接进入官方解释、办事入口、查询工具、计算器、投诉渠道或高质量实务说明。

**首轮 reader-facing reference pass 已完成：40 / 40 章正文 + 11 / 11 份执行清单。**

“首轮完成”表示：全书已系统增加 reader-facing links，高后果条目优先连接到官方入口；软性社交 / 家庭运营建议则明确保持为情境化实践建议，不强行伪装成学术定论。**这不表示所有州别、地方规则、个案、合同、保险条款或动态页面已经最终核验完成。**

下一阶段改为质量审计：

1. 扫描残留的旧式“来源：”与只证明出处、但不能帮助读者继续行动的链接。
2. 检查失效、跳转、历史 PDF、访问受限与明显过时的页面，能替换时优先换成当前 landing page / FAQ / action portal。
3. 检查重复链接、链接文字不清、裸 URL 与同一规则多处维护造成的漂移。
4. 对动态规则继续保留“最后核验”日期与适用边界。
5. 把正文与 11 份 checklist 的“去办 / 核验”入口保持一致。
