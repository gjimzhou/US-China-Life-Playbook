# US–China Life Playbook

> 面向高收入、长期在美国生活、同时维持中国家庭与社会连接的第一代移民家庭的一套可执行生活操作系统。

这不是“省钱技巧合集”，也不是“中国人如何适应美国”的入门手册。它假设读者已经能够独立生活、受教育程度较高、家庭收入较高，也愿意用钱购买专业服务；真正缺少的是美国本地家庭通过父母、朋友、社区和几十年生活经验自然获得的 **tacit knowledge / social infrastructure**，以及一套能同时维持中美两地生活的系统。

核心目标：

1. 降低死亡、重伤、诉讼、身份盗窃、税务、移民、失能等 **tail risk**。
2. 建立 “event → institution → professional → procedure” 的默认映射。
3. 用专业服务和制度替代临时 Google、记忆和运气。
4. 让美国成为完整的 principal home system，同时保持中国作为可随时重新接入的 secondary home system。
5. 把复杂家庭生活变成一套可以维护、审计和年度 review 的 operating system。

---

## 适用画像

本指南主要为以下家庭设计：

- 30–50 岁，第一代移民或长期海外华人；
- 美国为主要居住地，同时在中国长期维持父母、身份、银行、医疗和社会关系；
- high W-2 / professional income，有显著储蓄和资产；
- 有能力购买律师、CPA、insurance broker、医生、contractor 等专业服务；
- 有汽车、旅行、宠物、婚姻、未来孩子/父母养老等复杂 household operations；
- 对美国很多“默认大家都知道”的社会流程缺少代际传承。

它不是根据收入决定“谁更值得安全”，而是承认：不同家庭的 opportunity cost、资产暴露、专业服务使用方式和跨境复杂度不同。

## 本书的基本哲学

### 1. 用钱购买可靠性，而不是购买炫耀
高收入以后，$100–$1,000 的优化通常不如一次六位数 liability、错误税务处理、身份盗窃、漏掉保险、重大医疗延误重要。

### 2. 优先处理不可逆 downside
排序优先考虑：
- impact
- probability
- irreversibility
- evidence
- implementation cost
- ongoing friction

### 3. 不把“检查越多”误认为“健康管理越好”
医疗以 evidence-based preventive care 为基线。无指征筛查、全身扫描、肿瘤标志物套餐等需要同时考虑 false positive、incidental finding、overdiagnosis 和 downstream harm。

### 4. 不要求家庭成员记住所有东西
最可靠的家庭不是“最聪明”，而是：
- 有 checklist；
- 有固定入口；
- 有备用联系人；
- 有文档；
- 有明确授权；
- 有年度 review。

### 5. 中美双栖不是两个半套系统
目标是：

**US primary system + China maintained secondary system + cross-border interface**

而不是每次回国重新学习中国、每次返美重新 Google 美国。

## Methodology

详见 [METHODOLOGY.md](METHODOLOGY.md)。

每条建议逐步使用：

| 字段 | 含义 |
|---|---|
| Evidence | A / B / C：证据和权威来源质量 |
| Priority | P0 / P1 / P2 / P3 |
| Impact | Low / Medium / High / Catastrophic |
| Cost | Free / Low / Medium / High |
| Friction | One-time / Annual / Ongoing |
| Geography | US / China / Cross-border |
| Owner | Self / Spouse / Household / Professional |

- **P0**：低成本、高后果，建议尽快完成。
- **P1**：明显提高家庭稳健性，建议本年度完成。
- **P2**：在特定生活阶段执行。
- **P3**：有价值但不急。

来源规范见 [references/source-policy.md](references/source-policy.md)。

## Public-first 隐私原则

本项目是 **public-first**：只保存通用规则、公开资料与空白模板。**绝不提交任何作者或使用者的个人信息、可识别生活细节或私人记录。**

不应提交：

- SSN / 身份证号码；
- passport number；
- 银行账号；
- 密码 / recovery code；
- 完整 medical record；
- 私人律师、医生、父母等敏感联系人详情；
- 真实住址、工作单位、收入/资产数字、行程、家庭成员身份、健康史、移民个案等可识别个人信息。

真实敏感信息应存放在合适的 password manager、encrypted storage 或其他私密系统；repo 只存字段结构和操作说明。

任何示例人物、金额、地点和情景都应使用虚构或泛化数据，不以 repo owner 的真实情况为示例。
