## 阅读须知与免责声明

内容仍在持续编写与核验，仅供一般参考，不替代个人医疗、法律、税务、投资或移民专业意见。行动前核对适用地区、日期和官方来源；紧急危险时优先联系当地应急服务。[完整声明](DISCLAIMER.md)。

## 如何判断优先级与可信度

[方法论](METHODOLOGY.md)区分证据、优先级、后果、成本与适用地区。P0–P3 是准备优先级，不是紧急等级，也不合成为“人生分数”。

## 核心原则

先处理高后果风险，必要时找合格专业人士；用清单、资料索引和定期复查减少遗漏。中美两地规则分别确认，再安排衔接。
